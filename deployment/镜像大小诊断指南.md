# Docker 镜像大小诊断指南

## 🔍 快速诊断

### 方法1: 使用分析脚本（推荐）

```bash
cd deployment
./analyze-image-size.sh cozychat/backend:v0.1.0
```

这个脚本会自动分析：
- 镜像各层大小
- 目录大小分布
- Python 包大小
- 系统包大小
- 大文件位置
- 缓存和临时文件
- Git 历史
- 构建工具

### 方法2: 手动分析

#### 1. 查看镜像基本信息

```bash
docker images cozychat/backend:v0.1.0
```

#### 2. 查看镜像各层大小

```bash
docker history cozychat/backend:v0.1.0 --human
```

#### 3. 启动临时容器分析

```bash
# 创建临时容器
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)

# 查看根目录大小分布
docker exec $CONTAINER_ID du -h --max-depth=1 / | sort -rh

# 查看 Python 虚拟环境大小
docker exec $CONTAINER_ID du -sh /opt/cozychat/backend/.venv

# 查看最大的 Python 包
docker exec $CONTAINER_ID du -h /opt/cozychat/backend/.venv/lib/python3.11/site-packages/* | sort -rh | head -20

# 查找大文件（>100MB）
docker exec $CONTAINER_ID find / -type f -size +100M 2>/dev/null

# 清理临时容器
docker rm $CONTAINER_ID
```

## 📊 常见问题分析

### 问题1: Python 包过大

**检查方法**：
```bash
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)
docker exec $CONTAINER_ID du -h /opt/cozychat/backend/.venv/lib/python3.11/site-packages/* | sort -rh | head -20
docker rm $CONTAINER_ID
```

**可能的大包**：
- `sentence-transformers` (~500MB-1GB) - 包含预训练模型
- `chromadb` (~200-500MB) - 向量数据库
- `torch` (~1-2GB) - PyTorch（如果被依赖）
- `numpy` (~50-100MB)
- `transformers` (~500MB-1GB) - Hugging Face 模型

**优化方案**：
1. 使用 `--no-cache-dir` 安装（已实施）
2. 考虑使用更小的模型或按需下载
3. 使用多阶段构建，只复制必要的包

### 问题2: 基础镜像过大

**检查方法**：
```bash
docker images phusion/passenger-full:latest
```

**可能的大小**：2-3GB

**优化方案**：
1. 使用 `python:3.11-slim` (~200MB)
2. 使用 `ubuntu:22.04` + 手动安装 Python (~500MB)
3. 使用多阶段构建

### 问题3: Git 历史未清理

**检查方法**：
```bash
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)
docker exec $CONTAINER_ID test -d /opt/cozychat/.git && echo "⚠️ Git 历史存在" || echo "✓ Git 已清理"
docker exec $CONTAINER_ID du -sh /opt/cozychat/.git 2>/dev/null || echo "已清理"
docker rm $CONTAINER_ID
```

**优化方案**：
- 确保 `install.sh` 中删除了 `.git` 目录（已实施）

### 问题4: 构建工具未清理

**检查方法**：
```bash
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)
docker exec $CONTAINER_ID dpkg -l | grep -E "build-essential|gcc|python3.11-dev"
docker rm $CONTAINER_ID
```

**优化方案**：
- 确保 `install.sh` 中删除了构建工具（已实施）

### 问题5: 缓存未清理

**检查方法**：
```bash
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)
echo "apt 缓存:"
docker exec $CONTAINER_ID du -sh /var/lib/apt/lists 2>/dev/null || echo "已清理"
echo "pip 缓存:"
docker exec $CONTAINER_ID du -sh /root/.cache/pip 2>/dev/null || echo "已清理"
docker rm $CONTAINER_ID
```

**优化方案**：
- 确保清理了所有缓存（已实施）

### 问题6: 系统包过多

**检查方法**：
```bash
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)
docker exec $CONTAINER_ID dpkg-query -Wf '${Installed-Size}\t${Package}\n' | sort -rn | head -20 | awk '{printf "%.2f MB\t%s\n", $1/1024, $2}'
docker rm $CONTAINER_ID
```

**优化方案**：
- 只安装运行时必需的包
- 使用 `--no-install-recommends`

## 🎯 针对性优化方案

### 如果 Python 包过大（>5GB）

**问题**：`sentence-transformers` 或 `chromadb` 包含大型模型

**解决方案1：使用浅克隆模型**
```python
# 在代码中按需下载模型，而不是在安装时下载
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')  # 使用小模型
```

**解决方案2：多阶段构建**
```dockerfile
# 阶段1: 构建（包含所有依赖）
FROM phusion/passenger-full:latest AS builder
# ... 安装所有包 ...

# 阶段2: 运行（只复制必要的包）
FROM phusion/passenger-full:latest
COPY --from=builder /opt/cozychat/backend/.venv /opt/cozychat/backend/.venv
# 只复制运行时需要的包
```

**解决方案3：使用外部模型服务**
- 将模型部署到单独的服务
- 通过 API 调用，而不是本地加载

### 如果基础镜像过大（>3GB）

**解决方案：使用更小的基础镜像**

```dockerfile
# 方案1: 使用 python:3.11-slim
FROM python:3.11-slim

# 安装运行时依赖
RUN apt-get update && apt-get install -y --no-install-recommends \
    ffmpeg \
    libssl3 \
    libffi8 \
    portaudio19-dev \
    && rm -rf /var/lib/apt/lists/*

# 安装应用
WORKDIR /app
COPY requirements/base.txt .
RUN pip install --no-cache-dir -r requirements/base.txt
COPY . .

# 使用 gunicorn 或 uvicorn 运行
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 如果系统包过多（>1GB）

**解决方案：最小化系统包**

```bash
# 只安装运行时必需的包
apt install -y --no-install-recommends \
    ffmpeg \
    libssl3 \
    libffi8 \
    portaudio19-dev \
    python3.11 \
    python3.11-venv

# 不安装开发包和构建工具
```

## 📈 预期优化效果

| 优化项 | 当前 | 优化后 | 节省 |
|--------|------|--------|------|
| 基础镜像 | ~3GB | ~200MB (slim) | ~2.8GB |
| Python 包 | ~5GB | ~3GB (优化模型) | ~2GB |
| 系统包 | ~1GB | ~200MB | ~800MB |
| Git/缓存 | ~500MB | ~0MB | ~500MB |
| **总计** | **~9.5GB** | **~3.5GB** | **~6GB** |

## 🚀 快速优化步骤

### 步骤1: 运行诊断

```bash
cd deployment
./analyze-image-size.sh cozychat/backend:v0.1.0
```

### 步骤2: 根据诊断结果优化

1. **如果 Python 包过大**：
   - 检查最大的包
   - 考虑使用更小的模型
   - 或使用多阶段构建

2. **如果基础镜像过大**：
   - 考虑使用 `python:3.11-slim`
   - 或使用多阶段构建

3. **如果系统包过多**：
   - 只安装运行时必需的包
   - 删除所有开发工具

### 步骤3: 重新构建并验证

```bash
cd deployment
./build-images.sh --no-cache
./analyze-image-size.sh cozychat/backend:v0.1.0
```
