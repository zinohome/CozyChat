# CozyChat 快速部署说明

## 📦 部署结构

```
deployment/
├── backend/docker/          # 后端Docker构建文件
├── frontend/docker/         # 前端Docker构建文件
├── backend.env.example      # 后端环境变量示例
├── frontend.env.example     # 前端环境变量示例
├── docker-compose.yml       # Docker Compose配置
└── README.md               # 详细部署文档
```

## ⚡ 快速开始（5分钟）

### 1. 准备环境变量

```bash
cd deployment
cp backend.env.example backend.env
cp frontend.env.example frontend.env
```

### 2. 配置必需的环境变量

**编辑 `backend.env`**，至少配置：

```bash
APP_SECRET_KEY=your-secret-key-here
JWT_SECRET_KEY=your-jwt-secret-key-here
DATABASE_URL=postgresql://user:password@postgres-host:5432/cozychat
REDIS_URL=redis://redis-host:6379/0
OPENAI_API_KEY=sk-your-openai-api-key
CORS_ORIGINS=["https://your-frontend-domain.com"]
```

**编辑 `frontend.env`**，至少配置：

```bash
VITE_API_BASE_URL=https://api.your-domain.com
```

### 3. 创建数据目录

```bash
sudo mkdir -p /data/cozychat/{backend/{logs,data},frontend/dist}
sudo mkdir -p /data/qdrant/data
sudo chmod -R 755 /data/cozychat /data/qdrant
```

### 4. 确保1Panel网络存在

```bash
docker network create 1panel-network 2>/dev/null || true
```

### 5. 构建并启动

```bash
cd deployment
docker-compose build
docker-compose up -d
```

### 6. 查看日志

```bash
docker-compose logs -f
```

## 🔍 验证部署

1. **检查服务状态**：
   ```bash
   docker-compose ps
   ```

2. **检查后端健康**：
   ```bash
   curl http://localhost:8000/health
   ```

3. **访问前端**：
   浏览器打开 `http://your-frontend-domain:5173`

## 📝 常用命令

```bash
# 启动
docker-compose up -d

# 停止
docker-compose down

# 重启
docker-compose restart

# 查看日志
docker-compose logs -f backend
docker-compose logs -f frontend

# 重新构建
docker-compose build --no-cache
```

## ⚠️ 重要提示

1. **生产环境必须修改**：
   - `APP_SECRET_KEY` 和 `JWT_SECRET_KEY`
   - 数据库密码
   - 所有API密钥

2. **网络配置**：
   - 确保PostgreSQL和Redis在 `1panel-network` 网络中
   - 或使用外部IP地址

3. **CORS配置**：
   - 生产环境必须配置实际的前端域名
   - 不要使用 `["*"]`
