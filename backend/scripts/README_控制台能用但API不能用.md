# 控制台能用但API不能用 - 诊断指南

## 🎯 您的情况

- ✅ 控制台：AI大模型音色正常使用
- ❌ API调用：报"资源包配额用尽"
- ✅ 资源包：已购买100万字符，余额充足

## 📋 诊断流程（按顺序执行）

### 第1步：运行原生SDK测试

```bash
cd backend
python scripts/test_tencent_raw_sdk.py
```

**目的**：排除我们封装层的影响，验证腾讯SDK原生代码能否工作

**如果成功** ✅：
- 说明SDK本身没问题
- 可能是我们封装层的参数配置问题
- 继续使用我们的引擎，无需额外配置

**如果失败** ❌：
- 说明问题在于API调用参数
- 继续执行第2步

### 第2步：查看控制台的调用参数

1. 打开：https://console.cloud.tencent.com/tts
2. 找到"在线测试"或"API调试"功能
3. 选择AI大模型音色（如：AI女声）
4. 进行一次成功的合成
5. **打开浏览器开发者工具（F12）**：
   - 切换到 **Network** 标签
   - 找到WebSocket连接或HTTP请求
   - 查看请求参数，特别关注：

```
需要查看的关键参数：
┌────────────────────────────┐
│ ModelType: ？              │  ← 重点！可能不是1
│ VoiceType: ？              │  ← 应该是101001
│ FastVoiceType: ？          │  ← 可能有值
│ EmotionCategory: ？        │  ← 是否存在
│ 其他特殊参数: ？          │
└────────────────────────────┘
```

### 第3步：对比参数差异

**我们的API调用参数**（SDK硬编码）：
- ModelType: **1**
- VoiceType: **101001**
- FastVoiceType: **""**（空）

**控制台的参数**（您需要查看）：
- ModelType: **？** ← 关键：如果不是1，这就是问题所在！
- VoiceType: **？**
- FastVoiceType: **？**

### 第4步：检查服务开通状态

在控制台查看：

1. **基础语音合成服务**：
   - 状态：？（已开通/未开通）

2. **AI大模型语音合成服务**：
   - 状态：？（已开通/未开通）← 关键！

**可能的问题**：AI大模型服务需要单独开通！

**开通路径**（如果未开通）：
1. 访问：https://console.cloud.tencent.com/tts
2. 找到"服务管理"或"产品管理"
3. 开通"AI大模型语音合成服务"

### 第5步：检查资源包绑定

在控制台"资源包管理"中，确认：

```
资源包详情：
├── 状态：？（必须是"已生效"）
├── 绑定AppID：？（必须是 1318633704）
├── 类型：大模型语音合成
└── 剩余：1,000,000字符
```

**可能的问题**：
- 资源包未绑定到当前AppID
- 资源包绑定到了其他AppID

**解决方案**：
在资源包管理页面，手动绑定资源包到AppID 1318633704

## 🔧 可能的解决方案

### 解决方案1：ModelType不匹配（最可能）

**如果**控制台的ModelType不是1（例如是2），则：

**临时修复**：手动修改SDK源码

编辑文件：
```
backend/vendor/tencentcloud-speech-sdk-python/tts/speech_synthesizer_ws.py
```

找到第122行：
```python
params['ModelType'] = 1  # ← 改这里
```

改为控制台的值（例如2）：
```python
params['ModelType'] = 2  # ← 根据控制台的实际值
```

然后重新测试：
```bash
python scripts/test_tencent_raw_sdk.py
```

### 解决方案2：服务未开通

如果AI大模型语音合成服务未开通：

1. 访问：https://console.cloud.tencent.com/tts
2. 进入"服务管理"
3. 开通"AI大模型语音合成服务"
4. 等待5-15分钟生效
5. 重新测试

### 解决方案3：资源包未正确绑定

如果资源包未绑定或绑定错误：

1. 访问控制台"资源包管理"
2. 找到您的资源包
3. 点击"绑定"或"重新绑定"
4. 选择AppID：1318633704
5. 确认绑定
6. 等待生效（5-15分钟）
7. 重新测试
