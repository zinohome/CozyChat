# 记忆检索问题修复报告

## 问题描述

用户询问"我体重多少？"，但系统回答"目前你还没有告诉我你的体重"，尽管数据库中存在包含"体重90kg"的记忆。

## 问题分析

### 1. 数据库迁移问题

**错误**：`column session_contexts.extra_metadata does not exist`

**原因**：
- 迁移脚本中使用的是 `metadata` 列
- 模型中使用的是 `extra_metadata` 列
- 两者不一致导致查询失败

**修复**：创建新的迁移脚本，将 `metadata` 重命名为 `extra_metadata`

### 2. 记忆检索问题

**问题**：包含"体重90kg"的记忆（`'年龄 47  男  身高174  体重90kg'`）相似度太低（0.371525），未进入 top 5

**原因分析**：
1. **相似度太低**：查询"我体重多少？"和记忆"年龄 47  男  身高174  体重90kg"的语义相似度只有0.371525
2. **Boost不够大**：虽然智能评分会加分（+0.5+0.3=0.8），但最终分数只有1.171525，可能还是不够高
3. **检索数量不足**：只检索了20个结果（max_results * 2），那个记忆可能不在前20个中

## 修复方案

### 1. 数据库迁移修复

创建新的迁移脚本 `rename_session_contexts_metadata_to_extra_metadata.py`：
- 将 `metadata` 列重命名为 `extra_metadata`
- 兼容处理：如果列不存在，则创建新列

### 2. 智能评分优化

**增加检索数量**：
- 从 `max_results * 2` 增加到 `max_results * 3`
- 确保包含关键信息的记忆能被检索到

**增强Boost机制**：
- 对于包含查询关键词+具体数值的记忆，给予额外的大幅boost（+0.8）
- 例如："我体重多少？" 查询包含"体重"，记忆"体重90kg"也包含"体重"
- 这样即使原始相似度只有0.37，最终分数也能达到 0.37 + 0.5 + 0.3 + 0.8 = 1.97，确保进入top 5

**优化逻辑**：
```python
# 特殊处理：如果记忆包含查询关键词+具体数值，且查询也包含该关键词
query_keywords = [kw for kw in config.numeric_query_keywords if kw in query]
if query_keywords:
    for qk in query_keywords:
        if qk in content:
            # 对于"我体重多少？"和"体重90kg"这样的精确匹配，给予额外的大幅boost
            score += 0.8  # 大幅boost，确保关键记忆进入top 5
            break
```

### 3. 增强日志记录

添加关键记忆的专门日志记录：
- 记录所有包含数字+关键词的记忆
- 便于调试和问题排查

## 预期效果

修复后：
1. **数据库查询正常**：不再出现 `extra_metadata` 列不存在的错误
2. **关键记忆能被检索到**：包含"体重90kg"的记忆能够进入top 5
3. **智能评分更准确**：对于数值查询，包含具体数值的记忆会被大幅提升
