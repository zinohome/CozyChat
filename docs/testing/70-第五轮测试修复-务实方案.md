### 1. **useChat.test.ts** - 修复useChatStore.getState()问题 ✅

**问题**: 
```
TypeError: Cannot read properties of undefined (reading 'error')
error: useChatStore.getState().error
```

**根本原因**: 只mock了`useChatStore()`作为hook，但没有mock`useChatStore.getState()`静态方法

**修复**:
```typescript
beforeEach(() => {
  // Mock useChatStore as hook
  (useChatStore as any).mockReturnValue({
    isLoading: false,
    setLoading: mockSetLoading,
    setError: mockSetError,
    error: null,
  });
  
  // ✅ 新增：Mock useChatStore.getState() method
  (useChatStore as any).getState = vi.fn(() => ({
    isLoading: false,
    setLoading: mockSetLoading,
    setError: mockSetError,
    error: null,
  }));
});
```

**影响**: 修复5个测试失败

### 2. **useAuth.test.ts** - 修复localStorage和token问题 ✅

**问题**: 
```
AssertionError: expected "spy" to be called with arguments: [ { id: 'user-1', ... } ]
Number of calls: 0
```

**根本原因**: 
1. `useQuery`的`enabled`条件依赖`localStorage.getItem('access_token')`
2. 测试环境中没有mock localStorage

**修复**:
```typescript
it('应该获取当前用户', async () => {
  const mockUser = { id: 'user-1', username: 'testuser', email: 'test@example.com' };

  // ✅ Mock localStorage to have access_token
  Storage.prototype.getItem = vi.fn((key) => {
    if (key === 'access_token') return 'test-token';
    return null;
  });

  vi.mocked(authApi.getCurrentUser).mockResolvedValue(mockUser);
  
  const { result } = renderHook(() => useAuth(), { wrapper: createWrapper() });
  
  await waitFor(() => {
    expect(mockSetUser).toHaveBeenCalledWith(mockUser);
  });
});
```

**影响**: 修复1个测试失败

## 🎓 经验总结

### 1. **Mock Zustand Store的正确方式**
Zustand store既可以作为hook使用`useStore()`，也可以直接调用`useStore.getState()`，**两者都需要mock**：

```typescript
// ❌ 错误：只mock了hook
(useStore as any).mockReturnValue({ /* ... */ });

// ✅ 正确：同时mock hook和getState
(useStore as any).mockReturnValue({ /* ... */ });
(useStore as any).getState = vi.fn(() => ({ /* ... */ }));
```

### 2. **useQuery的enabled条件**
React Query的`enabled`选项会阻止查询执行，测试时需要满足条件：

```typescript
// Hook中的条件
useQuery({
  queryKey: ['auth', 'me'],
  queryFn: () => authApi.getCurrentUser(),
  enabled: !!localStorage.getItem('access_token'), // ⚠️ 需要mock
});

// 测试中需要mock localStorage
Storage.prototype.getItem = vi.fn((key) => {
  if (key === 'access_token') return 'test-token';
  return null;
});
```
