**原因**:
- 测试需要连接Redis服务
- Redis服务未启动或配置不正确

**修复方法 1: 启动Redis**

```bash
# macOS
brew services start redis

# 或手动启动
redis-server
```

**修复方法 2: 使用Mock (推荐测试环境)**

```python
# tests/conftest.py
import pytest
from unittest.mock import MagicMock

@pytest.fixture(autouse=True)
def mock_redis(monkeypatch):
    """为所有测试Mock Redis"""
    mock = MagicMock()
    monkeypatch.setattr('redis.Redis', lambda **kwargs: mock)
    return mock
```

**修复方法 3: 配置测试使用FakeRedis**

```bash
# 安装fake-redis
pip install fakeredis

# 在pytest.ini或conftest.py中配置使用fakeredis
```

**影响的测试**:
- `test_utils/test_cache.py` (12个测试)
- `test_utils/test_cache_coverage.py` (16个测试)
