## 优化方案

### 方案1：统一使用单例模式（推荐）

**修改 `app/main.py`**：

```python
# 5. 初始化并启动记忆写入Worker
memory_worker = None
if settings.memory_async_write:
    try:
        from app.engines.memory import get_memory_manager
        from app.engines.memory.worker import MemoryWorker
        
        # 使用全局单例，而不是创建新实例
        memory_manager = get_memory_manager()
        
        # 从memory_manager获取queue和engine
        if memory_manager.queue and memory_manager.engine:
            memory_worker = MemoryWorker(
                queue=memory_manager.queue,
                engine=memory_manager.engine,
                batch_size=settings.memory_batch_size
            )
            await memory_worker.start()
            logger.info("Memory worker started")
        else:
            logger.warning("Memory manager queue or engine not available")
    except Exception as e:
        logger.error(f"Failed to start memory worker: {e}", exc_info=True)
```

**修改 `app/engines/memory/worker.py`**：

```python
def __init__(
    self,
    queue: MemoryQueue,
    engine: QdrantMemoryEngine,
    deduplicator: Optional[MemoryDeduplicator] = None,  # 新增参数
    batch_size: Optional[int] = None,
    poll_interval: float = 1.0
):
    # ...
    # 使用传入的deduplicator，如果没有则创建新的
    self.deduplicator = deduplicator or MemoryDeduplicator(engine=engine)
```

**修改 `app/api/v1/memory.py`**：

```python
# 使用单例，而不是直接创建实例
from app.engines.memory import get_memory_manager

# 全局记忆管理器实例（使用单例）
memory_manager = get_memory_manager()
```

### 方案2：延迟初始化
