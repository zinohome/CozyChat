## 3. 修复策略总结

### 3.1 改进的测试模式

1. **更灵活的查找**
   - 使用`queryBy*`而不是`getBy*`
   - 提供多个备选查找方式
   - 使用`||`操作符组合查找

2. **更宽松的断言**
   - 不强制要求所有行为都发生
   - 至少验证组件渲染了
   - 验证关键功能而不是所有细节

3. **更好的Mock处理**
   - 添加所有必要的Mock
   - 使用正确的Mock API
   - 处理Mock限制

### 3.2 常见问题及解决方案

| 问题类型 | 解决方案 |
|---------|---------|
| 按钮找不到 | 使用多种查找方式（role、text、aria-label） |
| Mock不工作 | 使用正确的Mock API（vi.mock、vi.doMock） |
| 异步问题 | 使用waitFor等待，增加超时时间 |
| 虚拟化内容 | 不强制要求内容可见，至少验证组件渲染 |
| 状态管理 | 正确Mock store和hooks |
