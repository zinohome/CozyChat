## 📌 重要说明

### 核心理解（最终正确版本）

**现有架构**（engines/下的平级引擎）：
```
engines/
├── ai/        # AI引擎（保持不变）
├── memory/    # 记忆引擎 ← ❌ 删除整个目录
├── tools/     # 工具引擎（保持不变）
└── voice/     # 语音引擎（保持不变）
```

**重构后架构**（三个平级的新引擎替换memory/）：
```
engines/
├── ai/           # ✅ 保持不变
├── knowledge/    # ✅ 新增：知识引擎（Cognee），替换memory/
├── userprofile/  # ✅ 新增：用户画像引擎（Memobase），替换memory/
├── chatmemory/   # ✅ 新增：会话记忆引擎（Mem0），替换memory/
├── tools/        # ✅ 保持不变
└── voice/        # ✅ 保持不变
```

### 关键设计原则

1. **平级引擎**：三个新引擎与`ai/`、`tools/`、`voice/`平级
2. **完全独立**：每个引擎有自己的目录、基类、工厂模式
3. **可插拔**：类似`ai/`的设计，支持未来替换实现
4. **直接替换**：直接删除`memory/`，用三个新引擎替代
5. **配置驱动**：每个引擎通过配置文件管理

## 1. 项目背景与目标

### 1.1 背景

CozyChat已完成基础开发，当前使用单一的`memory/`引擎（Qdrant/ChromaDB/Cognee）处理所有记忆相关功能。为实现更强的人格化能力，需要将单一记忆系统拆分为三个专用引擎：

1. **知识引擎（Knowledge）**：使用Cognee，负责知识图谱构建和检索
2. **用户画像引擎（UserProfile）**：使用Memobase，负责用户长期画像管理
3. **会话记忆引擎（ChatMemory）**：使用Mem0，负责会话级短期记忆

### 1.2 目标

- ✅ **删除**：移除现有的`engines/memory/`目录及相关代码
- ✅ **新增**：创建三个平级的新引擎，与`ai/`、`tools/`、`voice/`平级
- ✅ **可插拔**：每个引擎设计为可配置、可替换
- ✅ **质量保证**：确保不破坏现有功能，通过完整测试验证

```python
# app/engines/knowledge/base.py
from abc import ABC, abstractmethod
from typing import Any, Dict, List, Optional

class KnowledgeEngineBase(ABC):
    """知识引擎基类
    
    定义知识引擎的统一接口，类似AIEngineBase的设计。
    """
    
    def __init__(self, config: Dict[str, Any]):
        self.config = config
        self._initialized = False
    
    @abstractmethod
    async def initialize(self) -> bool:
        """初始化引擎（连接SDK）"""
        pass
    
    @abstractmethod
    async def health_check(self) -> bool:
        """健康检查"""
        pass
    
    @abstractmethod
    async def search_knowledge(
        self,
        query: str,
        dataset_names: Optional[List[str]] = None,
        top_k: int = 5,
        **kwargs
    ) -> List[Dict[str, Any]]:
        """搜索知识
        
        Args:
            query: 查询文本
            dataset_names: 数据集名称列表
            top_k: 返回结果数量
            **kwargs: 其他参数
        
        Returns:
            List[Dict]: 知识搜索结果列表
        """
        pass
    
    @abstractmethod
    async def add_knowledge(
        self,
        content: str,
        dataset_name: str,
        metadata: Optional[Dict[str, Any]] = None,
        **kwargs
    ) -> str:
        """添加知识
        
        Args:
            content: 知识内容
            dataset_name: 数据集名称
            metadata: 元数据
            **kwargs: 其他参数
        
        Returns:
            str: 知识ID
        """
        pass
    
    @abstractmethod
    async def close(self):
        """清理资源"""
        pass
```

#### 3.1.2 Cognee实现

```python
# app/engines/knowledge/cognee_engine.py
from typing import Any, Dict, List, Optional
from cognee_sdk import CogneeClient, SearchType
from app.engines.knowledge.base import KnowledgeEngineBase
from app.utils.logger import logger

class CogneeKnowledgeEngine(KnowledgeEngineBase):
    """Cognee知识引擎实现
    
    通过cognee_sdk连接Cognee后端服务，实现知识图谱的构建和检索。
    """
    
    def __init__(self, config: Dict[str, Any]):
        super().__init__(config)
        self.api_url = config.get("api_url", "http://localhost:8000")
        self.api_token = config.get("api_token")
        self.client: Optional[CogneeClient] = None
    
    async def initialize(self) -> bool:
        """初始化Cognee客户端"""
        if self._initialized:
            return True
        
        try:
            self.client = CogneeClient(
                api_url=self.api_url,
                api_token=self.api_token
            )
            # 健康检查
            health = await self.client.health_check()
            self._initialized = health.status == "ok"
            logger.info(f"CogneeKnowledgeEngine initialized: {health.status}")
            return self._initialized
        except Exception as e:
            logger.error(f"Failed to initialize CogneeKnowledgeEngine: {e}", exc_info=True)
            return False
    
    async def health_check(self) -> bool:
        """健康检查"""
        if not self.client:
            return False
        try:
            health = await self.client.health_check()
            return health.status == "ok"
        except Exception:
            return False
    
    async def search_knowledge(
        self,
        query: str,
        dataset_names: Optional[List[str]] = None,
        top_k: int = 5,
        **kwargs
    ) -> List[Dict[str, Any]]:
        """搜索知识"""
        await self.initialize()
        
        try:
            results = await self.client.search(
                query=query,
                datasets=dataset_names or [],
                top_k=top_k,
                search_type=SearchType.INSIGHTS,
                **kwargs
            )
            
            # 转换为标准格式
            return [
                {
                    "content": r.get("text", ""),
                    "score": r.get("score", 0.0),
                    "metadata": r.get("metadata", {}),
                    "dataset": r.get("dataset_name", ""),
                }
                for r in results
            ]
        except Exception as e:
            logger.error(f"CogneeKnowledgeEngine search error: {e}", exc_info=True)
            return []
    
    async def add_knowledge(
        self,
        content: str,
        dataset_name: str,
        metadata: Optional[Dict[str, Any]] = None,
        **kwargs
    ) -> str:
        """添加知识"""
        await self.initialize()
        
        try:
            result = await self.client.add(
                data=content,
                dataset_name=dataset_name,
                metadata=metadata,
                **kwargs
            )
            logger.info(f"Knowledge added to dataset '{dataset_name}': {result.data_id}")
            return result.data_id
        except Exception as e:
            logger.error(f"CogneeKnowledgeEngine add error: {e}", exc_info=True)
            raise
    
    async def close(self):
        """清理资源"""
        if self.client:
            # Cognee SDK可能没有显式close方法
            self.client = None
        self._initialized = False
```

```python
# app/engines/userprofile/memobase_engine.py
from typing import Any, Dict, List, Optional
from memobase import MemoBaseClient, ChatBlob, User
from app.engines.userprofile.base import UserProfileEngineBase
from app.utils.logger import logger

class MemobaseUserProfileEngine(UserProfileEngineBase):
    """Memobase用户画像引擎实现
    
    通过memobase SDK连接Memobase后端服务，实现用户画像的管理。
    """
    
    def __init__(self, config: Dict[str, Any]):
        super().__init__(config)
        self.project_url = config.get("project_url", "http://localhost:8019")
        self.api_key = config.get("api_key", "secret")
        self.client: Optional[MemoBaseClient] = None
    
    async def initialize(self) -> bool:
        """初始化Memobase客户端"""
        if self._initialized:
            return True
        
        try:
            self.client = MemoBaseClient(
                project_url=self.project_url,
                api_key=self.api_key
            )
            # Memobase没有显式health_check，尝试list_users
            await self.client.list_users()
            self._initialized = True
            logger.info(f"MemobaseUserProfileEngine initialized: {self.project_url}")
            return True
        except Exception as e:
            logger.error(f"Failed to initialize MemobaseUserProfileEngine: {e}", exc_info=True)
            return False
    
    async def health_check(self) -> bool:
        """健康检查"""
        if not self.client:
            return False
        try:
            await self.client.list_users()
            return True
        except Exception:
            return False
    
    async def get_profile(
        self,
        user_id: str,
        max_token_size: int = 300,
        **kwargs
    ) -> Dict[str, Any]:
        """获取用户画像"""
        await self.initialize()
        
        try:
            user: User = self.client.get_or_create_user(user_id)
            profile = user.profile(max_token_size=max_token_size, **kwargs)
            
            return {
                "user_id": user_id,
                "profile_text": profile,
                "token_size": len(profile.split()),  # 粗略估计
            }
        except Exception as e:
            logger.error(f"MemobaseUserProfileEngine get_profile error: {e}", exc_info=True)
            return {"user_id": user_id, "profile_text": "", "token_size": 0}
    
    async def update_profile(
        self,
        user_id: str,
        messages: List[Dict[str, str]],
        **kwargs
    ) -> bool:
        """更新用户画像"""
        await self.initialize()
        
        try:
            user: User = self.client.get_or_create_user(user_id)
            blob = ChatBlob(messages=messages)
            user.insert(blob)
            logger.info(f"UserProfile updated for user '{user_id}'")
            return True
        except Exception as e:
            logger.error(f"MemobaseUserProfileEngine update_profile error: {e}", exc_info=True)
            return False
    
    async def close(self):
        """清理资源"""
        if self.client:
            self.client = None
        self._initialized = False
```

```python
        self.api_url = config.get("api_url", "http://localhost:8888")

        self.client: Optional[AsyncMemoryClient] = None
    
    async def initialize(self) -> bool:
        """初始化Mem0客户端"""
        if self._initialized:
            return True
        
        try:
            self.client = AsyncMemoryClient(
                host=self.api_url,
                api_key=self.api_key
            )
            # 健康检查
            health = await self.client.health_check()
            self._initialized = health.status == "ok"
            logger.info(f"Mem0ChatMemoryEngine initialized: {health.status}")
            return self._initialized
        except Exception as e:
            logger.error(f"Failed to initialize Mem0ChatMemoryEngine: {e}", exc_info=True)
            return False
    
    async def health_check(self) -> bool:
        """健康检查"""
        if not self.client:
            return False
        try:
            health = await self.client.health_check()
            return health.status == "ok"
        except Exception:
            return False
    
    async def search_memories(
        self,
        query: str,
        user_id: str,
        session_id: Optional[str] = None,
        top_k: int = 5,
        **kwargs
    ) -> List[Dict[str, Any]]:
        """搜索会话记忆"""
        await self.initialize()
        
        try:
            results = await self.client.search(
                query=query,
                user_id=user_id,
                session_id=session_id,
                limit=top_k,
                **kwargs
            )
            
            # 转换为标准格式
            return [
                {
                    "memory": r.get("memory", ""),
                    "score": r.get("score", 0.0),
                    "created_at": r.get("created_at", ""),
                    "updated_at": r.get("updated_at", ""),
                }
                for r in results
            ]
        except Exception as e:
            logger.error(f"Mem0ChatMemoryEngine search error: {e}", exc_info=True)
            return []
    
    async def add_memory(
        self,
        user_id: str,
        session_id: str,
        messages: List[Dict[str, str]],
        **kwargs
    ) -> str:
        """添加会话记忆"""
        await self.initialize()
        
        try:
            result = await self.client.add(
                messages=messages,
                user_id=user_id,
                session_id=session_id,
                **kwargs
            )
            logger.info(f"Memory added for user '{user_id}', session '{session_id}': {result.id}")
            return result.id
        except Exception as e:
            logger.error(f"Mem0ChatMemoryEngine add error: {e}", exc_info=True)
            raise
    
    async def close(self):
        """清理资源"""
        if self.client:
            # Mem0 SDK可能有close方法
            await self.client.close() if hasattr(self.client, 'close') else None
            self.client = None
        self._initialized = False
```

### 3.4 ContextService集成

修改现有的`ContextService`，集成三大新引擎：

```python
# app/services/context/context_service.py（修改）
from typing import Dict, Any, List, Optional
import asyncio
from app.engines.knowledge.factory import KnowledgeEngineFactory
from app.engines.userprofile.factory import UserProfileEngineFactory
from app.engines.chatmemory.factory import ChatMemoryEngineFactory
from app.engines.knowledge.base import KnowledgeEngineBase
from app.engines.userprofile.base import UserProfileEngineBase
from app.engines.chatmemory.base import ChatMemoryEngineBase
from app.config.config import settings
from app.utils.logger import logger

class ContextService:
    """上下文服务（修改后）
    
    集成三大个性化引擎，替换旧的MemoryManager。
    """
    
    def __init__(self):
        # 通过工厂创建三大引擎（可配置可插拔）
        self.knowledge_engine: KnowledgeEngineBase = KnowledgeEngineFactory.create_engine(
            provider=settings.knowledge_engine_provider,  # 例如 "cognee"
            config=settings.knowledge_engine_config
        )
        
        self.userprofile_engine: UserProfileEngineBase = UserProfileEngineFactory.create_engine(
            provider=settings.userprofile_engine_provider,  # 例如 "memobase"
            config=settings.userprofile_engine_config
        )
        
        self.chatmemory_engine: ChatMemoryEngineBase = ChatMemoryEngineFactory.create_engine(
            provider=settings.chatmemory_engine_provider,  # 例如 "mem0"
            config=settings.chatmemory_engine_config
        )
        
        logger.info("ContextService initialized with 3 personalization engines")
    
    async def initialize(self) -> bool:
        """初始化所有引擎"""
        results = await asyncio.gather(
            self.knowledge_engine.initialize(),
            self.userprofile_engine.initialize(),
            self.chatmemory_engine.initialize(),
            return_exceptions=True
        )
        
        if any(isinstance(r, Exception) for r in results):
            logger.error(f"One or more engines failed to initialize: {results}")
            return False
        
        return all(results)
    
    async def build_personalized_context(
        self,
        user_id: str,
        session_id: str,
        query: str,
        knowledge_datasets: Optional[List[str]] = None,
        max_profile_tokens: int = 300,
        max_memory_results: int = 5,
        max_knowledge_results: int = 2
    ) -> Dict[str, Any]:
        """构建个性化上下文
        
        并行调用三大引擎，获取知识、画像、记忆。
        
        Args:
            user_id: 用户ID
            session_id: 会话ID
            query: 当前查询
            knowledge_datasets: 知识数据集列表
            max_profile_tokens: 用户画像最大token数
            max_memory_results: 记忆结果数量
            max_knowledge_results: 知识结果数量
        
        Returns:
            Dict: 包含knowledge、profile、memories的上下文
        """
        knowledge_datasets = knowledge_datasets or []
        
        # 并行获取三类数据
        knowledge_task = self.knowledge_engine.search_knowledge(
            query=query,
            dataset_names=knowledge_datasets,
            top_k=max_knowledge_results
        )
        
        profile_task = self.userprofile_engine.get_profile(
            user_id=user_id,
            max_token_size=max_profile_tokens
        )
        
        memory_task = self.chatmemory_engine.search_memories(
            query=query,
            user_id=user_id,
            session_id=session_id,
            top_k=max_memory_results
        )
        
        knowledge, profile, memories = await asyncio.gather(
            knowledge_task, profile_task, memory_task, return_exceptions=True
        )
        
        # 处理异常
        if isinstance(knowledge, Exception):
            logger.error(f"Knowledge engine error: {knowledge}")
            knowledge = []
        if isinstance(profile, Exception):
            logger.error(f"Profile engine error: {profile}")
            profile = {}
        if isinstance(memories, Exception):
            logger.error(f"Memory engine error: {memories}")
            memories = []
        
        return {
            "knowledge": knowledge,
            "profile": profile,
            "memories": memories,
            "debug": {
                "knowledge_count": len(knowledge) if not isinstance(knowledge, Exception) else 0,
                "profile_tokens": profile.get("token_size", 0) if profile else 0,
                "memory_count": len(memories) if not isinstance(memories, Exception) else 0,
            }
        }
    
    async def update_user_data(
        self,
        user_id: str,
        session_id: str,
        messages: List[Dict[str, str]]
    ) -> Dict[str, bool]:
        """更新用户数据（画像和记忆）
        
        Args:
            user_id: 用户ID
            session_id: 会话ID
            messages: 会话消息列表
        
        Returns:
            Dict: 更新状态
        """
        # 并行更新画像和记忆
        profile_task = self.userprofile_engine.update_profile(
            user_id=user_id,
            messages=messages
        )
        
        memory_task = self.chatmemory_engine.add_memory(
            user_id=user_id,
            session_id=session_id,
            messages=messages
        )
        
        profile_result, memory_result = await asyncio.gather(
            profile_task, memory_task, return_exceptions=True
        )
        
        return {
            "profile_updated": not isinstance(profile_result, Exception) and profile_result,
            "memory_added": not isinstance(memory_result, Exception),
        }
    
    async def close(self):
        """清理所有引擎资源"""
        await asyncio.gather(
            self.knowledge_engine.close(),
            self.userprofile_engine.close(),
            self.chatmemory_engine.close(),
            return_exceptions=True
        )
        logger.info("ContextService closed")
```

## 7. 总结

### 7.1 核心变更

| 方面 | 现有架构 | 重构后架构 |
|------|----------|------------|
| **引擎数量** | 1个（memory/） | 3个（knowledge/、userprofile/、chatmemory/） |
