## 3. 修复策略总结

### 3.1 按钮查找改进

**问题**：Ant Design按钮可能没有标准的role或name

**解决方案**：
```typescript
// 使用queryAllByRole查找所有按钮，然后通过文本内容匹配
const buttons = screen.queryAllByRole('button');
const button = buttons.find(btn => btn.textContent?.includes('注册')) || buttons[0];
```

### 3.2 组件Props修复

**问题**：测试使用的props与组件实际props不匹配

**解决方案**：
- 查看组件实际定义
- 使用正确的props
- 移除不存在的props

### 3.3 Mock处理完善

**问题**：Mock不完整或API不匹配

**解决方案**：
- 查看组件实际使用的API
- 添加所有必需的Mock（useQuery、useMutation、useQueryClient等）
- 使用正确的Mock API

### 3.4 异步处理改进

**问题**：选项或内容需要时间渲染

**解决方案**：
- 使用waitFor等待
- 增加超时时间
- 提供备选查找方式
