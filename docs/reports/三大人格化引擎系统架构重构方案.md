## 📌 重要说明

### 核心理解（最终正确版本）

**现有架构**（engines/下的平级引擎）：
```
engines/
├── ai/        # AI引擎（保持不变）
├── memory/    # 记忆引擎 ← ❌ 删除整个目录
├── tools/     # 工具引擎（保持不变）
└── voice/     # 语音引擎（保持不变）
```

**重构后架构**（三个平级的新引擎替换memory/）：
```
engines/
├── ai/           # ✅ 保持不变
├── knowledge/    # ✅ 新增：知识引擎（Cognee），替换memory/
├── userprofile/  # ✅ 新增：用户画像引擎（Memobase），替换memory/
├── chatmemory/   # ✅ 新增：会话记忆引擎（Mem0），替换memory/
├── tools/        # ✅ 保持不变
└── voice/        # ✅ 保持不变
```

### 关键设计原则

1. **平级引擎**：三个新引擎与`ai/`、`tools/`、`voice/`平级
2. **完全独立**：每个引擎有自己的目录、基类、工厂模式
3. **可插拔**：类似`ai/`的设计，支持未来替换实现
4. **直接替换**：直接删除`memory/`，用三个新引擎替代
5. **配置驱动**：每个引擎通过配置文件管理

## 1. 项目背景与目标

### 1.1 背景

CozyChat已完成基础开发，当前使用单一的`memory/`引擎（Qdrant/ChromaDB/Cognee）处理所有记忆相关功能。为实现更强的人格化能力，需要将单一记忆系统拆分为三个专用引擎：

1. **知识引擎（Knowledge）**：使用Cognee，负责知识图谱构建和检索
2. **用户画像引擎（UserProfile）**：使用Memobase，负责用户长期画像管理
3. **会话记忆引擎（ChatMemory）**：使用Mem0，负责会话级短期记忆

### 1.2 目标

- ✅ **删除**：移除现有的`engines/memory/`目录及相关代码
- ✅ **新增**：创建三个平级的新引擎，与`ai/`、`tools/`、`voice/`平级
- ✅ **可插拔**：每个引擎设计为可配置、可替换
- ✅ **质量保证**：确保不破坏现有功能，通过完整测试验证

```python
from abc import ABC, abstractmethod
from typing import Any, Dict, List, Optional

class KnowledgeEngineBase(ABC):
    """知识引擎基类
    
    定义知识引擎的统一接口，类似AIEngineBase的设计。
    """
    
    def __init__(self, config: Dict[str, Any]):
        self.config = config
        self._initialized = False
    
    @abstractmethod
    async def initialize(self) -> bool:
        """初始化引擎（连接SDK）"""
        pass
    
    @abstractmethod
    async def health_check(self) -> bool:
        """健康检查"""
        pass
    
    @abstractmethod
    async def search_knowledge(
        self,
        query: str,
        dataset_names: Optional[List[str]] = None,
        top_k: int = 5,
        **kwargs
    ) -> List[Dict[str, Any]]:
        """搜索知识
        
        Args:
            query: 查询文本
            dataset_names: 数据集名称列表
            top_k: 返回结果数量
            **kwargs: 其他参数
        
        Returns:
            List[Dict]: 知识搜索结果列表
        """
        pass
    
    @abstractmethod
    async def add_knowledge(
        self,
        content: str,
        dataset_name: str,
        metadata: Optional[Dict[str, Any]] = None,
        **kwargs
    ) -> str:
        """添加知识
        
        Args:
            content: 知识内容
            dataset_name: 数据集名称
            metadata: 元数据
            **kwargs: 其他参数
        
        Returns:
            str: 知识ID
        """
        pass
    
    @abstractmethod
    async def close(self):
        """清理资源"""
        pass
```

#### 3.1.2 Cognee实现

```python
# app/engines/knowledge/cognee_engine.py
from typing import Any, Dict, List, Optional
from cognee_sdk import CogneeClient, SearchType
from app.engines.knowledge.base import KnowledgeEngineBase
from app.utils.logger import logger

class CogneeKnowledgeEngine(KnowledgeEngineBase):
    """Cognee知识引擎实现
    
    通过cognee_sdk连接Cognee后端服务，实现知识图谱的构建和检索。
    """
    
    def __init__(self, config: Dict[str, Any]):
        super().__init__(config)
        self.api_url = config.get("api_url", "http://localhost:8000")
        self.api_token = config.get("api_token")
        self.client: Optional[CogneeClient] = None
    
    async def initialize(self) -> bool:
        """初始化Cognee客户端"""
        if self._initialized:
            return True
        
        try:
            self.client = CogneeClient(
                api_url=self.api_url,
                api_token=self.api_token
            )
            # 健康检查
            health = await self.client.health_check()
            self._initialized = health.status == "ok"
            logger.info(f"CogneeKnowledgeEngine initialized: {health.status}")
            return self._initialized
        except Exception as e:
            logger.error(f"Failed to initialize CogneeKnowledgeEngine: {e}", exc_info=True)
            return False
    
    async def health_check(self) -> bool:
        """健康检查"""
        if not self.client:
            return False
        try:
            health = await self.client.health_check()
            return health.status == "ok"
        except Exception:
            return False
    
    async def search_knowledge(
        self,
        query: str,
        dataset_names: Optional[List[str]] = None,
        top_k: int = 5,
        **kwargs
    ) -> List[Dict[str, Any]]:
        """搜索知识"""
        await self.initialize()
        
        try:
            results = await self.client.search(
                query=query,
                datasets=dataset_names or [],
                top_k=top_k,
                search_type=SearchType.INSIGHTS,
                **kwargs
            )
            
            # 转换为标准格式
            return [
                {
                    "content": r.get("text", ""),
                    "score": r.get("score", 0.0),
                    "metadata": r.get("metadata", {}),
                    "dataset": r.get("dataset_name", ""),
                }
                for r in results
            ]
        except Exception as e:
            logger.error(f"CogneeKnowledgeEngine search error: {e}", exc_info=True)
            return []
    
    async def add_knowledge(
        self,
        content: str,
        dataset_name: str,
        metadata: Optional[Dict[str, Any]] = None,
        **kwargs
    ) -> str:
        """添加知识"""
        await self.initialize()
        
        try:
            result = await self.client.add(
                data=content,
                dataset_name=dataset_name,
                metadata=metadata,
                **kwargs
            )
            logger.info(f"Knowledge added to dataset '{dataset_name}': {result.data_id}")
            return result.data_id
        except Exception as e:
            logger.error(f"CogneeKnowledgeEngine add error: {e}", exc_info=True)
            raise
    
    async def close(self):
        """清理资源"""
        if self.client:
            # Cognee SDK可能没有显式close方法
            self.client = None
        self._initialized = False
```

```python
# app/engines/userprofile/memobase_engine.py
from typing import Any, Dict, List, Optional
from memobase import MemoBaseClient, ChatBlob, User
from app.engines.userprofile.base import UserProfileEngineBase
from app.utils.logger import logger

class MemobaseUserProfileEngine(UserProfileEngineBase):
    """Memobase用户画像引擎实现
    
    通过memobase SDK连接Memobase后端服务，实现用户画像的管理。
    """
    
    def __init__(self, config: Dict[str, Any]):
        super().__init__(config)
        self.project_url = config.get("project_url", "http://localhost:8019")
        self.api_key = config.get("api_key", "secret")
        self.client: Optional[MemoBaseClient] = None
    
    async def initialize(self) -> bool:
        """初始化Memobase客户端"""
        if self._initialized:
            return True
        
        try:
            self.client = MemoBaseClient(
                project_url=self.project_url,
                api_key=self.api_key
            )
            # Memobase没有显式health_check，尝试list_users
            await self.client.list_users()
            self._initialized = True
            logger.info(f"MemobaseUserProfileEngine initialized: {self.project_url}")
            return True
        except Exception as e:
            logger.error(f"Failed to initialize MemobaseUserProfileEngine: {e}", exc_info=True)
            return False
    
    async def health_check(self) -> bool:
        """健康检查"""
        if not self.client:
            return False
        try:
            await self.client.list_users()
            return True
        except Exception:
            return False
    
    async def get_profile(
        self,
        user_id: str,
        max_token_size: int = 300,
        **kwargs
    ) -> Dict[str, Any]:
        """获取用户画像"""
        await self.initialize()
        
        try:
            user: User = self.client.get_or_create_user(user_id)
            profile = user.profile(max_token_size=max_token_size, **kwargs)
            
            return {
                "user_id": user_id,
                "profile_text": profile,
                "token_size": len(profile.split()),  # 粗略估计
            }
        except Exception as e:
            logger.error(f"MemobaseUserProfileEngine get_profile error: {e}", exc_info=True)
            return {"user_id": user_id, "profile_text": "", "token_size": 0}
    
    async def update_profile(
        self,
        user_id: str,
        messages: List[Dict[str, str]],
        **kwargs
    ) -> bool:
        """更新用户画像"""
        await self.initialize()
        
        try:
            user: User = self.client.get_or_create_user(user_id)
            blob = ChatBlob(messages=messages)
            user.insert(blob)
            logger.info(f"UserProfile updated for user '{user_id}'")
            return True
        except Exception as e:
            logger.error(f"MemobaseUserProfileEngine update_profile error: {e}", exc_info=True)
            return False
    
    async def close(self):
        """清理资源"""
        if self.client:
            self.client = None
        self._initialized = False
```

## 4. 性能优化策略

### 4.1 核心性能考虑

由于三大引擎都是通过SDK连接远程服务器，网络延迟是主要性能瓶颈。我们需要从多个层面进行优化：

| 优化层面 | 策略 | 预期收益 |
|---------|------|---------|
| **并发层** | 异步调用 + 并行请求 | 延迟降低60-70% |
| **缓存层** | 多级缓存（本地+Redis） | QPS提升5-10倍 |
| **请求层** | 超时控制 + 降级策略 | 可用性提升至99.9% |
| **数据层** | 结果预取 + 批量操作 | 吞吐量提升2-3倍 |

### 4.2 异步并行策略

#### 4.2.1 并行请求设计

**核心原理**：三大引擎查询互不依赖，使用`asyncio.gather()`并行调用。

```python
# app/services/context/context_service.py
import asyncio
from typing import Dict, Any, List, Optional

class ContextService:
    async def build_personalized_context(
        self,
        user_id: str,
        session_id: str,
        query: str,
        **kwargs
    ) -> Dict[str, Any]:
        """并行调用三大引擎，最小化总延迟"""
        
        # 创建并行任务
        tasks = {
            "knowledge": self._fetch_knowledge(query, **kwargs),
            "profile": self._fetch_profile(user_id, **kwargs),
            "memories": self._fetch_memories(user_id, session_id, query, **kwargs),
        }
        
        # 并行执行（使用超时控制）
        results = {}
        try:
            # 并行执行，最长等待1秒
            done, pending = await asyncio.wait(
                [asyncio.create_task(task) for task in tasks.values()],
                timeout=1.0,
                return_when=asyncio.ALL_COMPLETED
            )
            
            # 收集成功的结果
            task_map = dict(zip(tasks.keys(), tasks.values()))
            for task in done:
                for name, original_task in task_map.items():
                    if task.get_coro() == original_task.get_coro():
                        try:
                            results[name] = task.result()
                        except Exception as e:
                            logger.error(f"Task {name} failed: {e}")
                            results[name] = self._get_empty_result(name)
            
            # 取消未完成的任务
            for task in pending:
                task.cancel()
                for name in tasks.keys():
                    if name not in results:
                        logger.warning(f"Task {name} timeout")
                        results[name] = self._get_empty_result(name)
        
        except Exception as e:
            logger.error(f"Parallel execution failed: {e}", exc_info=True)
            # 降级：返回空结果
            results = {name: self._get_empty_result(name) for name in tasks.keys()}
        
        return results
    
    def _get_empty_result(self, engine_name: str) -> Any:
        """获取引擎的空结果"""
        if engine_name == "knowledge":
            return []
        elif engine_name == "profile":
            return {"user_id": "", "profile_text": "", "token_size": 0}
        elif engine_name == "memories":
            return []
        return None
```

**性能对比**：

| 调用方式 | 单次延迟 | 总延迟 | 改善 |
|---------|---------|-------|------|
| **串行调用** | Knowledge: 200ms<br>Profile: 300ms<br>Memory: 250ms | 750ms | - |
| **并行调用** | max(200, 300, 250) | 300ms | **↓ 60%** |
| **并行+超时** | max(200, 300, 250) + 控制 | <350ms | **↓ 53%** |

#### 4.3.2 缓存实现

```python
# app/utils/cache/multi_level_cache.py
from typing import Any, Optional, Callable
from functools import lru_cache
import hashlib
import json
import asyncio
from app.utils.redis_client import get_redis_client
from app.utils.logger import logger

class MultiLevelCache:
    """多级缓存管理器"""
    
    def __init__(
        self,
        l1_maxsize: int = 1000,
        l1_ttl: int = 300,      # 5分钟
        l2_ttl: int = 1800,     # 30分钟
    ):
        self.l1_maxsize = l1_maxsize
        self.l1_ttl = l1_ttl
        self.l2_ttl = l2_ttl
        self.redis_client = None
        self._l1_cache = {}  # {cache_key: (value, expire_time)}
        self._lock = asyncio.Lock()
    
    async def initialize(self):
        """初始化Redis连接"""
        self.redis_client = await get_redis_client()
    
    def _generate_cache_key(self, prefix: str, **kwargs) -> str:
        """生成缓存键"""
        data = json.dumps(kwargs, sort_keys=True)
        hash_value = hashlib.md5(data.encode()).hexdigest()
        return f"{prefix}:{hash_value}"
    
    async def get(
        self,
        cache_key: str,
        fetch_func: Callable,
        *args,
        **kwargs
    ) -> Any:
        """获取缓存（L1 -> L2 -> 远程）"""
        
        # L1: 内存缓存
        l1_result = await self._get_from_l1(cache_key)
        if l1_result is not None:
            logger.debug(f"Cache L1 hit: {cache_key}")
            return l1_result
        
        # L2: Redis缓存
        l2_result = await self._get_from_l2(cache_key)
        if l2_result is not None:
            logger.debug(f"Cache L2 hit: {cache_key}")
            # 回写L1
            await self._set_to_l1(cache_key, l2_result)
            return l2_result
        
        # L3: 远程调用
        logger.debug(f"Cache miss, fetching from remote: {cache_key}")
        result = await fetch_func(*args, **kwargs)
        
        # 写入缓存
        await self._set_to_l1(cache_key, result)
        await self._set_to_l2(cache_key, result)
        
        return result
    
    async def _get_from_l1(self, cache_key: str) -> Optional[Any]:
        """从L1获取"""
        import time
        async with self._lock:
            if cache_key in self._l1_cache:
                value, expire_time = self._l1_cache[cache_key]
                if time.time() < expire_time:
                    return value
                else:
                    del self._l1_cache[cache_key]
        return None
    
    async def _set_to_l1(self, cache_key: str, value: Any):
        """写入L1"""
        import time
        async with self._lock:
            # LRU淘汰
            if len(self._l1_cache) >= self.l1_maxsize:
                # 删除最旧的
                oldest_key = min(self._l1_cache.keys(), key=lambda k: self._l1_cache[k][1])
                del self._l1_cache[oldest_key]
            
            self._l1_cache[cache_key] = (value, time.time() + self.l1_ttl)
    
    async def _get_from_l2(self, cache_key: str) -> Optional[Any]:
        """从L2（Redis）获取"""
        if not self.redis_client:
            return None
        try:
            result = await self.redis_client.get(cache_key)
            if result:
                return json.loads(result)
        except Exception as e:
            logger.error(f"Redis get error: {e}")
        return None
    
    async def _set_to_l2(self, cache_key: str, value: Any):
        """写入L2（Redis）"""
        if not self.redis_client:
            return
        try:
            await self.redis_client.setex(
                cache_key,
                self.l2_ttl,
                json.dumps(value)
            )
        except Exception as e:
            logger.error(f"Redis set error: {e}")
    
    async def invalidate(self, cache_key: str):
        """失效缓存"""
        async with self._lock:
            if cache_key in self._l1_cache:
                del self._l1_cache[cache_key]
        
        if self.redis_client:
            try:
                await self.redis_client.delete(cache_key)
            except Exception as e:
                logger.error(f"Redis delete error: {e}")


# 全局缓存实例
_global_cache: Optional[MultiLevelCache] = None

async def get_global_cache() -> MultiLevelCache:
    """获取全局缓存实例"""
    global _global_cache
    if _global_cache is None:
        _global_cache = MultiLevelCache()
        await _global_cache.initialize()
    return _global_cache
```

```python
        # ... 其他初始化 ...
```

```python
# app/utils/performance_monitor.py
import time
from typing import Dict, Any
from app.utils.logger import logger

class PerformanceMonitor:
    """性能监控"""
    
    def __init__(self):
        self.metrics = {
            "knowledge_search": {"count": 0, "total_time": 0, "cache_hits": 0},
            "profile_get": {"count": 0, "total_time": 0, "cache_hits": 0},
            "memory_search": {"count": 0, "total_time": 0, "cache_hits": 0},
        }
    
    async def track(self, operation: str, func, *args, **kwargs):
        """跟踪操作性能"""
        start = time.time()
        try:
            result = await func(*args, **kwargs)
            duration = time.time() - start
            
            self.metrics[operation]["count"] += 1
            self.metrics[operation]["total_time"] += duration
            
            if duration > 0.5:  # 超过500ms警告
                logger.warning(f"{operation} took {duration:.2f}s")
            
            return result
        except Exception as e:
            logger.error(f"{operation} failed: {e}")
            raise
    
    def get_stats(self) -> Dict[str, Any]:
        """获取统计信息"""
        stats = {}
        for operation, metrics in self.metrics.items():
            if metrics["count"] > 0:
                avg_time = metrics["total_time"] / metrics["count"]
                cache_hit_rate = metrics["cache_hits"] / metrics["count"] * 100
                stats[operation] = {
                    "count": metrics["count"],
                    "avg_time_ms": avg_time * 1000,
                    "cache_hit_rate": f"{cache_hit_rate:.1f}%",
                }
        return stats
```

```python
# app/services/context/intent_analyzer.py
from typing import Dict, List
from enum import Enum

class QueryIntent(Enum):
    """查询意图"""
    CHITCHAT = "chitchat"           # 闲聊
    KNOWLEDGE_QUERY = "knowledge"   # 知识查询
    TASK_EXECUTION = "task"         # 任务执行
    EMOTIONAL_SUPPORT = "emotional" # 情感支持
    INFORMATION_QUERY = "info"      # 信息查询
    LEARNING = "learning"           # 学习辅导

class IntentAnalyzer:
    """意图分析器"""
    
    @staticmethod
    def analyze_intent(query: str, context: Dict) -> QueryIntent:
        """分析查询意图"""
        # 简化版：基于关键词匹配（实际可用LLM分类）
        query_lower = query.lower()
        
        # 知识查询关键词
        knowledge_keywords = ["什么是", "如何", "为什么", "解释", "原理", "定义"]
        if any(kw in query_lower for kw in knowledge_keywords):
            return QueryIntent.KNOWLEDGE_QUERY
        
        # 任务执行关键词
        task_keywords = ["帮我", "请", "完成", "执行", "做"]
        if any(kw in query_lower for kw in task_keywords):
            return QueryIntent.TASK_EXECUTION
        
        # 情感支持关键词
        emotional_keywords = ["难过", "开心", "焦虑", "压力", "感觉"]
        if any(kw in query_lower for kw in emotional_keywords):
            return QueryIntent.EMOTIONAL_SUPPORT
        
        # 学习辅导关键词
        learning_keywords = ["学习", "教", "练习", "理解", "掌握"]
        if any(kw in query_lower for kw in learning_keywords):
            return QueryIntent.LEARNING
        
        # 默认：闲聊
        return QueryIntent.CHITCHAT
    
    @staticmethod
    def get_engine_config(intent: QueryIntent) -> Dict[str, Dict]:
        """根据意图获取引擎配置"""
        configs = {
            QueryIntent.CHITCHAT: {
                "knowledge": {"enabled": False},
                "userprofile": {"enabled": True, "max_tokens": 300},
                "chatmemory": {"enabled": True, "top_k": 5},
            },
            QueryIntent.KNOWLEDGE_QUERY: {
                "knowledge": {"enabled": True, "top_k": 3},
                "userprofile": {"enabled": True, "max_tokens": 200},
                "chatmemory": {"enabled": True, "top_k": 3},
            },
            QueryIntent.TASK_EXECUTION: {
                "knowledge": {"enabled": True, "top_k": 2},
                "userprofile": {"enabled": True, "max_tokens": 200},
                "chatmemory": {"enabled": True, "top_k": 5},

                "knowledge": {"enabled": False},
                "userprofile": {"enabled": True, "max_tokens": 400},
                "chatmemory": {"enabled": True, "top_k": 8},
            },
            QueryIntent.INFORMATION_QUERY: {
                "knowledge": {"enabled": True, "top_k": 5},
                "userprofile": {"enabled": False},
                "chatmemory": {"enabled": True, "top_k": 2},
            },
            QueryIntent.LEARNING: {
                "knowledge": {"enabled": True, "top_k": 3},
                "userprofile": {"enabled": True, "max_tokens": 300},
                "chatmemory": {"enabled": True, "top_k": 4},
            },
        }
        return configs.get(intent, configs[QueryIntent.CHITCHAT])
```

### 5.3 智能上下文构建

```python
# app/services/context/context_service.py（增强版）
from app.services.context.intent_analyzer import IntentAnalyzer, QueryIntent

class ContextService:
    async def build_personalized_context(
        self,
        user_id: str,
        session_id: str,
        query: str,
        auto_detect_intent: bool = True,
        **kwargs
    ) -> Dict[str, Any]:
        """智能构建个性化上下文
        
        根据查询意图动态决定使用哪些引擎，优化性能和相关性。
        """
        
        # 1. 分析意图
        intent = IntentAnalyzer.analyze_intent(query, context={})
        logger.info(f"Detected intent: {intent.value}")
        
        # 2. 获取引擎配置
        engine_config = IntentAnalyzer.get_engine_config(intent)
        
        # 3. 条件性调用引擎（只调用需要的）
        tasks = {}
        
        if engine_config["knowledge"]["enabled"]:
            tasks["knowledge"] = self._fetch_knowledge(
                query=query,
                top_k=engine_config["knowledge"].get("top_k", 3),
                **kwargs
            )
        
        if engine_config["userprofile"]["enabled"]:
            tasks["profile"] = self._fetch_profile(
                user_id=user_id,
                max_tokens=engine_config["userprofile"].get("max_tokens", 300),
                **kwargs
            )
        
        if engine_config["chatmemory"]["enabled"]:
            tasks["memories"] = self._fetch_memories(
                user_id=user_id,
                session_id=session_id,
                query=query,
                top_k=engine_config["chatmemory"].get("top_k", 5),
                **kwargs
            )
        
        # 4. 并行执行启用的任务
        if not tasks:
            # 所有引擎都未启用，返回空结果
            return {
                "knowledge": [],
                "profile": {},
                "memories": [],
                "intent": intent.value,
                "debug": {"enabled_engines": []}
            }
        
        results = {}
        try:
            done, pending = await asyncio.wait(
                [asyncio.create_task(task) for task in tasks.values()],
                timeout=1.0,
                return_when=asyncio.ALL_COMPLETED
            )
            
            # 收集结果
            for name, task in zip(tasks.keys(), done):
                try:
                    results[name] = await task
                except Exception as e:
                    logger.error(f"Engine {name} failed: {e}")
                    results[name] = self._get_empty_result(name)
            
            # 取消未完成的
            for task in pending:
                task.cancel()
        
        except Exception as e:
            logger.error(f"Context building failed: {e}", exc_info=True)
            results = {name: self._get_empty_result(name) for name in tasks.keys()}
        
        # 5. 填充未启用的引擎结果
        for engine_name in ["knowledge", "profile", "memories"]:
            if engine_name not in results:
                results[engine_name] = self._get_empty_result(engine_name)
        
        # 6. 添加元数据
        results["intent"] = intent.value
        results["debug"] = {
            "enabled_engines": list(tasks.keys()),
            "engine_config": engine_config,
        }
        
        return results
```

```python
class ContextBuilder:
    def _adjust_weights_dynamically(
        self,
        intent: QueryIntent,
        user_history: Dict,
        query_complexity: float
    ) -> Dict[str, float]:
        """动态调整引擎权重"""
        
        # 获取默认权重
        weights = self._get_default_weights(intent)
        
        # 根据用户历史调整
        if user_history.get("is_new_user"):
            # 新用户：降低画像权重，增加知识权重
            weights["userprofile"] *= 0.5
            weights["knowledge"] *= 1.5
        
        if user_history.get("recent_conversations") < 3:
            # 对话少：降低记忆权重
            weights["chatmemory"] *= 0.7
        
        # 根据查询复杂度调整
        if query_complexity > 0.8:
            # 复杂查询：增加知识权重
            weights["knowledge"] *= 1.3
        
        # 归一化
        total = sum(weights.values())
        if total > 0:
            weights = {k: v / total for k, v in weights.items()}
        
        return weights
```

```python
    await context_service.close()
```

## 9. 总结

### 9.1 核心变更

| 方面 | 现有架构 | 重构后架构 |
|------|----------|------------|
| **引擎数量** | 1个（memory/） | 3个（knowledge/、userprofile/、chatmemory/） |
| **引擎位置** | `engines/memory/` | `engines/knowledge/`、`engines/userprofile/`、`engines/chatmemory/`（平级） |
| **后端服务** | Qdrant/ChromaDB | Cognee、Memobase、Mem0（通过SDK连接） |
| **管理方式** | MemoryManager | ContextService集成三大引擎 |
| **可插拔性** | 不支持 | 支持（工厂模式） |
| **配置** | 单一memory配置 | 三大引擎独立配置 |

### 9.2 优势

1. **功能专业化**：三个引擎各司其职，知识、画像、记忆分离
2. **可扩展性**：工厂模式支持未来替换实现
3. **性能优化**：并行调用三大引擎，减少总延迟
4. **架构清晰**：与ai/、tools/、voice/平级，结构统一
