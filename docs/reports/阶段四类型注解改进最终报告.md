## 3. 剩余工作

### 3.1 仍需改进的类型（约29个）

#### 3.1.1 SQLAlchemy查询中的类型问题（约15个）

**位置**：
- `app/core/user/stats.py` - SQLAlchemy查询条件
- `app/core/context/builder.py` - SQLAlchemy查询
- 其他查询文件

**问题**：
```python
User.status == "active"  # type: ignore[arg-type]
```

**说明**：
- 这是SQLAlchemy的正常用法
- 类型检查器无法理解SQLAlchemy的查询语法
- 需要保留 `type: ignore`，但可以添加更详细的注释

**改进方案**：
- 添加详细注释说明为什么需要 `type: ignore`
- 对于可以改进的查询，使用更精确的类型定义

#### 3.1.2 ORM属性赋值（约8个）

**位置**：
- `app/core/user/stats.py` - 用户统计更新
- `app/core/user/manager.py` - 用户状态更新
- 其他ORM赋值

**问题**：
```python
user.total_sessions = value  # type: ignore[assignment]
```

**改进方案**：
- 使用 `cast()` 明确类型
- 已部分改进，继续完善

#### 3.1.3 动态属性访问（约4个）

**位置**：
- `app/api/v1/models.py` - 动态引擎属性
- `app/engines/ai/openai_engine.py` - 动态模型列表
- 其他动态属性

**问题**：
```python

```

**改进方案**：
- 使用 `hasattr()` 检查

#### 3.1.4 其他复杂类型问题（约2个）

**改进方案**：

**应对**：
