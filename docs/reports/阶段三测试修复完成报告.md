## 测试执行建议

为了避免hang死，建议：

1. **使用--no-cov** - 禁用覆盖率检查，加快测试速度
2. **使用-x** - 遇到第一个失败就停止
3. **使用--maxfail=N** - 最多失败N个测试后停止
4. **分模块运行** - 不要一次性运行所有测试

```bash
# 快速验证单个测试
python -m pytest tests/test_services/test_message_service.py -v --tb=short --no-cov

# 运行特定模块
python -m pytest tests/test_services/test_chat/ -v --tb=line --no-cov

# 运行所有服务测试（最多失败5个）
python -m pytest tests/test_services/ -v --tb=line --no-cov --maxfail=5
```
