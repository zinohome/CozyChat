# 腾讯语音引擎集成指南

## 🎯 集成概述

腾讯语音引擎已经完全集成到CozyChat应用中，您只需要**修改配置文件**即可使用，无需修改代码。

**工作原理**：
- ✅ API层已经使用工厂模式
- ✅ 根据配置自动选择引擎
- ✅ 支持全局配置和人格配置
- ✅ 人格配置可覆盖全局配置

## 📋 快速开始（3步）

### 步骤1：确认环境变量

确保 `.env` 文件中已配置腾讯云凭证：

```bash
# 腾讯云凭证
TENCENT_APP_ID=1318633704
TENCENT_SECRET_ID=AKIDxxxxxxxxxxxxx
TENCENT_SECRET_KEY=xxxxxxxxxxxxxxxx
```

### 步骤2：配置使用腾讯引擎

#### 选项A：全局配置（所有人格默认使用）

编辑全局配置文件：

**STT配置** - `backend/config/voice/stt.yaml`：
```yaml
engines:
  stt:
    default: "tencent"  # ← 改为 tencent
    
    tencent:
      provider: "tencent"
      model: "16k_zh"  # 16k_zh: 中文，16k_en: 英语
      language: "zh-CN"
      
      # 识别模式
      recognition_mode: "auto"  # flash: 一句话，realtime: 实时，auto: 自动
      realtime_threshold: 1048576  # 1MB
      
      # 过滤选项
      filter_modal: 1  # 过滤语气词
      filter_punc: 1   # 过滤标点
      filter_dirty: 1  # 过滤脏词
```

**TTS配置** - `backend/config/voice/tts.yaml`：
```yaml
engines:
  tts:
    default: "tencent"  # ← 改为 tencent
    
    tencent:
      provider: "tencent"
      
      # AI大模型音色（推荐）
      voice: "ai_female"     # ai_female, ai_male, ai_narrator 等
      voice_type: 101001     # 101001-101005
      
      # 或使用基础音色
      # voice: "female"      # female, male, mature_male 等
      # voice_type: 0        # 0-5
      
      # 合成参数
      speed: 1.0           # 语速（0.25-4.0，OpenAI格式）
      volume: 0            # 音量（-10到10）
      codec: "mp3"         # mp3 或 pcm
      sample_rate: 16000   # 8000 或 16000
      
      # 合成模式
      tts_mode: "http"     # http 或 websocket
```

#### 选项B：人格配置（特定人格使用）

编辑人格配置文件，例如 `backend/config/personalities/health_assistant.yaml`：

```yaml
personality:
  id: "health_assistant"
  name: "健康助手小研"
  # ... 其他配置 ...
  
  # 语音配置
  voice:
    # STT配置（使用腾讯ASR）
    stt:
      provider: "tencent"        # ← 改为 tencent
      model: "16k_zh"
      language: "zh-CN"
      recognition_mode: "auto"
      filter_modal: 1
      filter_punc: 1
    
    # TTS配置（使用腾讯TTS）
    tts:
      provider: "tencent"        # ← 改为 tencent
      voice: "ai_female"         # AI女声（温柔、自然）
      voice_type: 101001
      speed: 1.0
      volume: 0
      codec: "mp3"
    
    # RealTime配置（继续使用OpenAI）
    realtime:
      enabled: true
      provider: "openai"
      voice: "shimmer"
```

### 步骤3：重启应用

```bash
cd backend
# 如果使用uvicorn直接运行
uvicorn app.main:app --reload

# 或使用您的启动脚本
python main.py
```

**完成！** 🎉 现在您的应用已经使用腾讯语音引擎了！

### 方法2：使用Python客户端测试

创建测试脚本 `test_integration.py`：

```python
import requests
import os
from pathlib import Path

# API配置
API_BASE_URL = "http://localhost:8000/api/v1"
TOKEN = "your_access_token"  # 从登录获取

headers = {
    "Authorization": f"Bearer {TOKEN}"
}

# 测试STT
def test_stt():
    print("=" * 60)
    print("测试 STT（语音转文本）")
    print("=" * 60)
    
    # 准备音频文件
    audio_file = Path("test.wav")
    if not audio_file.exists():
        print("❌ 请先准备一个 test.wav 文件")
        return
    
    with open(audio_file, "rb") as f:
        files = {"file": f}
        data = {
            "model": "16k_zh",
            "personality_id": "health_assistant"
        }
        
        response = requests.post(
            f"{API_BASE_URL}/audio/transcriptions",
            headers=headers,
            files=files,
            data=data
        )
    
    if response.status_code == 200:
        result = response.json()
        print(f"✅ 转录成功:")
        print(f"   文本: {result['text']}")
    else:
        print(f"❌ 转录失败: {response.text}")

# 测试TTS
def test_tts():
    print("\n" + "=" * 60)
    print("测试 TTS（文本转语音）")
    print("=" * 60)
    
    data = {
        "input": "你好，这是腾讯AI大模型语音合成测试。",
        "voice": "ai_female",
        "speed": 1.0,
        "personality_id": "health_assistant"
    }
    
    response = requests.post(
        f"{API_BASE_URL}/audio/speech",
        headers=headers,
        json=data
    )
    
    if response.status_code == 200:
        output_file = "output_tts.mp3"
        with open(output_file, "wb") as f:
            f.write(response.content)
        print(f"✅ 合成成功:")
        print(f"   文件: {output_file}")
        print(f"   大小: {len(response.content)} bytes")
    else:
        print(f"❌ 合成失败: {response.text}")

# 测试流式TTS
def test_tts_stream():
    print("\n" + "=" * 60)
    print("测试流式 TTS（文本转语音）")
    print("=" * 60)
    
    data = {
        "input": "这是一段较长的文本，用于测试AI大模型流式合成功能。",
        "voice": "ai_male",
        "speed": 1.0,
        "personality_id": "health_assistant"
    }
    
    response = requests.post(
        f"{API_BASE_URL}/audio/speech/stream",
        headers=headers,
        json=data,
        stream=True
    )
    
    if response.status_code == 200:
        output_file = "output_tts_stream.mp3"
        total_size = 0
        with open(output_file, "wb") as f:
            for chunk in response.iter_content(chunk_size=8192):
                if chunk:
                    f.write(chunk)
                    total_size += len(chunk)
                    print(f"   收到音频块: {len(chunk)} bytes")
        
        print(f"✅ 流式合成成功:")
        print(f"   文件: {output_file}")
        print(f"   总大小: {total_size} bytes")
    else:
        print(f"❌ 流式合成失败: {response.text}")

if __name__ == "__main__":
    # 运行所有测试
    test_stt()
    test_tts()
    test_tts_stream()
    
    print("\n" + "=" * 60)
    print("测试完成！")
    print("=" * 60)
```

运行测试：
```bash
python test_integration.py
```

## 🎨 音色配置

### 腾讯TTS支持的音色

#### AI大模型音色（需要"AI大模型语音合成"资源包）

| voice值 | voice_type | 描述 | 特点 |
|---------|------------|------|------|
| ai_female | 101001 | AI女声 | 温柔、自然、亲和力强 |
| ai_male | 101002 | AI男声 | 磁性、稳重、专业感 |
| ai_narrator | 101003 | AI旁白 | 清晰、专业、适合讲述 |
| ai_warm_female | 101004 | AI温暖女声 | 温暖、治愈、亲切 |
| ai_energetic | 101005 | AI活力声音 | 充满活力、年轻化 |

#### 基础音色（需要"基础语音合成"资源包）

| voice值 | voice_type | 描述 |
|---------|------------|------|
| female | 0 | 女声 |
| male | 1 | 男声 |
| mature_male | 2 | 成熟男声 |
| energetic_male | 3 | 充满活力的男声 |
| warm_female | 4 | 温暖的女声 |
| warm_male | 5 | 温暖的男声 |

### 音色选择建议

**根据人格特点选择**：

## 🔧 高级配置

### 混合使用多个引擎

您可以为不同的人格使用不同的语音引擎：

```yaml
# 人格A：使用腾讯引擎
# config/personalities/personality_a.yaml
voice:
  stt:
    provider: "tencent"
    model: "16k_zh"
  tts:
    provider: "tencent"
    voice: "ai_female"

# 人格B：使用OpenAI引擎
# config/personalities/personality_b.yaml
voice:
  stt:
    provider: "openai"
    model: "whisper-1"
  tts:
    provider: "openai"
    voice: "alloy"
```

### 根据场景动态选择

API支持在请求时覆盖人格配置：

```bash
# 临时使用不同的音色
curl -X POST "http://localhost:8000/api/v1/audio/speech" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "测试文本",
    "voice": "ai_male",          # ← 覆盖人格配置
    "speed": 1.5,                # ← 覆盖速度
    "personality_id": "health_assistant"
  }'
```

### WebSocket模式（AI大模型音色专用）

AI大模型音色自动使用WebSocket模式以获得更好的性能：

```yaml
tts:
  provider: "tencent"
  voice: "ai_female"
  voice_type: 101001
  
  # 模式配置
  tts_mode: "http"              # http: HTTP流式，websocket: WebSocket
  
  # 流式配置
  streaming:
    enabled: true
    use_websocket: false        # 是否强制使用WebSocket
```

**自动选择逻辑**：
- AI大模型音色（101001+）：自动使用WebSocket
- 基础音色（0-5）：使用HTTP

## 🎯 最佳实践

### 1. 资源包管理

- **基础音色**：购买"基础语音合成"资源包
- **AI大模型音色**：购买"AI大模型语音合成"资源包
- **监控余额**：定期检查资源包余额
- **购买地址**：https://console.cloud.tencent.com/tts

### 2. 性能优化

```yaml
# 对于实时对话场景
tts:
  provider: "tencent"
  voice: "ai_female"
  codec: "mp3"           # MP3比PCM体积更小
  sample_rate: 16000     # 16kHz适合语音对话
  streaming:
    enabled: true        # 启用流式传输

# 对于高质量朗读场景
tts:
  provider: "tencent"
  voice: "ai_narrator"
  codec: "pcm"           # PCM音质更好
  sample_rate: 16000
  speed: 0.9             # 稍慢更清晰
```

### 3. 用户体验

- **选择合适的音色**：根据人格特点选择
- **调整语速**：对话场景1.0，朗读场景0.9-1.1
- **使用流式TTS**：减少用户等待时间
- **启用ASR过滤**：提升识别准确度

### 4. 成本控制

## 🐛 故障排查

### 问题1：API返回500错误

**可能原因**：
- 环境变量未配置
- 资源包余额不足
- 网络连接问题

**解决方案**：
1. 检查 `.env` 文件
2. 检查资源包余额
3. 查看应用日志

### 问题2：音频无声音或质量差

**可能原因**：
- 音频格式不匹配
- 采样率配置错误

**解决方案**：
```yaml
tts:
  codec: "mp3"           # 确保使用MP3
  sample_rate: 16000     # 确保16kHz
```

### 问题3：识别准确度低

**解决方案**：
```yaml
stt:
  model: "16k_zh"        # 确保使用正确的模型
  language: "zh-CN"      # 确保语言正确
  filter_modal: 1        # 启用过滤
  filter_punc: 1
  need_vad: 1            # 启用VAD
```
