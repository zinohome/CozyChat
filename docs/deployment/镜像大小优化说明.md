# Docker 镜像大小优化说明

## 📊 问题分析

**原始镜像大小：14.6GB** ⚠️ 太大了！

### 主要原因

1. **基础镜像 `phusion/passenger-full:latest`**
   - 这个镜像本身就很大（~2-3GB），包含了很多运行时不需要的工具

2. **构建工具未清理**
   - `build-essential` (~500MB)
   - `python3.11-dev` (~200MB)
   - `libpython3.11-dev` (~100MB)
   - `git` (~50MB)
   - 这些工具在构建完成后就不需要了

3. **Git 历史记录**
   - `.git` 目录可能包含大量历史记录（几百MB到几GB）
   - 生产环境不需要 Git 历史

4. **缓存未清理**
   - `apt` 缓存
   - `pip` 缓存
   - 临时文件

5. **Python 依赖**
   - `sentence-transformers` 可能包含大型模型文件
   - `chromadb` 可能包含预训练模型

## ✅ 优化措施

### 1. 清理构建工具

**优化前**：
```bash
apt install -y build-essential python3.11-dev libpython3.11-dev git
# ... 构建 ...
# 构建工具仍然保留在镜像中
```

**优化后**：
```bash
# 安装构建工具（仅用于编译）
apt install -y build-essential python3.11-dev libpython3.11-dev git
# ... 构建 Python 包 ...
# 构建完成后删除
apt-get remove -y --purge build-essential python3.11-dev libpython3.11-dev git
apt-get autoremove -y
```

### 2. 删除 Git 历史记录

```bash
# 克隆后立即删除 .git 目录
if [ -d ".git" ]; then
    rm -rf .git
fi
```

### 3. 清理所有缓存

```bash
# 清理 apt 缓存
apt-get clean
rm -rf /var/lib/apt/lists/*

# 清理 pip 缓存
rm -rf ~/.cache/pip
rm -rf /root/.cache/pip

# 清理临时文件
rm -rf /tmp/* /var/tmp/*
rm -rf /root/.cache
```

### 4. 使用 pip --no-cache-dir

```bash
# 安装时不缓存
pip install --no-cache-dir -r requirements/base.txt
```

### 5. 删除 Python 字节码缓存

```bash
find . -type d -name __pycache__ -exec rm -r {} + 2>/dev/null || true
find . -type f -name "*.pyc" -delete 2>/dev/null || true
find . -type f -name "*.pyo" -delete 2>/dev/null || true
```

### 6. 使用 .dockerignore

创建 `.dockerignore` 文件，排除不需要的文件：
- `.git/`
- `__pycache__/`
- `*.pyc`
- `venv/`
- `node_modules/`
- `docs/`
- `tests/`

## 📈 预期效果

| 优化项 | 节省空间 | 说明 |
|--------|---------|------|
| 删除构建工具 | ~850MB | build-essential, python3.11-dev, git |
| 删除 Git 历史 | ~100-500MB | 取决于仓库大小 |
| 清理缓存 | ~200-500MB | apt + pip 缓存 |
| 删除字节码 | ~10-50MB | __pycache__ 文件 |
| **总计** | **~1.2-1.9GB** | **预期镜像大小：~2-3GB** |

## 🚀 进一步优化建议

### 方案1: 使用多阶段构建（推荐）

```dockerfile
# 阶段1: 构建阶段
FROM phusion/passenger-full:latest AS builder
# ... 安装构建工具和依赖 ...
# ... 构建应用 ...

# 阶段2: 运行阶段
FROM phusion/passenger-full:latest
# 只复制构建好的应用和运行时依赖
COPY --from=builder /opt/cozychat/backend /opt/cozychat/backend
# ... 只安装运行时依赖 ...
```

**优势**：
- 构建工具不会进入最终镜像
- 镜像大小可减少 50-70%

### 方案2: 使用更小的基础镜像

考虑使用 `python:3.11-slim` 或 `ubuntu:22.04` 替代 `phusion/passenger-full`：

```dockerfile
FROM python:3.11-slim
# 只安装必要的运行时依赖
```

**优势**：
- 基础镜像更小（~200MB vs ~2GB）
- 镜像大小可减少 60-80%

**注意**：需要自己配置 Nginx 和进程管理

### 方案3: 使用 Alpine Linux

```dockerfile
FROM python:3.11-alpine
# Alpine 镜像只有 ~50MB
```

**优势**：
- 镜像极小
- 安全性高

**注意**：
- 某些 Python 包可能不兼容 Alpine
- 需要测试所有依赖
