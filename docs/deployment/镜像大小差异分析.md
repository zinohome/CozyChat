# Docker 镜像大小差异分析

## 🔍 问题

- **本地 backend 目录**：~1.5GB
- **Docker 镜像**：9.89GB
- **差异**：~8.4GB

## 📊 大小组成分析

### 1. 基础镜像大小

```bash
docker images phusion/passenger-full:latest
```

**预期大小**：~1-2GB

`phusion/passenger-full:latest` 是一个完整的基础镜像，包含：
- Ubuntu 系统
- Nginx
- Passenger
- Ruby/Python/Node.js 运行时
- 各种系统工具

### 2. 构建过程中的临时文件

#### 2.1 APT 包安装

```bash
# 安装的包
- build-essential (~500MB)
- python3.11-dev (~200MB)
- libpython3.11-dev (~100MB)
- ffmpeg (~100MB)
- 其他系统依赖 (~200MB)
```

**总计**：~1.1GB

#### 2.2 Python 虚拟环境

```bash
# 虚拟环境大小
.venv/
├── lib/python3.11/site-packages/  # Python 包
│   ├── sentence-transformers/     # ~100MB
│   ├── chromadb/                  # ~200MB
│   ├── torch/ (如果被依赖)        # ~1-2GB ⚠️
│   ├── numpy/                     # ~50MB
│   └── 其他包...                  # ~500MB
└── bin/                           # ~10MB
```

**预期大小**：~2-4GB（取决于是否包含 PyTorch）

#### 2.3 Git 仓库（如果未清理）

```bash
# Git 历史记录
.git/
├── objects/                       # ~100-500MB
└── refs/                          # ~10MB
```

**预期大小**：~100-500MB

#### 2.4 模型缓存（如果未清理）

```bash
# Hugging Face 缓存
~/.cache/huggingface/
├── transformers/                  # ~500MB-2GB
└── sentence_transformers/         # ~100-500MB

# PyTorch 缓存
~/.cache/torch/                    # ~500MB-1GB
```

**预期大小**：~1.1-3.5GB

#### 2.5 APT 缓存（如果未清理）

```bash
/var/lib/apt/lists/                # ~100-200MB
/var/cache/apt/                    # ~50-100MB
```

**预期大小**：~150-300MB

#### 2.6 临时文件

```bash
/tmp/                              # 构建过程中的临时文件
/var/tmp/                          # 临时文件
```

**预期大小**：~100-500MB

### 3. Docker 层叠加

Docker 镜像使用层叠存储，每一层都会增加大小：

```
基础镜像层：~1-2GB
├── 系统包层：~1.1GB
├── Python 环境层：~2-4GB
├── 项目代码层：~100MB
└── 其他层：~1-2GB
```

**层叠加可能导致额外开销**：~10-20%

## 🔍 为什么本地只有 1.5GB？

### 本地目录组成

```bash
backend/
├── app/                           # 代码 (~50MB)
├── tests/                         # 测试 (~20MB)
├── config/                        # 配置 (~5MB)
├── requirements/                  # 依赖文件 (~1MB)
├── .venv/                         # 虚拟环境 (~1-1.5GB) ⚠️
├── data/                          # 数据文件（可能为空）
└── 其他文件...                    # ~50MB
```

**关键差异**：
1. **本地 `.venv`**：可能不包含所有依赖，或使用了 `--no-cache-dir`
2. **没有基础系统**：本地只有 Python 代码和虚拟环境
3. **没有构建工具**：本地不需要 `build-essential` 等
4. **没有模型缓存**：本地可能没有下载模型

### Docker 镜像组成

```bash
镜像内容：
├── 基础系统 (Ubuntu + Nginx + Passenger)  # ~1-2GB
├── 系统包 (build-essential, python3.11-dev 等)  # ~1.1GB
├── Python 虚拟环境 (完整依赖)  # ~2-4GB
├── 项目代码  # ~100MB
├── Git 历史（如果未清理）  # ~100-500MB
├── 模型缓存（如果未清理）  # ~1.1-3.5GB
└── 其他临时文件  # ~500MB-1GB
```

## 🎯 问题定位

### 可能的原因

1. **PyTorch 被下载** (~1-2GB)
   - `sentence-transformers` 可能依赖 PyTorch
   - 检查：`pip show torch` 或 `pip list | grep torch`

2. **模型缓存未清理** (~1-3GB)
   - Hugging Face 模型被下载
   - 检查：`~/.cache/huggingface/`

3. **APT 缓存未清理** (~200MB)
   - `/var/lib/apt/lists/` 未清理

4. **构建工具未删除** (~850MB)
   - `build-essential`, `python3.11-dev` 等

5. **Git 历史未清理** (~100-500MB)
   - `.git` 目录存在

6. **Docker 层叠加** (~10-20% 额外开销)

## 🔧 诊断方法

### 方法1: 使用分析脚本

```bash
cd deployment
./analyze-image-size.sh cozychat/backend:v0.1.0
```

### 方法2: 手动检查

```bash
# 创建临时容器
CONTAINER_ID=$(docker create cozychat/backend:v0.1.0 /bin/bash)

# 检查虚拟环境大小
docker exec $CONTAINER_ID du -sh /opt/cozychat/backend/.venv

# 检查最大的 Python 包
docker exec $CONTAINER_ID du -h /opt/cozychat/backend/.venv/lib/python3.11/site-packages/* | sort -rh | head -20

# 检查模型缓存
docker exec $CONTAINER_ID du -sh /root/.cache/huggingface 2>/dev/null || echo "已清理"

# 检查构建工具
docker exec $CONTAINER_ID dpkg -l | grep -E "build-essential|python3.11-dev"

# 检查 Git 历史
docker exec $CONTAINER_ID test -d /opt/cozychat/.git && echo "存在" || echo "已清理"

# 清理
docker rm $CONTAINER_ID
```

### 方法3: 检查 Docker 层

```bash
docker history cozychat/backend:v0.1.0 --human
```

## 🚀 优化建议

### 1. 确认 PyTorch 是否被安装

```bash
# 在容器中检查
docker run --rm cozychat/backend:v0.1.0 pip list | grep torch
```

如果 PyTorch 被安装，考虑：
- 使用 CPU 版本的 PyTorch（更小）
- 或使用不依赖 PyTorch 的 embedding 方案

### 2. 使用多阶段构建

```dockerfile
# 阶段1: 构建
FROM phusion/passenger-full:latest AS builder
# ... 安装依赖和构建 ...

# 阶段2: 运行
FROM phusion/passenger-full:latest
# 只复制构建好的虚拟环境，不包含构建工具
COPY --from=builder /opt/cozychat/backend/.venv /opt/cozychat/backend/.venv
```

### 3. 使用更小的基础镜像

考虑使用 `python:3.11-slim` 替代 `phusion/passenger-full`：
- 基础镜像：~200MB vs ~1-2GB
- 需要自己配置 Nginx 和进程管理

## 📝 总结

**为什么本地只有 1.5GB，但镜像有 9.89GB？**

1. **基础系统**：镜像包含完整的 Ubuntu 系统（~1-2GB）
2. **系统包**：构建工具和运行时依赖（~1.1GB）
3. **Python 环境**：完整的虚拟环境，可能包含 PyTorch（~2-4GB）
4. **模型缓存**：如果未清理，可能包含模型文件（~1-3GB）
5. **其他开销**：Git 历史、APT 缓存、临时文件等（~1-2GB）

**关键**：使用分析脚本找出具体是哪个组件占用了最多空间，然后针对性优化。
