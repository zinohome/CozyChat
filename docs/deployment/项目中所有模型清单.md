# 项目中所有模型清单

## 📋 模型分类

### 1. 本地下载的模型（会占用镜像空间）

这些模型会在运行时下载到本地，存储在 `~/.cache/huggingface/` 目录。

#### 1.1 Embedding 模型（sentence-transformers）

**用途**：将文本转换为向量，用于记忆检索

**当前配置**：
- **配置文件**：`backend/config/memory.yaml`
- **ChromaDB 引擎**：`all-MiniLM-L6-v2`
- **Qdrant 引擎**：`all-MiniLM-L6-v2`
- **默认值**（代码中）：`all-MiniLM-L6-v2`

**模型详情**：

| 模型名称 | 大小 | 维度 | 语言 | 使用场景 | 状态 |
|---------|------|------|------|---------|------|
| `all-MiniLM-L6-v2` | ~80MB | 384 | 多语言 | 轻量级，资源受限 | ✅ **当前使用** |
| `BAAI/bge-base-zh-v1.5` | ~400MB | 768 | 中文优化 | 平衡性能和速度 | ⚠️ 需要 PyTorch 2.6+ |
| `BAAI/bge-large-zh-v1.5` | ~1.3GB | 1024 | 中文优化 | 最佳性能 | ⚠️ 需要 PyTorch 2.6+ |
| `BAAI/bge-m3` | ~2.2GB | 1024 | 多语言 | 最强性能 | ⚠️ 需要 PyTorch 2.6+ |

**代码位置**：
- `backend/app/engines/memory/qdrant_engine.py` - `_get_embedding_model()` 方法
- `backend/app/engines/memory/chromadb_engine.py` - 可能也有类似实现

**下载时机**：
- 首次调用 `_get_embedding_model()` 时自动下载
- 模型会缓存在内存中（类级别缓存）

**存储位置**：
- 运行时：`~/.cache/huggingface/transformers/`
- 容器中：`/root/.cache/huggingface/transformers/`

## 🔍 如何查看当前使用的模型

### 1. 查看配置

```bash
# 查看记忆引擎配置
cat backend/config/memory.yaml | grep -A 5 "embedding:"

# 查看人格配置
cat backend/config/personalities/default.yaml | grep "model:"
```

### 2. 查看代码中的默认值

```bash
# 查看 Qdrant 引擎的默认模型
grep -n "all-MiniLM-L6-v2" backend/app/engines/memory/qdrant_engine.py
```

### 3. 运行时查看日志

首次使用记忆功能时，会看到：
```

```

## 🚀 构建时预下载模型（可选）

如果希望在构建时预下载模型，可以在 `install.sh` 中添加：

```bash
# 在安装完依赖后，预下载模型
python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('all-MiniLM-L6-v2')"
```

**注意**：
- 模型会下载到 `/tmp`（因为设置了环境变量）
- 构建完成后会被清理
- 运行时仍需要重新下载（除非使用 volume 持久化）

## 📝 模型大小参考

### Embedding 模型大小

| 模型 | 下载大小 | 解压后大小 | 说明 |
|------|---------|-----------|------|
| `all-MiniLM-L6-v2` | ~80MB | ~90MB | 当前使用 |
| `BAAI/bge-base-zh-v1.5` | ~400MB | ~450MB | 需要 PyTorch 2.6+ |
| `BAAI/bge-large-zh-v1.5` | ~1.3GB | ~1.5GB | 需要 PyTorch 2.6+ |
| `BAAI/bge-m3` | ~2.2GB | ~2.5GB | 需要 PyTorch 2.6+ |

### 总大小估算

**当前配置**（只使用 `all-MiniLM-L6-v2`）：
- 模型文件：~90MB
- PyTorch 依赖：~500MB-1GB（如果被下载）
- **总计**：~600MB-1.1GB

**如果使用 BGE 模型**：
- 模型文件：~400MB-2.5GB
- PyTorch 依赖：~500MB-1GB
- **总计**：~900MB-3.5GB

## ⚠️ 重要提示

1. **当前只使用一个模型**：`all-MiniLM-L6-v2`（~80MB）
2. **模型在运行时下载**：首次使用记忆功能时自动下载
3. **模型缓存位置**：`~/.cache/huggingface/transformers/`
4. **构建时已防止下载**：通过环境变量将缓存指向 `/tmp`，构建后会被清理
5. **运行时需要网络**：首次运行需要访问 Hugging Face 下载模型

## 🔧 修改模型配置

### 修改 Embedding 模型

编辑 `backend/config/memory.yaml`：

```yaml
memory:
  qdrant:
    embedding:
      model: "all-MiniLM-L6-v2"  # 修改这里
      dimension: 384  # 根据模型修改维度
```

**注意**：
- 修改模型后需要重启服务
- 新模型会在首次使用时自动下载
- 确保维度与模型匹配
