# 记忆重要性评分问题修复

## 问题分析

### 问题描述

用户发现 Qdrant 中存储的所有记忆的 `importance` 字段都是 `0.5`，而不是根据内容自动计算的重要性分数。

### 根本原因

1. **`importance` 字段的含义**：
   - 记忆的重要性分数，范围 `[0, 1]`
   - 用于记忆淘汰策略（低重要性的记忆会被优先淘汰）
   - 用于记忆去重（保留重要性更高的记忆）
   - 由 `ImportanceScorer` 根据内容长度、关键词、频率、时间等因素自动计算

2. **为什么都是 0.5**：
   - 在 `backend/app/api/v1/chat.py:960` 中，调用 `add_conversation_turn` 时**硬编码了 `importance=0.5`**
   - 这覆盖了自动计算的重要性分数
   - `add_conversation_turn` 方法直接将这个硬编码的 `importance` 传递给 `add_memory`
   - 虽然 `add_memory` 有 `auto_calculate_importance=True` 的默认参数，但如果传入了 `importance` 参数，就不会自动计算了

### 代码位置

```python
# backend/app/api/v1/chat.py:960
await memory_manager.add_conversation_turn(
    user_id=user_id,
    session_id=data.session_id,

    assistant_message=assistant_content,
    importance=0.5,  # ❌ 硬编码，覆盖了自动计算

```

## 修复方案

### 方案 1：让 `importance` 参数可选，自动计算（推荐）

修改 `add_conversation_turn` 方法，让 `importance` 参数可选（`Optional[float] = None`），如果不提供则让 `add_memory` 自动计算。

### 方案 2：在 `add_conversation_turn` 中分别计算用户和AI记忆的重要性

为 `user_message` 和 `assistant_message` 分别计算重要性，因为它们的内容不同，重要性也应该不同。

### 推荐方案：方案 1 + 方案 2 结合

1. 修改 `add_conversation_turn` 方法：
   - `importance` 参数改为 `Optional[float] = None`
   - 如果不提供，则分别计算用户消息和AI消息的重要性
   - 如果提供，则使用提供的值（向后兼容）

2. 修改 `chat.py` 中的调用：
   - 移除硬编码的 `importance=0.5`
   - 让系统自动计算

## 重要性评分算法

`ImportanceScorer` 根据以下因素计算重要性：

1. **内容长度评分** (权重 0.3)：内容越长，重要性越高（但有限制）
2. **关键词评分** (权重 0.4)：包含重要关键词越多，重要性越高
   - 个人信息：姓名、年龄、生日、地址、电话、邮箱
   - 偏好：喜欢、不喜欢、偏好、习惯、爱好
   - 重要事件：重要、关键、必须、记得、记住
   - 健康：健康、疾病、过敏、药物、治疗
   - 关系：朋友、同事、恋人、配偶
3. **频率评分** (权重 0.2)：基于历史访问频率（需要metadata支持）
4. **时间评分** (权重 0.1)：基于创建时间（新记忆权重更高）

最终分数 = 加权平均，范围 `[0, 1]`

## 配置

重要性评分在 `backend/config/memory.yaml` 中配置：

```yaml
importance:
  scoring:
    enabled: true
    algorithm: "default"
    default:
      content_length_weight: 0.3
      keyword_weight: 0.4
      frequency_weight: 0.2
      recency_weight: 0.1
```

## 预期效果

修复后：
- 包含重要关键词的记忆（如"身高174"）会得到更高的重要性分数（如 0.7-0.9）
- 普通对话的记忆会得到中等的重要性分数（如 0.4-0.6）
- 无意义的短文本会得到较低的重要性分数（如 0.2-0.4）
- 重要性分数会用于记忆淘汰和去重策略
