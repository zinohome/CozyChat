# 「我在」全端全量 UI 设计图集 (v8.0)

为了实现与深色系列同等甚至更高的设计完整度，我们为 **「我在」** 品牌打造了全套 8 张高保真、全连贯的浅色系设计稿。

---

## 1. 视觉系统 (Design System: CUID v8.0)
-   **品牌名称**: 「我在」
-   **核心调色**: 鼠尾草绿 (#7CB342), 翡翠绿 (#10B981), 薄荷白 (#F1F8E9)
-   **设计材质**: 白色玻璃拟态 (White Glassmorphism), 24px 圆角, 软环境投影。
-   **交互逻辑**: PC、Mobile、Pad 功能 1:1 深度对等。
