## 技术实现

### 依赖注入模式

所有API路由现在使用FastAPI的依赖注入系统：

```python
async def endpoint(
    ...,
    personality_registry: PersonalityRegistry = Depends(get_personality_registry),
    tool_factory: ToolManagerFactory = Depends(get_tool_manager_factory),
    engine_pool: LLMEnginePool = Depends(get_llm_engine_pool),
):
    # 使用全局组件，无需重新初始化
    personality = personality_registry.get_personality(personality_id)
    tool_manager = tool_factory.get_tool_manager()
    engine = engine_pool.get_engine(provider="openai", model="gpt-4")
```

### 全局组件生命周期

1. **应用启动时**（`main.py` lifespan）：
   - 初始化 `PersonalityRegistry` - 加载所有人格配置
   - 初始化 `ToolManagerFactory` - 创建工具管理器工厂
   - 初始化 `LLMEnginePool` - 创建引擎池
   - 初始化 `QdrantClient` - 创建Qdrant客户端

2. **请求处理时**：
   - 通过依赖注入获取全局组件
   - 使用缓存的实例，无需重新初始化
