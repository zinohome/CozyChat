# 语音转录繁体转简体功能说明

## 问题背景

在使用语音转录功能时，某些语音识别引擎（如 OpenAI Whisper、腾讯ASR）可能会将中文转录为繁体中文，而不是简体中文。这会影响用户体验，特别是对于习惯使用简体中文的用户。

## 解决方案

我们实现了自动将繁体中文转换为简体中文的功能，确保所有转录结果都是简体中文。

### 实现方式

#### 1. 后端实现（STT API）

**位置**: `backend/app/api/v1/audio.py`

**实现**:
- 使用 `zhconv` Python库进行转换
- 在STT API返回转录结果前自动转换
- 适用于所有通过 `/api/v1/audio/transcriptions` API的转录请求

**代码示例**:
```python
from app.utils.text_converter import to_simplified

# 在返回转录结果前转换
text = await stt_engine.transcribe(audio_data, **transcribe_kwargs)
text = to_simplified(text)  # 转换为简体中文
return TranscriptionResponse(text=text)
```

**依赖**: `zhconv==1.4.2` (已在 `backend/requirements/base.txt` 中添加)

#### 2. 前端实现（实时语音转录）

**位置**: 
- `frontend/src/hooks/useVoiceAgent.v1.ts`
- `frontend/src/features/voice/services/EventHandler.ts`

**实现**:
- 使用 `chinese-simple2traditional` TypeScript库进行转换
- 在所有实时语音转录的回调中进行转换
- 适用于OpenAI Realtime API的实时语音转录

**代码示例**:
```typescript
import { toSimplifiedChinese } from '@/utils/textConverter';

// 在转录回调中转换
const simplifiedTranscript = toSimplifiedChinese(transcript.trim());
callbacks.onUserTranscript(simplifiedTranscript);
```

**依赖**: `chinese-simple2traditional` (已在 `frontend/package.json` 中添加)

## 工具函数

### 后端工具函数

**文件**: `backend/app/utils/text_converter.py`

**函数**:
- `to_simplified(text: str) -> str`: 将繁体中文转换为简体中文
- `is_traditional_chinese(text: str) -> bool`: 检测文本是否包含繁体中文

**特性**:
- 自动检测并转换繁体中文
- 如果文本已经是简体，不会改变
- 转换失败时返回原文本（容错处理）

### 前端工具函数

**文件**: `frontend/src/utils/textConverter.ts`

**函数**:
- `toSimplifiedChinese(text: string): string`: 将繁体中文转换为简体中文
- `isTraditionalChinese(text: string): boolean`: 检测文本是否包含繁体中文

**特性**:
- 使用 `chinese-simple2traditional` 库
- 自动加载短语库（+374kb）以获得更精确的转换
- 使用增强模式（`enhance=true`）进行转换
- 添加了自定义短语修复已知的转换错误（如"退休"）
- 支持浏览器和Node环境

## 使用场景

### 1. STT API转录

所有通过 `/api/v1/audio/transcriptions` API的转录请求都会自动转换：

```bash
curl -X POST "http://localhost:8000/api/v1/audio/transcriptions" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@audio.wav" \
  -F "personality_id=health_assistant"
```

**响应**:
```json
{
  "text": "你好，这是简体中文转录结果。"
}
```

即使语音识别引擎返回繁体中文，API也会自动转换为简体中文。

### 2. 实时语音转录

所有通过OpenAI Realtime API的实时语音转录都会自动转换：

```typescript
const { useVoiceAgent } = require('@/hooks/useVoiceAgent.v1');

useVoiceAgent(sessionId, personalityId, {
  onUserTranscript: (text: string) => {
    // text 已经是简体中文
    console.log(text); // "你好，这是简体中文转录结果。"
  }
});
```

## 性能影响

### 后端

- **转换时间**: < 1ms（对于普通长度的文本）
- **内存占用**: 可忽略不计
- **CPU占用**: 可忽略不计

### 前端

- **包体积**: 
  - 基础库：`chinese-simple2traditional` 约 30KB（gzipped）
  - 短语库：约 374KB（增强模式，已加载）
- **转换时间**: < 1ms（对于普通长度的文本）
- **内存占用**: 可忽略不计

**注意**: 我们使用了增强模式（短语库），以获得更精确的转换结果。同时添加了自定义短语来修复已知的转换错误（如"退休"被错误转换为"煺休"的问题）。

## 常见问题

### Q1: 为什么需要转换？

A: 某些语音识别引擎（如OpenAI Whisper）可能返回繁体中文，而用户习惯使用简体中文。自动转换可以提升用户体验。

### Q2: 转换是否准确？

A: 是的。`zhconv` 和 `chinese-simple2traditional` 都是成熟的繁简体转换库，转换准确率很高。

### Q3: 是否会影响性能？

A: 不会。转换操作非常快速（< 1ms），对性能影响可忽略不计。

### Q4: 是否可以禁用转换？

A: 可以，但不推荐。如果需要禁用，请参考"配置说明"部分。

### Q5: 是否支持其他语言？

A: 目前仅支持中文繁简体转换。其他语言的转换需要额外的库支持。
