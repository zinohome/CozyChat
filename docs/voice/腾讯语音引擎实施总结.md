## 实施内容

### 1. TencentSTTEngine（腾讯ASR引擎）

**文件**: `backend/app/engines/voice/stt/tencent_stt.py`

**功能特性**:

1. **两种识别模式**:
   - FlashRecognizer（一句话识别）：适合短音频，基于HTTP
   - SpeechRecognizer（实时识别）：适合长音频，基于WebSocket

2. **智能模式选择**:
   - `auto` 模式：根据音频大小自动选择（默认1MB阈值）
   - `flash` 模式：强制使用一句话识别
   - `realtime` 模式：强制使用实时识别

3. **异步转换**:
   - 使用 `ThreadPoolExecutor` 在线程中运行同步SDK
   - 使用 `threading.Event` 进行线程同步
   - 实现了 `ResultCollector` 监听器收集识别结果

4. **语言支持**:
   - 支持中文（zh-CN -> 16k_zh）
   - 支持英文（en-US -> 16k_en）
   - 自动语言代码映射

5. **音频格式**:
   - 支持 wav, mp3, opus, speex, pcm
   - 自动检测音频格式（通过文件头魔数）

6. **配置参数**:
   - `filter_modal`: 过滤语气词
   - `filter_punc`: 过滤标点符号
   - `filter_dirty`: 过滤脏词
   - `need_vad`: VAD（语音活动检测）

### 2. TencentTTSEngine（腾讯TTS引擎）

**文件**: `backend/app/engines/voice/tts/tencent_tts.py`

**功能特性**:

1. **两种合成模式**:
   - HTTP流式合成：适合短文本，快速响应
   - WebSocket流式合成：适合长文本和实时场景

2. **音色支持**:
   - 6种音色类型：female(0), male(1), mature_male(2), energetic_male(3), warm_female(4), warm_male(5)
   - 支持音色名称或数字映射

3. **参数转换**:
   - 语速转换：OpenAI格式（0.25-4.0）→ 腾讯格式（-2到2）
   - 音量控制：-10到10
   - 自动参数范围限制

4. **流式合成**:
   - 实现了 `synthesize()` 方法（非流式）
   - 实现了 `stream_synthesize()` 方法（流式）
   - 使用 `asyncio.Queue` 进行异步音频传递

5. **音频格式**:
   - 支持 mp3, pcm 编码
   - 支持 8000Hz, 16000Hz 采样率

6. **收集器实现**:
   - `AudioCollector`: HTTP合成音频收集
   - `StreamAudioCollector`: WebSocket流式音频收集

## 技术实现要点

### 异步转换策略

1. **ThreadPoolExecutor**:
   - 在线程池中运行同步SDK调用
   - 避免阻塞主事件循环
   - 使用 `loop.run_in_executor()` 执行

2. **线程同步**:
   - 使用 `threading.Event` 等待完成信号
   - 超时控制（默认30秒）

3. **结果收集**:
   - 实现监听器类收集异步结果
   - 使用 `asyncio.Queue` 传递流式数据
   - 使用 `asyncio.run_coroutine_threadsafe()` 跨线程通信

### 错误处理

1. **配置验证**:
   - 启动时检查必需配置项
   - 缺少配置时抛出清晰的错误信息

2. **API错误处理**:
   - 捕获腾讯SDK返回的错误码和消息
   - 记录详细的错误日志
   - 向上传播异常

3. **超时控制**:
   - 识别超时（默认30秒）
   - 合成超时（默认30秒）
   - 超时后抛出 `TimeoutError`

### 资源清理

1. **线程池管理**:
   - `__del__` 方法中清理线程池
   - `shutdown(wait=False)` 快速关闭

2. **WebSocket连接**:
   - SDK内部管理连接生命周期
   - 收集器正确处理完成和错误信号

## 使用示例

### ASR（语音识别）

```python
from app.engines.voice.stt import STTEngineFactory

# 创建腾讯ASR引擎
engine = STTEngineFactory.create_engine("tencent")

# 语音转文本
text = await engine.transcribe(audio_data, language="zh-CN")
print(f"识别结果: {text}")

# 强制使用一句话识别
text = await engine.transcribe(audio_data, flash=True)

# 强制使用实时识别
text = await engine.transcribe(audio_data, realtime=True)
```

### TTS（文本转语音）

```python
from app.engines.voice.tts import TTSEngineFactory

# 创建腾讯TTS引擎
engine = TTSEngineFactory.create_engine("tencent")

# 非流式合成
audio_data = await engine.synthesize(
    "你好，欢迎使用CozyChat",
    voice="female",
    speed=1.0
)

# 流式合成
async for audio_chunk in engine.stream_synthesize(
    "这是一段较长的文本，需要流式合成",
    voice="male",
    speed=1.2
):
    # 处理音频块
    process_audio(audio_chunk)
```

## 性能考虑

### ASR性能

1. **一句话识别（Flash）**:
   - 延迟：~500ms
   - 适用场景：短音频（<60秒）
   - 并发能力：高

2. **实时识别（Realtime）**:
   - 延迟：实时
   - 适用场景：长音频、实时对话
   - 并发能力：中等

### TTS性能

1. **HTTP流式合成**:
   - 首包延迟：~300ms
   - 适用场景：短文本
   - 并发能力：高

2. **WebSocket流式合成**:
   - 首包延迟：~200ms
   - 适用场景：长文本、实时场景
   - 并发能力：中等

## 已知限制

1. **SDK限制**:
   - 腾讯SDK为同步设计，需要异步包装
   - WebSocket连接管理由SDK内部处理

2. **音频格式**:
   - 需要确保音频格式符合腾讯云要求
   - 采样率建议使用16000Hz

3. **并发限制**:
   - 线程池大小限制为4
   - 可根据实际需求调整
