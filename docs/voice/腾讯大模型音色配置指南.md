# 腾讯大模型音色配置指南

## 概述

本文档说明如何使用腾讯云的AI大模型语音合成功能。

## 重要说明

腾讯云有**两种独立的**语音合成服务和资源包：

### 1. 基础语音合成
- **音色编号**: 0-5
- **音色名称**: `female`, `male`, `mature_male`, `energetic_male`, `warm_female`, `warm_male`
- **资源包**: 基础语音合成资源包
- **传输方式**: HTTP（快速）
- **价格**: 较低

### 2. AI大模型语音合成 ⭐
- **音色编号**: 101001-101005
- **音色名称**: `ai_female`, `ai_male`, `ai_narrator`, `ai_warm_female`, `ai_energetic`
- **资源包**: 大模型语音合成资源包（100万字符 = 650元）
- **传输方式**: WebSocket（实时）
- **价格**: 较高
- **音质**: 更自然、更接近真人

## 使用方法

### 方式1：在代码中指定音色

```python
from app.engines.voice.tts import TTSEngineFactory

engine = TTSEngineFactory.create_engine("tencent")

# 使用AI女声
audio_data = []
async for chunk in engine.stream_synthesize(
    "你好，这是AI大模型音色测试",
    voice="ai_female",  # 或使用 "101001"
    speed=1.0
):
    audio_data.append(chunk)

audio = b"".join(audio_data)
```

### 方式2：修改配置文件

编辑 `backend/config/voice/tts.yaml`:

```yaml
tencent:
  voice: "ai_female"      # 设置默认AI音色
  voice_type: 101001      # 对应的编号
  tts_mode: "websocket"   # AI音色自动使用WebSocket
```

### 方式3：在API调用中指定

```bash
curl -X POST http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "input": "你好，这是AI大模型音色",
    "voice": "ai_female",
    "model": "tencent",
    "speed": 1.0
  }'
```

## 注意事项

### 1. 资源包要求

- ✅ 您已购买：大模型语音合成资源包（100万字符）
- ✅ 可以使用：AI音色（101001-101005）
- ❌ 不能使用：基础音色（0-5）需要单独购买基础资源包

### 2. 传输模式

- **AI音色**（101001+）：自动使用WebSocket，无需手动配置
- **基础音色**（0-5）：默认使用HTTP，速度更快

### 3. SSL证书

- SSL证书配置已自动处理
- 使用certifi提供的CA证书
- 如遇证书问题，确保 `certifi` 包已安装

### 4. 性能特点

- **首包延迟**: AI音色约200-300ms（WebSocket）
- **音质**: AI音色明显优于基础音色
- **消耗**: AI音色资源包消耗速度与基础音色相同（按字符计费）

## 故障排查

### 问题1：资源包配额已用尽

**错误信息**: `PkgExhausted`

**原因**: 使用了错误的资源包对应的音色

**解决**:
- 检查当前使用的音色编号
- AI音色需要大模型资源包
- 基础音色需要基础资源包

### 问题2：SSL证书验证失败

**错误信息**: `[SSL: CERTIFICATE_VERIFY_FAILED]`

**解决**:
1. 确保已重新安装本地SDK包：
   ```bash
   cd backend
   pip install -e packages/tencent-speech-sdk --force-reinstall --no-deps
   ```

2. 检查certifi是否安装：
   ```bash
   pip install certifi
   ```

### 问题3：WebSocket连接失败

**解决**:
1. 检查网络连接
2. 确认防火墙允许WebSocket连接
3. 检查腾讯云凭证是否正确

## 配置示例

### 完整的TTS配置

```yaml
engines:
  tts:
    default: "tencent"
    
    tencent:
      provider: "tencent"
      
      # AI大模型音色配置
      voice: "ai_female"
      voice_type: 101001
      
      # 合成参数
      speed: 1.0
      volume: 0
      codec: "mp3"
      sample_rate: 16000
      
      # 模式（AI音色会自动使用WebSocket）
      tts_mode: "http"
      
      # API配置
      api:
        app_id: null  # 从环境变量获取
        secret_id: null
        secret_key: null
        timeout: 30
```

### 环境变量

```bash
# .env 文件
TENCENT_APP_ID=your_app_id
TENCENT_SECRET_ID=your_secret_id
TENCENT_SECRET_KEY=your_secret_key
```
