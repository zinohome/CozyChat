# 记忆机制优化方案

## 一、问题分析

### 1.1 当前问题

根据日志分析，当前记忆检索系统存在以下问题：

1. **关键记忆被遗漏**：
   - 查询："我体重多少？"
   - 记忆："年龄 47  男  身高174  体重90kg"
   - 相似度：0.3715（较低）
   - 最终分数：2.0715（排在第7位，未进入top 5）

2. **检索策略单一**：
   - 仅依赖语义相似度（向量搜索）
   - 没有关键词匹配机制
   - 没有混合检索策略

3. **排序因子不足**：
   - 只考虑相似度 + 智能评分
   - 没有考虑记忆重要性（importance）
   - 没有考虑记忆时效性（recency）

4. **关键词匹配不够灵活**：
   - 正则表达式 `体重[^\d]*(\d+)` 可能无法匹配"体重 90kg"（有空格）
   - 对于"年龄 47  男  身高174  体重90kg"这样的复合记忆，匹配逻辑不够智能

### 1.2 业界最佳实践

参考 Mem0 等成熟记忆系统的设计：

1. **混合检索策略**：
   - 语义搜索（向量相似度）
   - 关键词匹配（精确匹配）
   - 图关系查询（实体关系）

2. **多因子排序**：
   - 相似度（semantic similarity）
   - 重要性（importance）
   - 时效性（recency）
   - 相关性（relevance）

3. **记忆层级**：
   - 短期记忆（当前会话）
   - 长期记忆（跨会话）
   - 代理级记忆（系统级）

```python
async def hybrid_search(
    query: str,
    user_id: str,
    session_id: Optional[str] = None,
    limit: int = 15
) -> List[MemorySearchResult]:
    """混合检索：语义搜索 + 关键词匹配"""
    
    # 1. 语义搜索（向量相似度）
    semantic_results = await vector_search(
        query=query,
        user_id=user_id,
        session_id=session_id,
        limit=limit * 2,  # 获取更多候选
        similarity_threshold=0.3  # 宽松阈值
    )
    
    # 2. 关键词匹配（精确匹配）
    keyword_results = await keyword_search(
        query=query,
        user_id=user_id,
        session_id=session_id,
        limit=limit
    )
    
    # 3. 合并去重
    all_results = merge_and_deduplicate(
        semantic_results,
        keyword_results
    )
    
    return all_results
```

```python
async def intelligent_search(
    query: str,
    user_id: str,
    session_id: Optional[str] = None
) -> List[MemorySearchResult]:
    """智能检索：理解查询意图，多路径检索"""
    
    # 1. 查询理解
    query_intent = analyze_query(query)
    # 返回：{
    #   "type": "numeric_query",  # numeric_query / factual_query / conversational
    #   "keywords": ["体重", "多少"],
    #   "entities": ["体重"],
    #   "expected_format": "体重XXkg"
    # }
    
    # 2. 根据意图选择检索策略
    if query_intent["type"] == "numeric_query":
        # 数值查询：优先关键词匹配
        results = await keyword_first_search(
            query=query,
            keywords=query_intent["keywords"],
            user_id=user_id,
            session_id=session_id
        )
    else:
        # 其他查询：优先语义搜索
        results = await semantic_first_search(
            query=query,
            user_id=user_id,
            session_id=session_id
        )
    
    return results
```

### 2.2 多因子排序算法

#### 综合评分公式

```python
def calculate_comprehensive_score(
    memory: MemorySearchResult,
    query: str,
    query_intent: Dict[str, Any],
    config: RetrievalConfig
) -> float:
    """计算综合评分
    
    公式：
    final_score = (
        similarity_score * similarity_weight +
        importance_score * importance_weight +
        recency_score * recency_weight +
        relevance_score * relevance_weight +
        intelligent_boost
    )
    """
    
    # 1. 相似度分数（归一化到0-1）
    similarity_score = memory.similarity
    
    # 2. 重要性分数（归一化到0-1）
    importance_score = memory.memory.importance
    
    # 3. 时效性分数（归一化到0-1）
    recency_score = calculate_recency_score(memory.memory.created_at)
    
    # 4. 相关性分数（基于查询意图）
    relevance_score = calculate_relevance_score(
        memory.memory.content,
        query_intent
    )
    
    # 5. 智能boost（关键词匹配、数值匹配等）
    intelligent_boost = calculate_intelligent_boost(
        memory.memory.content,
        query,
        query_intent,
        config
    )
    
    # 6. 加权求和
    final_score = (
        similarity_score * config.weights.similarity +
        importance_score * config.weights.importance +
        recency_score * config.weights.recency +
        relevance_score * config.weights.relevance
    ) + intelligent_boost
    
    return final_score
```

### 2.3 改进的关键词匹配

#### 灵活的关键词-数值匹配

```python
def match_keyword_with_number(
    content: str,
    keyword: str,
    max_distance: int = 5
) -> Optional[Tuple[str, float]]:
    """匹配关键词和数值，支持多种格式
    
    支持的格式：
    - "体重90kg"
    - "体重 90kg"
    - "体重是90kg"
    - "体重：90kg"
    - "体重为90公斤"
    - "体重90"
    
    Returns:
        Optional[Tuple[str, float]]: (匹配的数值文本, 数值) 或 None
    """
    import re
    
    # 模式1：关键词 + 可选分隔符 + 数字 + 可选单位
    patterns = [
        rf'{re.escape(keyword)}[：:是]?\s*(\d+(?:\.\d+)?)\s*(?:kg|公斤|千克)?',
        rf'{re.escape(keyword)}\s+(\d+(?:\.\d+)?)',
        rf'{re.escape(keyword)}(\d+(?:\.\d+)?)',
    ]
    
    for pattern in patterns:
        match = re.search(pattern, content, re.IGNORECASE)
        if match:
            value_text = match.group(1)
            try:
                value = float(value_text)
                return (value_text, value)
            except ValueError:
                continue
    
    # 模式2：在关键词附近查找数字（距离限制）
    keyword_pos = content.find(keyword)
    if keyword_pos != -1:
        # 在关键词前后max_distance个字符内查找数字
        search_start = max(0, keyword_pos - max_distance)
        search_end = min(len(content), keyword_pos + len(keyword) + max_distance)
        search_text = content[search_start:search_end]
        
        # 查找数字
        number_match = re.search(r'(\d+(?:\.\d+)?)', search_text)
        if number_match:
            value_text = number_match.group(1)
            try:
                value = float(value_text)
                return (value_text, value)
            except ValueError:
                pass
    
    return None
```

### 2.4 查询理解模块

#### 查询意图分析

```python
def analyze_query(query: str) -> Dict[str, Any]:
    """分析查询意图
    
    Returns:
        {
            "type": "numeric_query" | "factual_query" | "conversational",
            "keywords": List[str],
            "entities": List[str],
            "expected_format": Optional[str],
            "is_question": bool
        }
    """
    import re
    
    # 检测数值查询关键词
    numeric_keywords = ['身高', '体重', '年龄', '多少', '几', '多高', '多重', '多大']
    is_numeric_query = any(kw in query for kw in numeric_keywords)
    
    # 提取关键词
    keywords = [kw for kw in numeric_keywords if kw in query]
    
    # 提取实体（简化版，实际可以使用NER模型）
    entities = extract_entities(query)
    
    # 判断是否为问题
    is_question = any(qw in query for qw in ['什么', '多少', '几', '如何', '怎么', '？', '?'])
    
    # 判断查询类型
    if is_numeric_query and is_question:
        query_type = "numeric_query"
        # 根据关键词推断期望格式
        if '体重' in keywords:
            expected_format = "体重XXkg"
        elif '身高' in keywords:
            expected_format = "身高XXcm"
        elif '年龄' in keywords:
            expected_format = "年龄XX岁"
        else:
            expected_format = None
    elif is_question:
        query_type = "factual_query"
        expected_format = None
    else:
        query_type = "conversational"
        expected_format = None
    
    return {
        "type": query_type,
        "keywords": keywords,
        "entities": entities,
        "expected_format": expected_format,
        "is_question": is_question
    }
```

### 2.5 记忆层级管理

#### 短期记忆 vs 长期记忆

```python
async def retrieve_memories_with_priority(
    query: str,
    user_id: str,
    session_id: str,
    config: RetrievalConfig
) -> List[MemorySearchResult]:
    """带优先级的记忆检索
    
    优先级：
    1. 当前会话记忆（短期记忆，权重更高）
    2. 跨会话记忆（长期记忆，权重较低）
    """
    
    # 1. 检索当前会话记忆（短期记忆）
    session_memories = await search_memories(
        query=query,
        user_id=user_id,
        session_id=session_id,  # 限制在当前会话
        limit=config.max_results * 2
    )
    
    # 2. 检索跨会话记忆（长期记忆）
    cross_session_memories = await search_memories(
        query=query,
        user_id=user_id,
        session_id=None,  # 跨会话
        limit=config.max_results * 2
    )
    
    # 3. 合并并应用优先级权重
    all_memories = []
    
    # 短期记忆：权重 1.2
    for mem in session_memories:
        mem.priority_boost = 1.2
        all_memories.append(mem)
    
    # 长期记忆：权重 1.0
    for mem in cross_session_memories:
        if mem.memory.session_id != session_id:  # 排除当前会话
            mem.priority_boost = 1.0
            all_memories.append(mem)
    
    # 4. 去重（相同内容只保留优先级更高的）
    all_memories = deduplicate_by_content(all_memories)
    
    # 5. 综合排序
    all_memories.sort(
        key=lambda m: calculate_comprehensive_score(m, query, ...) * m.priority_boost,
        reverse=True
    )
    
    return all_memories[:config.max_results]
```
