**集成说明**:
在 `main.py` 中注册异常处理器:
```python

from app.middleware.exception_handler import cozy_exception_handler, general_exception_handler

app.add_exception_handler(CozyError, cozy_exception_handler)
app.add_exception_handler(Exception, general_exception_handler)
```
