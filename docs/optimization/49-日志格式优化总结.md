# 日志格式优化总结

## 优化概述

对后端日志格式进行了三项重要优化，使日志更简洁、易读、易用。

## 优化内容

### 1. 时间格式优化

**优化前**：
```
2025-11-18T07:06:55.699562Z  # ISO 8601 UTC格式，不直观
```

**优化后**：
```
2025-11-18 15:06:55.699  # 本地时区，更直观
```

**实现**：
- 使用 `structlog.processors.TimeStamper(fmt="iso", utc=False)` 获取本地时间
- 自定义 `format_timestamp_local` 处理器格式化为简洁格式
- 毫秒保留3位

### 2. 日志级别格式优化

**优化前**：
```
[info     ]  # 有大量空格填充
```

**优化后**：
```
[info]  # 紧凑格式，无空格，带粗体
```

**实现**：
- 自定义 `format_level_compact` 处理器去掉空格填充
- 创建自定义 `CompactConsoleRenderer` 完全控制渲染格式
- 保留粗体和颜色，突出显示日志级别

### 3. 代码位置格式优化

**优化前**：
```
[app/engines/tools/builtin/factory.py:43:register_builtin_tools]
# 包含函数名，太长
```

**优化后**：
```
[app/engines/tools/builtin/factory.py:43]
# 只保留文件路径和行号，简洁
```

**实现**：
- 修改 `format_callsite` 处理器，去掉函数名输出
- 使用 `CallsiteParameter.PATHNAME` 获取完整路径
- 转换为相对路径，支持点击跳转

## 最终效果

### 日志输出示例

```bash
2025-11-18 15:15:43.268 [info] [app/engines/memory/base.py:36] Initializing qdrant memory engine extra={'engine': 'qdrant', 'config': {...}}
2025-11-18 15:15:43.659 [info] [app/engines/memory/qdrant_engine.py:88] Qdrant memory engine initialized extra={...}
2025-11-18 15:15:43.662 [debug] [app/engines/memory/importance_scorer.py:57] Importance scorer initialized extra={...}
```

### 特点

1. **简洁清晰**：去掉冗余信息，核心信息一目了然
2. **可点击**：文件路径在 VSCode/Cursor 终端中可点击跳转
3. **带颜色**：不同级别用不同颜色区分
4. **级别粗体**：日志级别使用粗体突出显示
5. **本地时区**：时间直观易读

## 颜色方案

| 级别 | 颜色 | ANSI代码 |
|------|------|----------|
| DEBUG | 青色 | `\x1b[36m` |
| INFO | 绿色 | `\x1b[32m` |
| WARNING | 黄色 | `\x1b[33m` |
| ERROR | 红色 | `\x1b[31m` |
| CRITICAL | 紫色 | `\x1b[35m` |
| 时间戳 | 灰色 | `\x1b[2m` |
| extra字段 | 青/紫 | `\x1b[36m`/`\x1b[35m` |

## 点击跳转

在 VSCode/Cursor 集成终端中：

1. 按住 `⌘ Cmd`（Mac）或 `Ctrl`（Windows/Linux）
2. 鼠标移到文件路径上，会出现下划线
3. 点击即可跳转到对应文件和行号

**示例**：点击 `app/engines/memory/base.py:36` → 自动打开文件并跳到第36行

## 代码实现

### 核心文件

- `backend/app/utils/logger.py`

### 关键组件

1. **format_level_compact**：去掉日志级别的空格填充
2. **format_timestamp_local**：格式化时间戳为本地时区
3. **format_callsite**：格式化代码位置为可点击链接
4. **CompactConsoleRenderer**：自定义渲染器，完全控制输出格式

### 自定义渲染器

```python
class CompactConsoleRenderer:
    """紧凑的控制台渲染器
    
    特点：
    1. 时间格式：2025-11-18 15:06:55.699
    2. 日志级别：[info] 无空格填充，带粗体
    3. 代码位置：[app/file.py:123] 无函数名
    4. 保留颜色和粗体
    """
    
    LEVEL_COLORS = {
        "debug": "\x1b[1m\x1b[36m",      # bold cyan
        "info": "\x1b[1m\x1b[32m",       # bold green
        "warning": "\x1b[1m\x1b[33m",    # bold yellow
        "error": "\x1b[1m\x1b[31m",      # bold red
        "critical": "\x1b[1m\x1b[35m",   # bold magenta
    }
```

## 兼容性

### 支持的终端

✅ **完全支持**（颜色+点击）：
- Cursor 集成终端
- VSCode 集成终端
- iTerm2（Mac）
- Windows Terminal
- 现代 Linux 终端（GNOME Terminal, Konsole等）

✅ **部分支持**（仅颜色）：
- 旧版 Mac Terminal.app
- 标准 SSH 终端

❌ **不支持**：
- 纯文本日志文件（通过 `PlainTextFormatter` 自动移除颜色代码）


## 对比总结

| 项目 | 优化前 | 优化后 | 改进 |
|------|--------|--------|------|
| 时间格式 | `2025-11-18T07:06:55.699562Z` | `2025-11-18 15:06:55.699` | 更直观，本地时区 |
| 日志级别 | `[info     ]` | `[info]` | 简洁，无空格，带粗体 |
| 代码位置 | `[file.py:123:func]` | `[file.py:123]` | 更简洁，可点击 |
| 视觉效果 | 空格填充 | 紧凑格式 | 提高可读性 |
| 行长度 | 较长 | 较短 | 更简洁 |
