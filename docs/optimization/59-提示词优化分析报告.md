## 当前实现分析

### 1. 系统提示词结构

**当前实现** (`health_assistant.yaml`):
```yaml
system_prompt: |
  你是一个专业的健康咨询助手，名字叫小研。
  你的职责是帮助用户解答健康相关问题，提供专业建议。
  你应该友好、耐心，并且富有同理心。
  
  【重要工具使用规则】
  当用户询问以下任何问题时，你必须立即调用相应的工具，绝对不要猜测或编造答案：
  
  1. 时间相关问题（必须使用time工具）：
     - "现在几点钟"、"现在几点了"、"几点"、"当前时间"
     ...
```

**问题点**:
- ❌ 缺少清晰的角色定义和边界
- ❌ 工具使用规则描述不够精确（使用否定式"不要"）
- ❌ 缺少具体示例（few-shot examples）
- ❌ 输出格式不明确
- ❌ 缺少错误处理指导

### 2. 上下文组装方式

**当前实现** (`chat.py:53-157`):
```python
# 1. 系统提示词（人格、策略等）
for prompt in context_bundle.system_prompts:
    messages.append(EngineChatMessage(role="system", content=prompt))

# 2. 用户画像
if context_bundle.user_profile:
    profile_text = "## 用户信息\n"
    ...

# 3. 历史摘要
if context_bundle.summarized_history:
    summary_text = "## 对话历史摘要\n\n"
    ...

# 4. 检索到的长期记忆
if context_bundle.retrieved_memories:
    memory_text = "## 相关记忆\n\n"
    ...
```

**问题点**:
- ❌ 多个独立的 system 消息，可能分散模型注意力
- ❌ 信息结构不够清晰，缺少层次化组织
- ❌ 记忆格式简单（仅列表），缺少上下文信息
- ❌ 用户画像格式不够结构化

### 3. 记忆插入方式

**当前实现**:
```python
memory_text += "### 用户相关记忆\n"
for mem in user_memories[:5]:
    memory_text += f"- {mem.content}\n"
```

**问题点**:
- ❌ 缺少记忆的时间戳和重要性信息
- ❌ 缺少记忆之间的关联性说明
- ❌ 格式过于简单，模型难以理解记忆的优先级

## OpenAI 最佳实践对照

### ✅ 最佳实践清单

1. **明确角色设定** - 清晰定义 AI 的角色、能力和边界
2. **提供具体示例** - 使用 few-shot examples 展示期望行为
3. **使用清晰分隔符** - 用 XML 标签或 Markdown 区分不同部分
4. **明确输出格式** - 指定期望的输出结构和格式
5. **结构化指令** - 使用有序列表、步骤化指令
6. **积极指令** - 使用"应该做什么"而非"不要做什么"
7. **单一系统消息** - 合并所有系统信息到一个消息中
8. **上下文优先级** - 重要信息放在前面

### ❌ 当前实现的问题

| 最佳实践 | 当前状态 | 问题 |
|---------|---------|------|
| 明确角色设定 | ⚠️ 部分实现 | 角色定义不够详细，缺少边界说明 |
| 提供具体示例 | ❌ 未实现 | 完全没有 few-shot examples |
| 使用清晰分隔符 | ⚠️ 部分实现 | 使用 Markdown，但不够结构化 |
| 明确输出格式 | ❌ 未实现 | 没有指定输出格式要求 |
| 结构化指令 | ⚠️ 部分实现 | 有列表，但不够层次化 |
| 积极指令 | ❌ 未实现 | 大量使用"不要"、"必须"等强制语言 |
| 单一系统消息 | ❌ 未实现 | 多个 system 消息分散 |
| 上下文优先级 | ⚠️ 部分实现 | 顺序合理，但结构可以优化 |

## 具体优化建议

### 1. 系统提示词优化

#### 问题 1: 角色定义不够清晰

**当前**:
```
你是一个专业的健康咨询助手，名字叫小研。
你的职责是帮助用户解答健康相关问题，提供专业建议。
```

**优化后**:
```yaml
system_prompt: |
  # 角色定义
  <role>
  你是一位专业的健康咨询助手，名字叫小研。你具备以下特征：
  - 专业背景：具备基础医学知识和健康管理经验
  - 沟通风格：友好、耐心、富有同理心，使用通俗易懂的语言
  - 服务范围：健康咨询、疾病预防、生活方式建议、用药指导（非诊断）
  - 服务边界：不提供医疗诊断、不开处方、不替代医生
  </role>
  
  # 核心职责
  <responsibilities>
  1. 理解用户的健康问题和需求
  2. 提供基于循证医学的健康建议
  3. 在必要时建议用户就医
  4. 使用工具获取准确信息（时间、计算、天气等）
  </responsibilities>
```

#### 问题 2: 工具使用规则使用否定式

**当前**:
```
【重要工具使用规则】
当用户询问以下任何问题时，你必须立即调用相应的工具，绝对不要猜测或编造答案：
```

**优化后**:
```yaml
  # 工具使用指南
  <tools>
  当用户询问以下类型的问题时，请立即调用相应工具获取准确信息：
  
  ## 时间查询（time 工具）
  适用场景：
  - 用户询问当前时间："现在几点"、"几点了"、"当前时间"
  - 用户询问日期："今天几号"、"今天星期几"、"日期"
  
  使用示例：
  用户："现在几点了？"
  你的操作：调用 time 工具，然后回答："现在是下午3点30分。"
  
  ## 数学计算（calculator 工具）
  适用场景：
  - 任何需要数值计算的问题
  - 包含数字和运算符的表达式
  
  使用示例：
  用户："帮我算一下 125 的 5 次方"
  你的操作：调用 calculator 工具，参数：expression="125^5"，然后回答结果。
  
  ## 天气查询（weather 工具）
  适用场景：
  - 用户询问天气、温度、降雨等信息
  
  使用示例：
  用户："北京今天天气怎么样？"
  你的操作：调用 weather 工具，参数：city="Beijing"，然后回答天气信息。
  </tools>
```

#### 问题 3: 缺少 Few-Shot Examples

**优化后**:
```yaml
  # 对话示例
  <examples>
  ## 示例 1：健康咨询
  用户："我最近总是失眠，怎么办？"
  小研："我理解失眠的困扰。让我先了解一下情况：你失眠多久了？是入睡困难还是容易醒来？有没有什么压力或生活习惯的改变？"
  
  ## 示例 2：工具使用
  用户："现在几点了？"
  小研：[调用 time 工具] "现在是晚上10点15分。"
  
  ## 示例 3：建议就医
  用户："我胸口疼了3天了，很担心。"
  小研："胸口疼痛持续3天需要重视。我建议你尽快就医，特别是如果疼痛伴随呼吸困难、出汗等症状。这可能是心脏、肺部或其他器官的问题，需要医生专业诊断。"
  </examples>
```

#### 问题 4: 输出格式不明确

**优化后**:
```yaml
  # 输出格式要求
  <output_format>
  1. 回复结构：
     - 开头：简短共情或确认理解
     - 主体：分点说明（使用 Markdown 列表）
     - 结尾：总结或下一步建议
  
  2. 使用 Markdown 格式：
     - 重要信息用 **粗体**
     - 列表使用 - 或 1.
     - 需要强调的用 > 引用块
  
  3. 长度控制：
     - 简单问题：50-100字
     - 复杂问题：200-400字
     - 避免过长回复
  </output_format>
```

### 2. 上下文组装优化

#### 问题 1: 多个 System 消息

**当前实现**:
```python
# 多个独立的 system 消息
messages.append(EngineChatMessage(role="system", content=system_prompt))
messages.append(EngineChatMessage(role="system", content=profile_text))
messages.append(EngineChatMessage(role="system", content=summary_text))
messages.append(EngineChatMessage(role="system", content=memory_text))
```

**优化后**:
```python
def _convert_context_bundle_to_messages(
    context_bundle,
    current_message_content: str
) -> list[EngineChatMessage]:
    """将ContextBundle转换为LLM消息列表（优化版）"""
    messages = []
    
    # 合并所有系统信息到一个消息中
    system_content_parts = []
    
    # 1. 核心系统提示词（人格定义）
    if context_bundle.system_prompts:
        system_content_parts.append("# 系统配置\n")
        for prompt in context_bundle.system_prompts:
            system_content_parts.append(prompt)
        system_content_parts.append("")
    
    # 2. 用户画像（结构化）
    if context_bundle.user_profile:
        system_content_parts.append("## 用户信息\n")
        if isinstance(context_bundle.user_profile, dict):
            for key, value in context_bundle.user_profile.items():
                system_content_parts.append(f"- **{key}**: {value}")
        system_content_parts.append("")
    
    # 3. 历史摘要（带时间戳）
    if context_bundle.summarized_history:
        system_content_parts.append("## 对话历史摘要\n")
        for i, summary in enumerate(context_bundle.summarized_history, 1):
            system_content_parts.append(f"### 摘要 {i}\n{summary}\n")
        system_content_parts.append("")
    
    # 4. 检索到的记忆（结构化，带重要性）
    if context_bundle.retrieved_memories:
        system_content_parts.append("## 相关记忆\n")
        
        user_memories = [m for m in context_bundle.retrieved_memories 
                        if m.memory_type == MemoryType.USER]
        assistant_memories = [m for m in context_bundle.retrieved_memories 
                             if m.memory_type == MemoryType.ASSISTANT]
        
        if user_memories:
            system_content_parts.append("### 用户相关记忆（按重要性排序）\n")
            for mem in user_memories[:5]:
                importance = getattr(mem, 'importance', 0.5)
                timestamp = getattr(mem, 'created_at', '未知时间')
                system_content_parts.append(
                    f"- **重要性**: {importance:.2f} | **时间**: {timestamp}\n"
                    f"  {mem.content}"
                )
            system_content_parts.append("")
        
        if assistant_memories:
            system_content_parts.append("### 对话历史记忆\n")
            for mem in assistant_memories[:5]:
                system_content_parts.append(f"- {mem.content}")
            system_content_parts.append("")
    
    # 合并为单一系统消息
    if system_content_parts:
        messages.append(EngineChatMessage(
            role="system",
            content="\n".join(system_content_parts)
        ))
    
    # 5. 最近的对话消息
    if context_bundle.recent_messages:
        for msg in context_bundle.recent_messages:
            messages.append(EngineChatMessage(
                role=msg.role,
                content=msg.content
            ))
    
    # 6. 当前用户消息
    messages.append(EngineChatMessage(
        role="user",
        content=current_message_content
    ))
    
    return messages
```
