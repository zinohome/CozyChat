# 记忆系统优化方案

## 问题分析

### 当前问题

1. **硬编码的返回值数量**：`result = all_memories[:5]` - 硬编码为5
2. **硬编码的关键词列表**：`['身高', '体重', '年龄', '高', '重', '岁']` - 硬编码在代码中
3. **硬编码的评分权重**：`score += 0.5`, `score += 0.3`, `score += 0.1` - 硬编码在代码中
4. **硬编码的查询类型检测**：`['身高', '体重', '年龄', '多少', '几', '多高', '多重', '多大']` - 硬编码在代码中
5. **硬编码的内容长度阈值**：`10 <= len(content) <= 100` - 硬编码在代码中

### 影响

- 无法根据不同人格配置不同的检索策略
- 无法根据不同场景调整筛选逻辑
- 难以扩展和维护
- 不符合配置驱动的设计原则

## 优化方案

### 1. 扩展 MemoryRetrieval 配置模型

在 `MemoryRetrieval` 中添加智能筛选配置：

```python
@dataclass
class IntelligentScoring:
    """智能评分配置"""
    enabled: bool = True
    # 数值查询检测关键词
    numeric_query_keywords: List[str] = field(default_factory=lambda: [
        '身高', '体重', '年龄', '多少', '几', '多高', '多重', '多大'
    ])
    # 数值记忆关键词（用于匹配记忆内容）
    numeric_memory_keywords: List[str] = field(default_factory=lambda: [
        '身高', '体重', '年龄', '高', '重', '岁'
    ])
    # 评分权重
    weights: Dict[str, float] = field(default_factory=lambda: {
        'numeric_boost': 0.5,      # 包含数字的加分
        'keyword_match_boost': 0.3,  # 同时包含关键词和数字的加分
        'length_boost': 0.1,        # 内容长度适中的加分
    })
    # 内容长度范围
    optimal_length_range: Tuple[int, int] = (10, 100)

@dataclass
class MemoryRetrieval:
    """记忆检索配置"""
    max_results: int = 5
    similarity_threshold: float = 0.7
    timeout_seconds: float = 0.5
    cache_ttl_seconds: int = 300
    # 新增：智能筛选配置
    intelligent_scoring: IntelligentScoring = field(default_factory=IntelligentScoring)
```

### 3. 重构 ContextBuilder._retrieve_memories

移除所有硬编码，使用配置：

```python
async def _retrieve_memories(
    self,
    user_id: str,
    session_id: str,
    query: str,
    personality_config: Optional[Personality] = None
) -> List[Any]:
    """检索相关记忆"""
    # 从配置获取参数
    if personality_config and hasattr(personality_config, 'memory'):
        retrieval_config = personality_config.memory.retrieval
        max_results = retrieval_config.max_results
        intelligent_scoring = retrieval_config.intelligent_scoring
    else:
        max_results = 5
        intelligent_scoring = IntelligentScoring()  # 使用默认值
    
    # 检索记忆...
    
    # 智能筛选（如果启用）
    if intelligent_scoring.enabled:
        all_memories = self._apply_intelligent_scoring(
            all_memories, 
            query, 
            intelligent_scoring
        )
    
    # 使用配置的 max_results
    result = all_memories[:max_results]
    
    return result
```

### 4. 提取智能评分逻辑为独立方法

```python
def _apply_intelligent_scoring(
    self,
    memories: List[MemorySearchResult],
    query: str,
    config: IntelligentScoring
) -> List[MemorySearchResult]:
    """应用智能评分"""
    # 检测查询类型
    is_numeric_query = any(
        keyword in query 
        for keyword in config.numeric_query_keywords
    )
    
    def score_memory(mem_result):
        score = mem_result.similarity
        
        if is_numeric_query:
            has_number = bool(re.search(r'\d+', mem_result.memory.content))
            if has_number:
                score += config.weights['numeric_boost']
                
                if any(
                    kw in mem_result.memory.content 
                    for kw in config.numeric_memory_keywords
                ):
                    score += config.weights['keyword_match_boost']
        
        # 内容长度评分
        content_len = len(mem_result.memory.content)
        if config.optimal_length_range[0] <= content_len <= config.optimal_length_range[1]:
            score += config.weights['length_boost']
        
        return score
    
    # 排序
    scored = [(score_memory(m), m) for m in memories]
    scored.sort(key=lambda x: x[0], reverse=True)
    return [m for _, m in scored]
```

## 优势

1. **可配置**：所有参数都可以通过配置文件调整
2. **可扩展**：可以轻松添加新的关键词和评分规则
3. **可维护**：逻辑清晰，易于理解和修改
4. **灵活**：不同人格可以使用不同的检索策略
5. **符合设计原则**：配置驱动，而非硬编码
