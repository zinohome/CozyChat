```sql
CREATE TABLE session_contexts (
    id UUID PRIMARY KEY,
    session_id UUID REFERENCES sessions(id) ON DELETE CASCADE,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    context_type VARCHAR(50) NOT NULL,  -- 'history_summary'
    content TEXT NOT NULL,              -- 摘要文本
    start_message_index INTEGER NOT NULL,
    end_message_index INTEGER NOT NULL,
    message_count INTEGER NOT NULL,

    vector_id VARCHAR(255),             -- Qdrant向量ID
    metadata JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 1.3 ContextBuilder服务 ✅

**文件**: `backend/app/core/context/builder.py`

#### 1.3.1 核心功能

`ContextBuilder`负责为LLM对话构建优化的分层上下文：

```python
class ContextBuilder:
    """智能上下文构建器"""
    
    async def build_context(
        self,
        user_id: str,
        session_id: str,
        current_message: str,
        personality_config: Personality,
        recent_message_count: Optional[int] = None,
        include_memories: bool = True,
        include_summaries: bool = True,
        max_tokens: Optional[int] = None
    ) -> ContextBundle:
        """构建智能上下文"""
```

#### 1.3.2 分层上下文模型

**第一层：最近会话原文**
- 保留最近N条（默认6条）原文对话
- 不做压缩，保持完整语义

**第二层：中段历史摘要**
- 对更早的对话进行摘要
- 从`session_contexts`表加载

**第三层：长期记忆**
- 使用`MemoryManager`检索相关记忆
- 基于相似度和重要性筛选

**第四层：用户画像**
- 从用户表加载偏好和配置

#### 1.3.3 构建流程

```python
# 并发执行各个组件
tasks = [
    self._get_recent_messages(session_id, recent_message_count),
    self._load_history_summaries(session_id),
    self._retrieve_memories(user_id, session_id, current_message),
    self._load_user_profile(user_id),
]

recent_messages, summaries, memories, user_profile = await asyncio.gather(*tasks)

# 组装上下文
context_bundle = self._assemble_context(
    personality_config, recent_messages, summaries, memories, user_profile, max_tokens
)
```

#### 1.3.4 性能优化

- **并发执行**: 使用`asyncio.gather`并发获取各层数据
- **降级机制**: 失败时返回基本上下文，不影响对话
- **Token估算**: 简单估算总token数，避免超限

### 1.4 SummaryGenerator服务 ✅

**文件**: `backend/app/core/context/summary_generator.py`

#### 1.4.1 核心功能

`SummaryGenerator`负责生成对话历史的结构化摘要：

```python
class SummaryGenerator:
    """历史摘要生成器"""
    
    async def generate_summary(
        self,
        session_id: str,
        user_id: str,
        start_message_index: int,
        end_message_index: int,
        force: bool = False
    ) -> Optional[HistorySummaryResponse]:
        """生成历史摘要"""
```

#### 1.4.2 摘要生成流程

1. **检查已存在摘要** - 避免重复生成（除非`force=True`）
2. **获取消息列表** - 从数据库查询指定范围的消息
3. **格式化对话** - 将消息格式化为易读的对话文本
4. **调用LLM生成** - 使用配置的模型（默认`gpt-4o-mini`）生成摘要
5. **存储摘要** - 同时存储到PostgreSQL和Qdrant（向量）

#### 1.4.3 摘要prompt模板

```python
SUMMARY_PROMPT_TEMPLATE = """请将以下对话历史压缩为简洁的摘要，保留：
1. 讨论的主要话题和内容

3. 重要的结论和待办事项
4. 情感基调和互动特点

对话内容：
{conversation}

请生成200字以内的摘要："""
```

#### 1.4.4 触发策略

```python
async def should_generate_summary(self, session_id: str) -> bool:
    """判断是否应该生成新摘要"""
    # 计算未摘要的消息数
    unsummarized_count = total_messages - last_summary.end_message_index
    
    # 达到阈值时触发
    return unsummarized_count >= settings.context_summary_trigger_count
```

**触发条件**:
- 消息数量达到阈值（默认50条）
- 可配置为时间间隔触发

#### 1.4.5 双重存储

**PostgreSQL存储**:
- 存储摘要文本、消息范围、token统计
- 快速查询和索引

**Qdrant存储**:
- 将摘要作为特殊记忆存储向量
- 支持语义检索
- metadata标记`is_summary: true`

```python
async def get_context_builder(db: Session = Depends(get_db)):
    """获取上下文构建器"""

    return SummaryGenerator(
        engine_pool=engine_pool,
```

## 3. 技术亮点

### 3.1 分层上下文策略

通过分层模型优化token使用：
- **短期记忆**：保留最近对话原文
- **中期记忆**：历史摘要压缩
- **长期记忆**：向量检索相关记忆
- **用户画像**：持久化用户信息

预期token节省：**20-30%**

### 3.2 并发构建

使用`asyncio.gather`并发执行：
- 读取最近消息
- 加载历史摘要
- 检索长期记忆
- 加载用户画像

**目标构建时间**: < 200ms

### 3.3 双重存储策略

摘要同时存储在：
- **PostgreSQL**: 快速查询、索引、事务
- **Qdrant**: 语义检索、向量相似度

### 3.4 智能触发

基于阈值自动触发摘要生成：
- 消息数量阈值
- 时间间隔阈值
- 存储压力阈值

### 3.5 降级机制

构建失败时的优雅降级：
- 返回基本上下文（仅人格配置）
- 记录错误但不中断对话
- 保证系统可用性

## 4. 使用示例

### 4.1 在Chat API中使用ContextBuilder

```python
from fastapi import Depends
from app.core.context.builder import ContextBuilder
from app.api.deps import get_context_builder

@router.post("/chat/completions")
async def create_chat_completion(
    request: ChatRequest,
    user: User = Depends(get_current_user),
    context_builder: ContextBuilder = Depends(get_context_builder),
    personality_registry = Depends(get_personality_registry)
):
    # 构建智能上下文
    context_bundle = await context_builder.build_context(
        user_id=str(user.id),
        session_id=str(request.session_id),
        current_message=request.messages[-1]["content"],
        personality_config=personality_registry.get_personality(request.personality_id)
    )
    
    # 使用context_bundle组装LLM消息
    llm_messages = []
    
    # 1. 系统提示词
    for prompt in context_bundle.system_prompts:
        llm_messages.append({"role": "system", "content": prompt})
    
    # 2. 历史摘要
    if context_bundle.summarized_history:
        summary_text = "\\n".join(context_bundle.summarized_history)
        llm_messages.append({
            "role": "system",
            "content": f"对话历史摘要：{summary_text}"
        })
    
    # 3. 相关记忆
    if context_bundle.retrieved_memories:
        memory_text = "\\n".join([m.content for m in context_bundle.retrieved_memories])
        llm_messages.append({
            "role": "system",
            "content": f"相关记忆：{memory_text}"
        })
    
    # 4. 最近消息
    for msg in context_bundle.recent_messages:
        llm_messages.append({
            "role": msg.role,
            "content": msg.content
        })
    
    # 调用LLM
    response = await engine.chat_completion(messages=llm_messages, ...)
```

```python
from app.core.context.summary_generator import SummaryGenerator
from app.api.deps import get_summary_generator

@router.post("/chat/completions")

    request: ChatRequest,
```
