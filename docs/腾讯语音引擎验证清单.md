## 功能验证

### 1. 快速测试

```bash
cd backend
python scripts/test_tencent_engines.py
```

预期结果：所有测试通过

### 2. ASR功能验证

准备一个测试音频文件 `test.wav`，然后运行：

```python
import asyncio
from app.engines.voice.stt import STTEngineFactory

async def test():
    engine = STTEngineFactory.create_engine("tencent")
    
    with open("test.wav", "rb") as f:
        audio_data = f.read()
    
    # 测试一句话识别
    text1 = await engine.transcribe(audio_data, flash=True)
    print(f"一句话识别: {text1}")
    
    # 测试实时识别
    text2 = await engine.transcribe(audio_data, realtime=True)
    print(f"实时识别: {text2}")
    
    # 测试自动选择
    text3 = await engine.transcribe(audio_data)
    print(f"自动选择: {text3}")

asyncio.run(test())
```

### 3. TTS功能验证

```python
import asyncio
from app.engines.voice.tts import TTSEngineFactory

async def test():
    engine = TTSEngineFactory.create_engine("tencent")
    
    # 测试所有音色
    voices = ["female", "male", "mature_male", "energetic_male", "warm_female", "warm_male"]
    
    for voice in voices:
        print(f"\n测试音色: {voice}")
        
        # 非流式合成
        audio = await engine.synthesize(
            f"这是{voice}音色的测试",
            voice=voice,
            speed=1.0
        )
        
        with open(f"/tmp/tts_{voice}.mp3", "wb") as f:
            f.write(audio)
        
        print(f"✅ {voice} 合成完成: {len(audio)} 字节")

asyncio.run(test())
```

### 4. 流式合成验证

```python
import asyncio
from app.engines.voice.tts import TTSEngineFactory

async def test():
    engine = TTSEngineFactory.create_engine("tencent")
    
    text = "这是一段很长的文本，用于测试流式合成。" * 10
    
    chunks = []
    async for chunk in engine.stream_synthesize(text, voice="female", speed=1.0):
        chunks.append(chunk)
        print(f"收到音频块: {len(chunk)} 字节")
    
    audio_data = b"".join(chunks)
    with open("/tmp/stream_test.mp3", "wb") as f:
        f.write(audio_data)
    
    print(f"✅ 流式合成完成: {len(chunks)} 个块, 总计 {len(audio_data)} 字节")

asyncio.run(test())
```

## 性能验证

### ASR性能

**一句话识别**:
- 预期延迟: < 1秒（短音频）
- 适用场景: < 60秒的音频

**实时识别**:
- 预期延迟: 实时
- 适用场景: 长音频或实时对话

**测试命令**:
```bash
cd backend
time python -c "
import asyncio
from app.engines.voice.stt import STTEngineFactory

async def test():
    engine = STTEngineFactory.create_engine('tencent')
    with open('test.wav', 'rb') as f:
        await engine.transcribe(f.read(), flash=True)

asyncio.run(test())
"
```

### TTS性能

**HTTP流式合成**:
- 预期首包延迟: < 500ms
- 适用场景: 短文本

**WebSocket流式合成**:
- 预期首包延迟: < 300ms
- 适用场景: 长文本

**测试命令**:
```bash
cd backend
time python -c "
import asyncio
from app.engines.voice.tts import TTSEngineFactory

async def test():
    engine = TTSEngineFactory.create_engine('tencent')
    await engine.synthesize('测试文本', voice='female')

asyncio.run(test())
"
```
