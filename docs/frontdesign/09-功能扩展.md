# 09. 功能扩展

## 文档概述

本文档描述 CozyChat 未来可能的功能扩展，包括注册页面增强、新增一级页面（首页、健康知识、健康圈），以及将聊天页面转为二级页面的架构调整。

## 1. 注册页面扩展

### 1.1 多步骤注册流程

#### 功能要求

1. **步骤一：基础信息**
   - 用户名输入
   - 邮箱输入
   - 密码输入
   - 确认密码输入
   - 下一步按钮

2. **步骤二：个人信息**（可选）
   - 显示名称
   - 性别选择
   - 年龄输入
   - 上一步/下一步按钮

3. **步骤三：健康信息**（可选）
   - 健康目标选择
   - 健康状况选择
   - 上一步/完成注册按钮

4. **步骤指示器**
   - 显示当前步骤
   - 显示总步骤数
   - 显示已完成步骤

#### 视觉要求

- 步骤指示器：顶部显示，进度条样式
- 表单区域：居中显示，卡片样式
- 按钮：底部固定，主按钮样式

### 1.2 邮箱验证

#### 功能要求

1. **验证流程**
   - 注册后发送验证邮件
   - 显示验证提示页面
   - 用户点击邮件链接验证
   - 验证成功后激活账户

2. **验证提示页面**
   - 显示邮箱地址
   - 显示"已发送验证邮件"提示
   - 提供"重新发送"按钮
   - 提供"修改邮箱"链接

3. **验证成功页面**
   - 显示验证成功提示
   - 提供"立即登录"按钮

#### 视觉要求

- 提示页面：居中显示，卡片样式
- 图标：邮件图标，大尺寸
- 按钮：主按钮样式

### 1.3 第三方登录

#### 功能要求

1. **登录方式**
   - 微信登录
   - 支付宝登录
   - 手机号登录（可选）

2. **登录按钮**
   - 显示第三方图标
   - 显示"使用微信登录"等文字
   - 点击跳转到第三方授权页面

#### 视觉要求

- 登录按钮：大尺寸，图标 + 文字
- 分隔线：显示"或"分隔符
- 布局：垂直排列

## 2. 首页（Home Page）

### 2.1 页面概述

首页作为应用的主入口，提供快速导航、健康概览、推荐内容等功能。

### 2.2 路由

- 路径：`/home` 或 `/`
- 访问权限：需要登录（受保护路由）
- 导航层级：一级页面

### 2.3 功能要求

1. **顶部横幅**
   - 欢迎信息（如："欢迎回来，{用户名}"）
   - 日期显示
   - 快捷操作按钮（可选）

2. **健康概览卡片**
   - 今日步数
   - 今日卡路里
   - 今日运动时长
   - 健康评分（可选）

3. **快速入口**
   - 健康档案入口
   - 健康知识入口
   - 健康圈入口
   - 聊天入口

4. **推荐内容**
   - 健康文章推荐
   - 健康视频推荐（可选）
   - 健康计划推荐

5. **最近会话**
   - 显示最近 3-5 个会话
   - 点击跳转到聊天页面
   - 显示最后一条消息预览

6. **健康提醒**
   - 用药提醒
   - 体检提醒
   - 运动提醒

### 2.4 页面布局

```
┌─────────────────────────────────────────┐
│      Header (顶部导航栏)                 │
├─────────────────────────────────────────┤
│      Welcome Banner (欢迎横幅)           │
├─────────────────────────────────────────┤
│      Health Overview (健康概览卡片)      │
├─────────────────────────────────────────┤
│      Quick Access (快速入口)            │
│      ┌──────┐ ┌──────┐ ┌──────┐         │
│      │ 健康 │ │ 知识 │ │ 圈子 │         │
│      │ 档案 │ │      │ │      │         │
│      └──────┘ └──────┘ └──────┘         │
├─────────────────────────────────────────┤
│      Recent Sessions (最近会话)         │
├─────────────────────────────────────────┤
│      Recommended Content (推荐内容)      │
├─────────────────────────────────────────┤
│      Health Reminders (健康提醒)        │
└─────────────────────────────────────────┘
```

### 2.5 视觉要求

1. **卡片样式**
   - 白色或主题背景色
   - 圆角：8px
   - 阴影：轻微阴影
   - 内边距：16px

2. **快速入口**
   - 网格布局：3 列（桌面端），2 列（移动端）
   - 图标：48x48px
   - 文字：14px，居中
   - 卡片高度：120px

3. **推荐内容**
   - 列表布局
   - 图片 + 标题 + 摘要
   - 点击跳转到详情页

### 2.6 响应式设计

- 桌面端：多列布局，信息密度高
- 移动端：单列布局，信息密度适中
- 支持下拉刷新（移动端）

## 3. 健康知识页面（Health Knowledge）

### 3.1 页面概述

健康知识页面提供健康相关的文章、视频、资讯等内容，支持分类浏览、搜索、收藏等功能。

### 3.2 路由

- 路径：`/knowledge`
- 访问权限：需要登录（受保护路由）
- 导航层级：一级页面

### 3.3 功能要求

1. **顶部搜索栏**
   - 搜索框
   - 搜索按钮
   - 支持搜索文章标题、内容

2. **分类导航**
   - 横向滚动分类标签
   - 分类：全部、疾病预防、营养健康、运动健身、心理健康等
   - 点击切换分类

3. **内容列表**
   - 文章卡片列表
   - 每条包含：
     - 封面图片
     - 标题
     - 摘要
     - 作者/来源
     - 发布时间
     - 阅读量
     - 收藏按钮

4. **筛选功能**
   - 按时间排序（最新、最热）
   - 按类型筛选（文章、视频）
   - 按标签筛选

5. **详情页面**
   - 文章详情
   - 视频播放（如有）
   - 相关推荐
   - 评论功能（可选）

### 3.4 页面布局

```
┌─────────────────────────────────────────┐
│      Header (顶部导航栏)                 │
├─────────────────────────────────────────┤
│      Search Bar (搜索栏)                │
├─────────────────────────────────────────┤
│      Category Tabs (分类标签)           │
├─────────────────────────────────────────┤
│      Content List (内容列表)             │
│      ┌─────────────────────────────┐    │
│      │  [图片] 标题                │    │
│      │  摘要...                    │    │
│      │  作者 | 时间 | 阅读量       │    │
│      └─────────────────────────────┘    │
│      ...                                 │
└─────────────────────────────────────────┘
```

### 3.5 视觉要求

1. **文章卡片**
   - 水平布局
   - 左侧：封面图片（120x80px）
   - 右侧：标题、摘要、元信息
   - 卡片间距：16px

2. **分类标签**
   - 胶囊样式
   - 选中状态：主色背景，白色文字
   - 未选中：浅色背景，深色文字

3. **搜索栏**
   - 高度：48px
   - 圆角：24px
   - 内边距：12px 16px

### 3.6 交互要求

- 点击文章：跳转到详情页
- 点击收藏：切换收藏状态
- 下拉刷新：刷新内容列表
- 上拉加载：加载更多内容

## 4. 健康圈页面（Health Circle）

### 4.1 页面概述

健康圈页面提供社区功能，用户可以发布动态、查看他人动态、互动评论等。

### 4.2 路由

- 路径：`/circle`
- 访问权限：需要登录（受保护路由）
- 导航层级：一级页面

### 4.3 功能要求

1. **发布动态**
   - 发布按钮（固定在底部或顶部）
   - 发布内容：文字、图片、视频
   - 支持话题标签
   - 支持@用户

2. **动态列表**
   - 时间线布局
   - 每条动态包含：
     - 用户头像和名称
     - 发布时间
     - 动态内容（文字、图片、视频）
     - 互动按钮（点赞、评论、分享）
     - 评论列表

3. **互动功能**
   - 点赞：点击点赞按钮
   - 评论：点击评论按钮，弹出评论框
   - 分享：点击分享按钮，分享到其他平台

4. **筛选功能**
   - 全部动态
   - 关注的人
   - 热门动态
   - 话题筛选

5. **用户主页**
   - 点击用户头像/名称跳转
   - 显示用户信息
   - 显示用户动态列表

### 4.4 页面布局

```
│      Timeline (动态时间线)               │

│      │  动态内容...                 │    │

│      │  👍 10  💬 5  🔗 2          │    │

│      ...                                 │
└─────────────────────────────────────────┘
```

### 4.5 视觉要求

1. **动态卡片**
   - 白色或主题背景色
   - 圆角：8px
   - 内边距：16px
   - 卡片间距：12px

2. **用户信息**
   - 头像：40x40px，圆形
   - 用户名：14px，加粗
   - 时间：12px，灰色

3. **互动按钮**
   - 图标 + 数字

   - 选中状态：主色

### 4.6 交互要求

- 点击发布：弹出发布对话框

- 点击评论：展开评论列表

## 5. 聊天页面转为二级页面

### 5.1 架构调整概述

将聊天页面从一级页面调整为二级页面，作为首页的一个功能模块。用户可以通过首页的快速入口进入聊天页面。

### 5.2 路由调整

#### 当前路由结构

```
/ (根路径) → /chat (聊天页面，一级)
/chat/:sessionId (聊天会话，一级)
```

#### 调整后路由结构

```
/ (根路径) → /home (首页，一级)
/home/chat (聊天页面，二级)
/home/chat/:sessionId (聊天会话，二级)
```

### 5.3 导航调整

#### 一级导航（底部导航栏）

- 首页（HomeOutlined）
- 健康知识（BookOutlined）
- 健康圈（TeamOutlined）
- 健康档案（HeartOutlined）
- 我的（UserOutlined）

#### 二级导航（页面内导航）

- 首页内：快速入口（健康档案、健康知识、健康圈、聊天）
- 聊天页面：保持现有导航结构

### 5.4 布局调整

#### 首页布局

```
┌─────────────────────────────────────────┐
│      Header (顶部导航栏)                 │
├─────────────────────────────────────────┤
│      Main Content (主要内容)            │
│      - 健康概览                          │
│      - 快速入口                          │
│      - 最近会话                          │
│      - 推荐内容                          │
├─────────────────────────────────────────┤
│      Bottom Nav (底部导航栏)            │
└─────────────────────────────────────────┘
```

#### 聊天页面布局（作为二级页面）

```
┌─────────────────────────────────────────┐
│      Header (返回按钮 + 标题)            │
├─────────────────────────────────────────┤
│      Chat Content (聊天内容)            │
│      - 会话头部                          │
│      - 消息列表                          │
│      - 输入区域                          │
└─────────────────────────────────────────┘
```

### 5.5 功能调整

1. **首页快速入口**
   - 添加"聊天"入口
   - 点击跳转到 `/home/chat`
   - 显示未读消息数量（如有）

2. **最近会话**
   - 显示在首页
   - 点击会话跳转到 `/home/chat/:sessionId`
   - 显示最后一条消息预览

3. **聊天页面**
   - 添加返回按钮
   - 点击返回首页
   - 保持现有功能不变

### 5.6 视觉调整

1. **首页聊天入口**
   - 与其他快速入口保持一致
   - 图标：消息图标
   - 显示未读消息徽章（如有）

2. **聊天页面头部**
   - 返回按钮：左侧箭头图标
   - 标题："AI 助手"或当前会话标题
   - 操作按钮：新建会话、设置等

### 5.7 迁移方案

1. **路由迁移**
   - 保留旧路由 `/chat` 作为重定向
   - 新路由 `/home/chat` 作为主要入口
   - 逐步迁移用户

2. **数据迁移**
   - 会话数据保持不变
   - 用户偏好保持不变
   - 历史消息保持不变

3. **兼容性处理**
   - 旧链接自动跳转到新路由
   - 保持 URL 参数传递
   - 保持状态管理
