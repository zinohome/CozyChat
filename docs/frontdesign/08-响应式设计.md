# 08. 响应式设计

## 设计概述

CozyChat 采用响应式设计，支持桌面端、平板端和移动端。使用断点系统实现不同屏幕尺寸的适配。

## 1. 断点系统

### 断点定义

| 设备类型 | 屏幕宽度 | 断点 |
|---------|---------|------|
| 移动端 | < 768px | `isMobile` |
| 平板端 | 768px - 1024px | `isTablet`（可选） |
| 桌面端 | ≥ 768px | `!isMobile` |

### 断点使用

```typescript
// 使用 useIsMobile Hook
const isMobile = useIsMobile(); // < 768px

// 条件渲染
{isMobile ? <MobileComponent /> : <DesktopComponent />}

// 条件样式
style={{ padding: isMobile ? '12px' : '24px' }}
```

## 2. 布局适配

### 2.1 Header（顶部导航栏）

#### 桌面端（≥768px）

- 高度：64px
- Logo：左侧显示
- 用户信息：右侧显示
- 菜单按钮：隐藏

#### 移动端（<768px）

- 高度：64px
- 菜单按钮：左侧显示
- Logo：居中或左侧显示
- 用户信息：右侧显示

### 2.2 Sidebar（侧边栏）

#### 桌面端（≥768px）

- 宽度：280px（固定）
- 位置：左侧固定显示
- 显示方式：始终显示

#### 移动端（<768px）

- 宽度：280px
- 位置：抽屉式（Drawer）
- 显示方式：点击菜单按钮打开
- 遮罩层：半透明黑色背景

### 2.3 Content（内容区域）

#### 桌面端（≥768px）

- 宽度：自适应（减去 Header 和 Sidebar）
- 内边距：24px
- 最大宽度：1920px（可选，居中显示）

#### 移动端（<768px）

- 宽度：100%
- 内边距：12px
- 全屏显示

### 2.4 MobileNav（移动端底部导航）

#### 桌面端（≥768px）

- 显示：隐藏

#### 移动端（<768px）

- 显示：固定底部
- 高度：56px
- 包含：聊天、健康档案、个人资料、设置

## 3. 组件适配

### 3.1 聊天页面

#### 桌面端

- 消息最大宽度：70%
- 输入框：多行显示
- 工具栏：图标 + 文字
- 会话头部：完整显示

#### 移动端

- 消息最大宽度：85%
- 输入框：自适应高度
- 工具栏：仅图标
- 会话头部：紧凑显示

### 3.2 表单页面

#### 桌面端

- 卡片最大宽度：800px
- 表单字段：左右布局（标签左侧，控件右侧）
- 内边距：24px

#### 移动端

- 卡片宽度：100%（减去内边距）
- 表单字段：上下布局（标签上方，控件下方）
- 内边距：16px

### 3.3 列表页面

#### 桌面端

- 列表项：水平布局
- 信息密度：较高
- 操作按钮：悬停显示

#### 移动端

- 列表项：垂直布局
- 信息密度：适中
- 操作按钮：始终显示

## 4. 字体系统

### 字体大小

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| 页面标题 | 24px | 20px |
| 卡片标题 | 18px | 16px |
| 正文 | 14px | 16px（避免 iOS 自动缩放） |
| 辅助文字 | 12px | 14px |
| 按钮文字 | 14px | 16px |

### 行高

- 标题：1.5
- 正文：1.6
- 按钮：1.5

## 5. 间距系统

### 基准间距

- 基准单位：8px
- 常用间距：8px、12px、16px、24px、32px

### 间距使用

| 场景 | 桌面端 | 移动端 |
|------|--------|--------|
| 页面内边距 | 24px | 12px |
| 卡片内边距 | 24px | 16px |
| 组件间距 | 16px | 12px |
| 元素间距 | 8px | 8px |

## 6. 触摸优化

### 触摸目标尺寸

- 最小尺寸：44x44px（iOS 推荐）
- 推荐尺寸：48x48px
- 按钮间距：至少 8px

### 触摸反馈

- 点击反馈：背景色变化
- 长按反馈：显示操作菜单（可选）
- 滑动反馈：平滑滚动

## 7. 图片适配

### 响应式图片

- 使用 `srcset` 属性
- 提供不同尺寸的图片
- 使用 `picture` 元素（可选）

### 图片尺寸

| 场景 | 桌面端 | 移动端 |
|------|--------|--------|
| 头像 | 32x32px | 28x28px |
| 大头像 | 120x120px | 100x100px |
| 卡片图片 | 自适应 | 自适应 |

## 8. 动画适配

### 动画时长

- 短动画：0.2s
- 中等动画：0.3s
- 长动画：0.5s

### 动画性能

- 使用 `transform` 和 `opacity`
- 避免动画 `width`、`height`、`margin` 等
- 使用 `will-change` 优化（谨慎使用）

## 9. 滚动优化

### 滚动行为

- 平滑滚动：`scroll-behavior: smooth`
- 虚拟滚动：长列表使用虚拟滚动
- 无限滚动：可选，用于加载更多内容

### 滚动性能

- 使用 `transform` 实现滚动
- 节流滚动事件处理
- 使用 `IntersectionObserver` 优化

## 10. 键盘适配

### 移动端键盘

- 输入框聚焦时自动滚动到可视区域
- 键盘弹出时调整布局
- 使用 `viewport-fit=cover`（iOS）

### 键盘类型

- 文本输入：`type="text"`
- 邮箱输入：`type="email"`
- 数字输入：`type="number"`
- 密码输入：`type="password"`

## 11. 横竖屏适配

### 布局调整

- 横屏时：调整布局比例
- 竖屏时：垂直布局
- 使用媒体查询：`@media (orientation: landscape)`

### 内容调整

- 横屏时：显示更多内容
- 竖屏时：紧凑显示
- 保持核心功能可用

## 12. 性能优化

### 图片优化

- 使用 WebP 格式（支持时）
- 图片懒加载
- 响应式图片

### 代码优化

- 代码分割
- 懒加载组件
- 减少重绘和重排

### 网络优化

- 使用 CDN
- 压缩资源
- 缓存策略

### 功能测试

- 兼容性

## 设计注意事项

1. **移动优先**
   - 优先设计移动端
   - 逐步增强到桌面端

2. **一致性**
   - 保持跨设备的一致性
   - 统一的交互模式

3. **性能**
   - 优化移动端性能
   - 减少资源占用

4. **可访问性**
   - 支持不同设备
   - 提供降级方案
