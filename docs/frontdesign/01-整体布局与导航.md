# 01. 整体布局与导航

## 页面概述

CozyChat 采用经典的三栏布局结构：顶部 Header、左侧 Sidebar、中间 Content 区域。移动端采用底部导航栏 + 抽屉式侧边栏。

## 布局结构

### 桌面端布局

```
┌─────────────────────────────────────────┐
│              Header (64px)               │
├──────────┬──────────────────────────────┤
│          │                              │
│ Sidebar  │        Content Area          │
│ (280px)  │        (自适应宽度)          │
│          │                              │
│          │                              │
└──────────┴──────────────────────────────┘
```

### 移动端布局

```
┌─────────────────────────┐
│      Header (64px)       │
├─────────────────────────┤
│                         │
│                         │
│    Content Area         │
│    (全屏宽度)           │
│                         │
│                         │
├─────────────────────────┤
│   MobileNav (底部导航)   │
└─────────────────────────┘
```

## 1. Header（顶部导航栏）

### 功能要求

1. **Logo 区域**
   - 左侧显示 CozyChat Logo
   - 点击 Logo 返回首页（/chat）
   - Logo 尺寸：32x32px

2. **用户信息区域**
   - 右侧显示用户头像（圆形，32x32px）
   - 点击头像显示下拉菜单：
     - 个人资料
     - 偏好设置
     - 退出登录
   - 未登录时显示"登录"按钮

3. **移动端适配**
   - 显示汉堡菜单按钮（左侧）
   - 点击打开侧边栏抽屉
   - Logo 居中或左侧显示

### 视觉要求

- 高度：64px（固定）
- 背景色：使用主题背景色
- 边框：底部 1px 边框（使用主题边框色）
- 阴影：轻微阴影（可选）
- 固定定位：滚动时保持在顶部

### 交互要求

- 用户头像悬停：显示提示信息
- 下拉菜单：点击外部区域关闭
- 移动端菜单按钮：点击切换侧边栏显示/隐藏

## 2. Sidebar（侧边栏）

### 功能要求

1. **会话列表区域**
   - 显示所有会话列表
   - 支持搜索会话
   - 支持新建会话按钮
   - 支持删除会话（右键菜单或长按）
   - 支持会话重命名

2. **会话项显示**
   - 会话标题（最多显示 2 行，超出省略）
   - 最后一条消息预览（最多 1 行，超出省略）
   - 时间显示（相对时间：今天、昨天、具体日期）
   - 未读消息数量（红色徽章）

3. **会话操作**
   - 点击会话项：切换到该会话
   - 悬停会话项：显示操作按钮（删除、重命名）
   - 当前会话：高亮显示

4. **搜索功能**
   - 顶部搜索框
   - 实时搜索会话标题和消息内容
   - 高亮匹配关键词

5. **新建会话按钮**
   - 固定在侧边栏顶部或底部
   - 点击弹出人格选择器（可选）
   - 创建新会话并自动切换

### 视觉要求

- 宽度：280px（桌面端固定）
- 背景色：使用主题背景色
- 边框：右侧 1px 边框（使用主题边框色）
- 滚动：内容超出时显示滚动条

### 交互要求

- 会话项悬停：背景色变化
- 会话项点击：切换会话，更新 URL
- 搜索框：聚焦时显示清除按钮
- 移动端：抽屉式显示，点击遮罩层关闭

## 3. Content（内容区域）

### 功能要求

1. **自适应宽度**
   - 桌面端：减去 Header 和 Sidebar 后的剩余宽度
   - 移动端：全屏宽度
   - 最大宽度：1920px（可选，居中显示）

2. **内边距**
   - 桌面端：24px
   - 移动端：12px

3. **背景色**
   - 使用主题背景色
   - 支持渐变背景（聊天页面）

### 视觉要求

- 最小高度：100vh - Header 高度
- 背景色：使用主题背景色
- 过渡动画：主题切换时平滑过渡

## 4. MobileNav（移动端底部导航）

### 功能要求

1. **导航项**
   - 聊天（默认选中）
   - 健康档案
   - 个人资料
   - 设置

2. **图标和文字**
   - 每个导航项显示图标和文字
   - 选中状态：图标和文字高亮
   - 未选中状态：灰色显示

3. **点击行为**
   - 点击导航项：跳转到对应页面
   - 当前页面：导航项高亮显示

### 视觉要求

- 高度：56px（固定）
- 背景色：使用主题背景色
- 边框：顶部 1px 边框（使用主题边框色）
- 固定定位：滚动时保持在底部
- 图标尺寸：24x24px
- 文字大小：12px

### 交互要求

- 点击导航项：页面切换动画
- 选中状态：视觉反馈明显

## 5. 响应式断点

### 断点定义

- **移动端**: < 768px
- **桌面端**: ≥ 768px

### 布局变化

1. **Sidebar 显示方式**
   - 桌面端：固定显示在左侧
   - 移动端：抽屉式，点击菜单按钮打开

2. **Header 布局**
   - 桌面端：Logo 左侧，用户信息右侧
   - 移动端：菜单按钮左侧，Logo 居中，用户信息右侧

3. **MobileNav 显示**
   - 桌面端：隐藏
   - 移动端：显示在底部

## 6. 主题切换

### 支持的主题

1. **明暗主题**
   - 浅色主题（Light）
   - 深色主题（Dark）
   - 跟随系统（Auto）

2. **主题切换位置**
   - Header 用户下拉菜单
   - 设置页面

### 视觉要求

- 切换动画：平滑过渡（0.3s）
- 颜色变量：使用 CSS 变量管理
- 保持一致性：所有组件同步切换

## 7. 加载状态

### 页面加载

- 显示全局加载动画（Spin）
- 居中显示
- 背景半透明遮罩

### 内容加载

- 骨架屏（Skeleton）
- 加载动画
- 错误状态提示

## 8. 错误处理

### 错误显示

- 全局错误边界（ErrorBoundary）
- 错误提示消息（Toast）
- 错误重试按钮

### 网络错误

- 显示网络错误提示
- 提供重试按钮
- 离线状态提示

## 设计注意事项

1. **一致性**
   - 保持所有页面的布局一致性
   - 统一的间距和字体系统

2. **可访问性**
   - 支持键盘导航
   - 提供清晰的焦点状态
   - 支持屏幕阅读器

3. **性能**
   - 减少重绘和重排
   - 使用 CSS 变量优化主题切换
   - 懒加载非关键内容

4. **移动端优化**
   - 触摸目标至少 44x44px
   - 避免悬停状态（移动端不支持）
   - 优化滚动性能
