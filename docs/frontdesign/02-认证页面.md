# 02. 认证页面

## 页面概述

认证页面包括登录页面和注册页面，采用居中卡片式设计，支持表单验证和错误提示。

## 1. 登录页面（Login Page）

### 路由
- 路径：`/login`
- 访问权限：公开路由（未登录用户可访问）

### 功能要求

1. **表单字段**
   - 用户名/邮箱输入框
     - 支持用户名或邮箱登录
     - 必填，显示验证提示
   - 密码输入框
     - 必填，显示验证提示
     - 支持显示/隐藏密码（眼睛图标）
   - 记住我（可选）
     - 复选框
     - 默认不勾选

2. **操作按钮**
   - 登录按钮
     - 主按钮样式
     - 加载状态显示
     - 禁用状态（表单未验证通过）
   - 注册链接
     - 文字链接样式
     - 点击跳转到注册页面

3. **表单验证**
   - 实时验证
   - 错误提示显示在输入框下方
   - 提交时再次验证

4. **错误处理**
   - 网络错误提示
   - 用户名/密码错误提示
   - 账户被锁定提示（如有）

### 视觉要求

1. **布局**
   - 全屏居中显示
   - 卡片宽度：400px（桌面端）
   - 卡片宽度：90%（移动端，最大 400px）
   - 卡片内边距：24px

2. **背景**
   - 渐变背景（135deg, #667eea 0%, #764ba2 100%）
   - 或使用主题背景色
   - 可配置背景图片（可选）

3. **卡片样式**
   - 白色背景（或主题背景色）
   - 圆角：8px
   - 阴影：中等阴影
   - 标题：24px，居中，加粗

4. **输入框样式**
   - 高度：40px
   - 圆角：4px
   - 边框：1px 实线
   - 聚焦状态：边框高亮

5. **按钮样式**
   - 登录按钮：主色背景，白色文字，高度 40px
   - 注册链接：主色文字，下划线（悬停时）

### 交互要求

1. **表单交互**
   - 输入框聚焦：边框高亮
   - 输入框失焦：验证并显示错误（如有）
   - 密码显示/隐藏：点击眼睛图标切换

2. **提交交互**
   - 点击登录按钮：显示加载状态
   - 登录成功：跳转到 `/chat`
   - 登录失败：显示错误提示，不清空表单

3. **键盘交互**
   - Enter 键：提交表单
   - Tab 键：切换输入框

## 2. 注册页面（Register Page）

### 路由
- 路径：`/register`
- 访问权限：公开路由（未登录用户可访问）

### 功能要求

1. **表单字段**
   - 用户名输入框
     - 必填，3-20 个字符
     - 只能包含字母、数字、下划线
     - 实时验证可用性（可选）
   - 邮箱输入框
     - 必填，邮箱格式验证
     - 实时验证可用性（可选）
   - 密码输入框
     - 必填，至少 8 个字符
     - 支持显示/隐藏密码
     - 显示密码强度指示器（可选）
   - 确认密码输入框
     - 必填，必须与密码一致
     - 支持显示/隐藏密码

2. **操作按钮**
   - 注册按钮
     - 主按钮样式
     - 加载状态显示
     - 禁用状态（表单未验证通过）
   - 登录链接
     - 文字链接样式
     - 点击跳转到登录页面

3. **表单验证**
   - 实时验证
   - 错误提示显示在输入框下方
   - 提交时再次验证

4. **错误处理**
   - 网络错误提示
   - 用户名已存在提示
   - 邮箱已注册提示
   - 密码强度不足提示

### 视觉要求

1. **布局**
   - 全屏居中显示
   - 卡片宽度：400px（桌面端）
   - 卡片宽度：90%（移动端，最大 400px）
   - 卡片内边距：24px

2. **背景**
   - 与登录页面保持一致
   - 渐变背景或主题背景色

3. **卡片样式**
   - 与登录页面保持一致
   - 标题：24px，居中，加粗

4. **输入框样式**
   - 与登录页面保持一致

5. **按钮样式**
   - 与登录页面保持一致

### 交互要求

1. **表单交互**
   - 与登录页面保持一致
   - 密码强度指示器：实时更新

2. **提交交互**
   - 点击注册按钮：显示加载状态
   - 注册成功：显示成功提示，跳转到登录页面（或直接登录）
   - 注册失败：显示错误提示，不清空表单

3. **键盘交互**
   - 与登录页面保持一致

## 3. 表单验证规则

### 登录表单

| 字段 | 验证规则 | 错误提示 |
|------|---------|---------|
| 用户名/邮箱 | 必填 | 请输入用户名或邮箱 |
| 密码 | 必填 | 请输入密码 |

### 注册表单

| 字段 | 验证规则 | 错误提示 |
|------|---------|---------|
| 用户名 | 必填，3-20 字符，字母数字下划线 | 用户名长度为 3-20 个字符，只能包含字母、数字和下划线 |
| 邮箱 | 必填，邮箱格式 | 请输入有效的邮箱地址 |
| 密码 | 必填，至少 8 字符 | 密码长度至少为 8 个字符 |
| 确认密码 | 必填，与密码一致 | 两次输入的密码不一致 |

## 4. 错误状态设计

### 错误提示样式

- 位置：输入框下方
- 颜色：红色（#ff4d4f）
- 字体大小：12px
- 图标：错误图标（可选）

### 错误类型

1. **验证错误**
   - 实时显示
   - 输入框边框变红
   - 显示错误提示文字

2. **网络错误**
   - Toast 提示
   - 显示在页面顶部或底部
   - 自动消失（3 秒）或手动关闭

3. **业务错误**
   - Toast 提示
   - 显示具体错误信息
   - 提供重试按钮（可选）

## 5. 加载状态设计

### 按钮加载状态

- 显示加载图标（Spin）
- 按钮文字变为"登录中..."或"注册中..."
- 禁用按钮点击

### 页面加载状态

- 显示全局加载动画
- 半透明遮罩
- 居中显示

## 6. 成功状态设计

### 登录成功

- 显示成功提示（可选）
- 自动跳转到 `/chat`
- 跳转动画：淡入淡出

### 注册成功

- 显示成功提示
- 提供两个选项：
  - 跳转到登录页面
  - 直接登录（如果支持）

## 7. 移动端适配

### 布局调整

1. **卡片宽度**
   - 桌面端：400px
   - 移动端：90%（最大 400px）

2. **内边距**
   - 桌面端：24px
   - 移动端：16px

3. **字体大小**
   - 标题：桌面端 24px，移动端 20px
   - 输入框文字：桌面端 14px，移动端 16px（避免 iOS 自动缩放）

### 交互优化

1. **键盘处理**
   - 输入框聚焦时，自动滚动到可视区域
   - 提交后自动收起键盘

2. **触摸优化**
   - 按钮触摸目标至少 44x44px
   - 输入框高度至少 44px（移动端）

## 设计注意事项

1. **安全性**
   - 密码输入框默认隐藏
   - 不显示密码明文
   - 支持密码强度提示（注册时）

2. **用户体验**
   - 清晰的错误提示
   - 快速反馈
   - 减少用户输入

3. **可访问性**
   - 支持键盘导航
   - 提供清晰的焦点状态
   - 支持屏幕阅读器

4. **一致性**
   - 与整体设计风格保持一致
   - 统一的颜色和字体系统
