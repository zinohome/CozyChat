# 04. 设置页面

## 页面概述

设置页面提供用户偏好配置功能，包括聊天设置和对话风格配置。采用标签页（Tabs）组织内容。

## 路由

- 路径：`/settings`
- 访问权限：需要登录（受保护路由）

## 页面布局

```
┌─────────────────────────────────────────┐
│      Header (返回按钮 + 标题)            │
├─────────────────────────────────────────┤
│                                         │
│      Card (设置卡片)                     │
│      ┌─────────────────────────────┐    │
│      │  Tabs (标签页)              │    │
│      │  - 聊天设置                 │    │
│      │  - 对话风格                 │    │
│      └─────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

## 1. 页面头部

### 功能要求

1. **返回按钮**
   - 左侧箭头图标
   - 点击返回聊天页面

2. **标题**
   - "偏好设置"
   - 居中或左侧显示

### 视觉要求

- 高度：64px
- 背景：主题背景色
- 标题字体：18px，加粗

## 2. 设置卡片

### 功能要求

1. **卡片容器**
   - 最大宽度：800px
   - 居中显示
   - 内边距：24px

2. **标签页**
   - 两个标签：聊天设置、对话风格
   - 支持切换标签

### 视觉要求

- 卡片背景：白色或主题背景色
- 卡片圆角：8px
- 卡片阴影：轻微阴影
- 标签页：Ant Design Tabs 组件样式

## 3. 聊天设置标签页

### 功能要求

1. **主题切换**
   - 显示当前主题
   - 支持切换：浅色、深色、跟随系统
   - 即时生效

2. **语言切换**
   - 显示当前语言
   - 支持切换：简体中文、繁体中文、English
   - 即时生效

3. **聊天背景**
   - 显示当前背景样式
   - 支持切换：渐变色、纯色
   - 即时生效

4. **自动播放语音**
   - 开关按钮
   - 开启：收到 AI 回复时自动播放语音
   - 关闭：不自动播放

5. **总是显示语音输入**
   - 开关按钮
   - 开启：宽屏幕下也显示语音输入按钮
   - 关闭：仅小屏幕显示

6. **时区设置**
   - 下拉选择框
   - 显示所有时区选项
   - 影响时间显示

### 视觉要求

1. **设置项布局**
   - 每项占一行
   - 左侧：设置名称和描述
   - 右侧：控制组件（开关/选择框）

2. **设置项样式**
   - 内边距：16px
   - 分隔线：Divider 组件
   - 描述文字：12px，灰色

3. **控制组件**
   - 开关：Ant Design Switch 组件
   - 选择框：Ant Design Select 组件
   - 宽度：120px（聊天背景），200px（时区）

### 交互要求

1. **即时保存**
   - 切换设置后立即保存
   - 显示保存成功提示（可选）
   - 保存失败：恢复原状态，显示错误提示

2. **加载状态**
   - 保存中：显示加载动画
   - 禁用控制组件（防止重复操作）

## 4. 对话风格标签页

### 功能要求

1. **风格预设选择**
   - 简洁模式
     - 120字内简短回答
     - 通俗易懂
     - 快速获取关键信息
   - 标准模式（推荐）
     - ChatGPT 风格
     - 结构化呈现
     - 分点说明
   - 专业模式
     - 详细解释背景机理
     - 提供权威医学建议
     - 内容全面深入

2. **预设卡片**
   - 显示预设名称
   - 显示预设描述
   - 显示预设图标
   - 选中状态：高亮显示

3. **显示判断依据**
   - 开关按钮
   - 开启：在回答末尾说明 AI 的判断理由
   - 关闭：不显示判断依据

### 视觉要求

1. **预设卡片**
   - 宽度：100%
   - 内边距：14px
   - 边框：2px 实线
   - 圆角：8px
   - 选中状态：主色边框，浅色背景
   - 悬停状态：边框高亮

2. **卡片内容**
   - 左侧：图标 + 名称 + 描述
   - 右侧：选中标记（✓）
   - 图标：20px
   - 名称：14px，加粗
   - 描述：12px，灰色

3. **卡片间距**
   - 卡片之间：10px

### 交互要求

1. **选择预设**
   - 点击预设卡片：应用该预设
   - 立即保存设置
   - 显示选中状态

2. **切换开关**
   - 点击开关：切换状态
   - 立即保存设置

## 5. 设置项详细说明

### 主题切换

- **选项**：浅色、深色、跟随系统
- **默认值**：跟随系统
- **影响范围**：整个应用界面

### 语言切换

- **选项**：简体中文、繁体中文、English
- **默认值**：简体中文
- **影响范围**：界面文字、AI 回复语言

### 聊天背景

- **选项**：渐变色、纯色
- **默认值**：渐变色
- **影响范围**：聊天页面背景

### 自动播放语音

- **类型**：开关
- **默认值**：关闭
- **影响范围**：收到 AI 回复时的行为

### 总是显示语音输入

- **类型**：开关
- **默认值**：关闭
- **影响范围**：输入区域语音按钮显示

### 时区设置

- **类型**：下拉选择
- **默认值**：系统时区
- **影响范围**：时间显示格式

### 对话风格预设

- **类型**：单选（预设卡片）
- **默认值**：标准模式
- **影响范围**：AI 回复风格

### 显示判断依据

- **类型**：开关
- **默认值**：关闭
- **影响范围**：AI 回复末尾是否显示判断理由

## 6. 响应式设计

### 桌面端（≥768px）

- 卡片最大宽度：800px
- 设置项：左右布局（名称左侧，控制右侧）
- 预设卡片：完整显示

### 移动端（<768px）

- 卡片宽度：100%（减去内边距）
- 设置项：上下布局（名称上方，控制下方）
- 预设卡片：紧凑显示

## 7. 数据持久化

### 保存机制

- 每个设置项独立保存
- 使用 API 保存到服务器
- 本地缓存（React Query）

### 同步机制

- 页面加载时从服务器获取设置
- 设置变更时立即保存
- 多设备同步（通过服务器）

## 8. 错误处理

### 保存失败

- 显示错误提示
- 恢复原状态
- 提供重试按钮（可选）

### 加载失败

- 显示加载失败提示
- 提供重新加载按钮
- 使用默认值（如有）

## 设计注意事项

1. **即时反馈**
   - 设置变更立即生效
   - 显示保存状态
   - 清晰的视觉反馈

2. **可访问性**
   - 支持键盘导航
   - 清晰的焦点状态
   - 支持屏幕阅读器

3. **一致性**
   - 与整体设计风格保持一致
   - 统一的组件样式
   - 统一的交互模式

4. **性能**
   - 减少不必要的 API 调用
   - 使用缓存优化
   - 快速响应
