# 06. 健康档案页面

## 页面概述

健康档案页面提供用户健康信息管理功能，包括健康自测、健康史、健康报告、健康计划、饮食健康、运动健康、药物记录、就医资料夹等模块。参考 yyAssistant 设计。

## 路由

- 路径：`/health-record`
- 访问权限：需要登录（受保护路由）

## 页面布局

```
┌─────────────────────────────────────────┐
│      Header (返回按钮 + 标题)            │
├─────────────────────────────────────────┤
│      User Card (用户信息卡片)            │
├─────────────────────────────────────────┤
│      Tabs Card (标签页卡片)              │
│      ┌─────────────────────────────┐    │
│      │  Tabs (8个标签页)           │    │
│      │  - 健康自测                 │    │
│      │  - 健康史                   │    │
│      │  - 健康报告                 │    │
│      │  - 健康计划                 │    │
│      │  - 饮食健康                 │    │
│      │  - 运动健康                 │    │
│      │  - 药物记录                 │    │
│      │  - 就医资料夹               │    │
│      └─────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

## 1. 页面头部

### 功能要求

1. **返回按钮**
   - 左侧箭头图标
   - 点击返回聊天页面

2. **标题**
   - "健康档案"
   - 居中或左侧显示

### 视觉要求

- 高度：64px
- 背景：主题背景色
- 标题字体：18px，加粗

## 2. 用户信息卡片

### 功能要求

1. **用户头像**
   - 圆形头像
   - 尺寸：80x80px
   - 默认图片：用户头像或默认头像

2. **用户信息**
   - 用户名
   - 性别（男/女）
   - 年龄
   - 身份证号（部分隐藏，如：320***********1234）

3. **编辑按钮**
   - "编辑资料"链接按钮
   - 点击跳转到个人资料页面（或弹出编辑对话框）

### 视觉要求

- 卡片背景：白色或主题背景色
- 卡片圆角：8px
- 卡片内边距：24px
- 布局：水平布局（头像左侧，信息右侧）

## 3. 标签页卡片

### 功能要求

1. **标签页容器**
   - 8 个标签页
   - 支持切换标签
   - 标签图标 + 文字

2. **标签页列表**
   - 健康自测（HeartOutlined）
   - 健康史（FileTextOutlined）
   - 健康报告（FileTextOutlined）
   - 健康计划（CalendarOutlined）
   - 饮食健康（AppleOutlined）
   - 运动健康（ThunderboltOutlined）
   - 药物记录（MedicineBoxOutlined）
   - 就医资料夹（FolderOpenOutlined）

### 视觉要求

- 卡片背景：白色或主题背景色
- 卡片圆角：8px
- 标签页：Ant Design Tabs 组件样式

## 4. 健康自测标签页

### 功能要求

1. **自测记录列表**
   - 显示所有自测记录
   - 每条记录包含：
     - 自测类型（血压、血糖、体重、体温、心率等）
     - 测量值
     - 状态标签（正常、异常等）
     - 测量时间
     - 查看详情按钮

2. **添加记录按钮**
   - "添加自测记录"按钮
   - 点击弹出添加对话框

### 视觉要求

1. **记录卡片**
   - 小尺寸卡片（Card size="small"）
   - 内边距：12px
   - 边框：1px 实线
   - 圆角：4px

2. **记录内容**
   - 水平布局
   - 左侧：类型、值、状态、时间
   - 右侧：查看详情按钮
   - 分隔符：Divider 组件

3. **状态标签**
   - 正常：绿色
   - 异常：红色
   - 警告：橙色

### 交互要求

- 点击查看详情：显示详情对话框
- 点击添加记录：弹出添加对话框

## 5. 健康史标签页

### 功能要求

1. **家族史卡片**
   - 显示家族病史标签
   - 显示描述文字
   - 编辑按钮

2. **个人史卡片**
   - 显示个人史信息：
     - 饮酒情况
     - 吸烟情况
     - 过敏史
   - 编辑按钮

3. **既往病史卡片**
   - 时间线显示（Timeline）
   - 显示历史疾病记录
   - 编辑按钮

### 视觉要求

1. **卡片样式**
   - 小尺寸卡片
   - 内边距：12px
   - 标题：加粗，14px

2. **标签**
   - 使用 Tag 组件
   - 不同颜色区分

3. **时间线**
   - Ant Design Timeline 组件
   - 标签：日期
   - 内容：疾病描述

### 交互要求

- 点击编辑：弹出编辑对话框
- 点击标签：查看详情（可选）

## 6. 健康报告标签页

### 功能要求

1. **空状态**
   - 显示空状态（Empty）
   - "生成健康报告"按钮

2. **报告列表**（如有数据）
   - 显示报告列表
   - 报告标题、日期、类型
   - 查看、下载、删除按钮

### 视觉要求

- 空状态：Ant Design Empty 组件
- 按钮：主按钮样式

## 7. 健康计划标签页

### 功能要求

1. **空状态**
   - 显示空状态
   - "生成专属健康计划"按钮

2. **计划列表**（如有数据）
   - 显示计划列表
   - 计划标题、日期、状态
   - 查看、编辑、删除按钮

### 视觉要求

- 与健康报告标签页类似

## 8. 饮食健康标签页

### 功能要求

1. **今日饮食统计卡片**
   - 摄入卡路里
   - 目标卡路里
   - 剩余卡路里
   - 数据可视化（可选）

2. **添加记录按钮**
   - "添加饮食记录"按钮

### 视觉要求

1. **统计卡片**
   - 小尺寸卡片
   - 统计项：3 列布局
   - 数值：大字体，不同颜色

2. **统计项**
   - 标签：12px，灰色
   - 数值：24px，加粗，主色

## 9. 运动健康标签页

### 功能要求

1. **今日运动数据卡片**
   - 步数
   - 距离
   - 卡路里
   - 运动时长

2. **添加记录按钮**
   - "添加运动记录"按钮

### 视觉要求

- 与饮食健康标签页类似
- 统计项：4 列布局

## 10. 药物记录标签页

### 功能要求

1. **当前用药卡片**
   - 显示当前用药列表
   - 每条记录包含：
     - 药物名称
     - 剂量
     - 服用频率
     - 服用时长
     - 状态标签（进行中、已暂停）
     - 详情、暂停按钮

2. **添加记录按钮**
   - "添加用药记录"按钮

### 视觉要求

1. **用药项**
   - 水平布局
   - 左侧：名称、状态、剂量、频率、时长
   - 右侧：操作按钮
   - 分隔符：Divider 组件

2. **状态标签**
   - 进行中：蓝色
   - 已暂停：灰色

## 11. 就医资料夹标签页

### 功能要求

1. **操作按钮**
   - "上传资料"按钮
   - "新建文件夹"按钮

2. **文件列表**
   - 显示所有文件
   - 每条记录包含：
     - 文件图标（PDF、图片、Word）
     - 文件名称
     - 文件类型标签
     - 检查日期
     - 文件大小
     - 查看、下载、删除按钮

### 视觉要求

1. **文件项**
   - 水平布局
   - 左侧：图标
   - 中间：名称、标签、日期、大小
   - 右侧：操作按钮

2. **文件图标**
   - PDF：FilePdfOutlined（红色）
   - 图片：FileImageOutlined（蓝色）
   - Word：FileWordOutlined（蓝色）

## 12. 响应式设计

### 桌面端（≥768px）

- 卡片最大宽度：1200px
- 标签页：顶部显示
- 统计项：多列布局

### 移动端（<768px）

- 卡片宽度：100%
- 标签页：可滚动
- 统计项：单列或两列布局

## 13. 数据加载

### 加载状态

- 显示加载动画
- 骨架屏（可选）

### 空状态

- 使用 Ant Design Empty 组件
- 提供操作按钮

## 14. 错误处理

### 加载失败

- 显示错误提示
- 提供重新加载按钮

### 操作失败

- 显示错误提示
- 提供重试按钮（可选）

## 设计注意事项

1. **信息密度**
   - 合理的信息密度
   - 清晰的视觉层次
   - 易于扫描

2. **操作便捷性**
   - 常用操作易于访问
   - 减少操作步骤
   - 清晰的反馈

3. **数据可视化**
   - 使用图表展示数据（可选）
   - 颜色编码状态
   - 直观的数据展示

4. **可访问性**
   - 支持键盘导航
   - 清晰的焦点状态
   - 支持屏幕阅读器
