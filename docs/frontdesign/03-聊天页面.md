# 03. 聊天页面

## 页面概述

聊天页面是 CozyChat 的核心页面，提供与 AI 助手的对话功能。支持文本输入、语音输入、消息流式显示、Markdown 渲染等功能。

## 路由

- 路径：`/chat` 或 `/chat/:sessionId`
- 访问权限：需要登录（受保护路由）

## 页面布局

```
┌─────────────────────────────────────────┐
│      ChatSessionHeader (会话头部)        │
├─────────────────────────────────────────┤
│                                         │
│      Messages Container (消息列表)       │
│      - 虚拟滚动                          │
│      - 消息气泡                          │
│      - Markdown 渲染                     │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│      ChatToolbar (工具栏)                │
├─────────────────────────────────────────┤
│      Input Area (输入区域)               │
│      - 文本输入框                        │
│      - 发送按钮                          │
│      - 语音输入按钮                      │
└─────────────────────────────────────────┘
```

## 1. ChatSessionHeader（会话头部）

### 功能要求

1. **会话列表按钮**
   - 历史图标按钮
   - 点击弹出会话列表 Popover
   - 显示当前会话数量

2. **新建会话按钮**
   - 加号图标按钮
   - 点击创建新会话
   - 使用当前人格 ID

3. **会话列表 Popover**
   - 宽度：300px（桌面端），280px（移动端）
   - 最大高度：400px
   - 显示所有会话列表
   - 支持搜索会话
   - 点击会话项切换会话

### 视觉要求

- 高度：48px（桌面端），40px（移动端）
- 位置：聊天区域顶部
- 背景：透明（继承父容器背景）
- 边框：底部 1px 边框
- 按钮：文字按钮样式，图标大小 16px

### 交互要求

- 点击历史图标：打开/关闭会话列表
- 点击新建按钮：创建新会话并切换
- 点击会话项：切换会话，关闭 Popover

## 2. Messages Container（消息列表区域）

### 功能要求

1. **消息显示**
   - 用户消息：右侧显示，用户头像
   - AI 消息：左侧显示，AI 头像
   - 消息时间：相对时间（刚刚、1分钟前、今天 10:30）
   - 消息状态：发送中、已发送、失败

2. **消息内容**
   - 支持 Markdown 渲染
   - 支持代码高亮
   - 支持表格显示
   - 支持链接预览
   - 支持图片显示

3. **流式显示**
   - 支持流式消息显示
   - 打字机效果
   - 实时更新消息内容

4. **虚拟滚动**
   - 使用虚拟滚动优化性能
   - 支持大量消息（1000+）
   - 自动滚动到底部（新消息）

5. **消息操作**
   - 复制消息
   - 重新生成（AI 消息）
   - 删除消息（可选）

### 视觉要求

1. **消息气泡**
   - 用户消息：主色背景，白色文字，右侧对齐
   - AI 消息：浅色背景，深色文字，左侧对齐
   - 圆角：12px
   - 内边距：12px 16px
   - 最大宽度：70%（桌面端），85%（移动端）

2. **头像**
   - 尺寸：32x32px（桌面端），28x28px（移动端）
   - 圆形
   - 用户头像：用户上传或默认头像
   - AI 头像：人格图标或默认图标

3. **消息间距**
   - 消息之间：16px
   - 同一用户连续消息：8px

4. **背景**
   - 支持渐变背景（可配置）
   - 支持纯色背景（可配置）
   - 使用主题背景色

### 交互要求

1. **滚动行为**
   - 新消息自动滚动到底部
   - 用户手动滚动时，暂停自动滚动
   - 滚动到底部时，恢复自动滚动

2. **消息交互**
   - 悬停消息：显示操作按钮（复制、重新生成）
   - 点击代码块：复制代码
   - 点击链接：新窗口打开

3. **加载状态**
   - 显示加载动画（AI 思考中）
   - 显示流式消息打字效果

## 3. ChatToolbar（工具栏）

### 功能要求

1. **快速入口按钮**
   - 健康档案按钮
   - 个人资料按钮
   - 偏好设置按钮

2. **按钮样式**
   - 文字按钮样式
   - 图标 + 文字
   - 移动端：仅图标

### 视觉要求

- 高度：48px
- 位置：输入区域上方
- 背景：透明
- 按钮间距：中等（桌面端），小（移动端）

### 交互要求

- 点击按钮：跳转到对应页面
- 悬停按钮：背景色变化

## 4. Input Area（输入区域）

### 功能要求

1. **文本输入框**
   - 多行输入（TextArea）
   - 自动调整高度（最多 6 行）
   - 支持占位符提示
   - 支持快捷键（Ctrl+Enter 发送）

2. **发送按钮**
   - 发送图标按钮
   - 禁用状态（输入为空或发送中）
   - 加载状态（发送中）

3. **语音输入按钮**
   - 麦克风图标按钮
   - 点击开始/停止录音
   - 录音状态：显示动画
   - 转写状态：显示加载动画

4. **语音通话按钮**（可选）
   - 电话图标按钮
   - 点击开始/结束语音通话
   - 通话状态：显示波形动画

### 视觉要求

1. **输入框**
   - 高度：自适应（最小 40px）
   - 圆角：8px
   - 边框：1px 实线
   - 内边距：12px 16px
   - 字体大小：14px

2. **按钮**
   - 尺寸：40x40px
   - 圆角：8px
   - 主色背景（发送按钮）
   - 文字按钮样式（语音按钮）

3. **容器**
   - 背景：白色或主题背景色
   - 边框：顶部 1px 边框
   - 内边距：12px 16px

### 交互要求

1. **输入交互**
   - 聚焦输入框：边框高亮
   - 输入文字：实时更新
   - 清空输入：显示清除按钮

2. **发送交互**
   - 点击发送：发送消息，清空输入框
   - 发送中：禁用按钮，显示加载状态
   - 发送成功：滚动到底部，显示新消息
   - 发送失败：显示错误提示

3. **语音交互**
   - 点击录音按钮：开始/停止录音
   - 录音中：显示录音动画
   - 转写中：显示转写动画
   - 转写完成：自动填入输入框

4. **键盘交互**
   - Enter：换行（Shift+Enter 发送，或仅 Enter 发送，可配置）
   - Ctrl+Enter：发送消息
   - Esc：取消输入（可选）

## 5. 语音通话功能（可选）

### 功能要求

1. **通话界面**
   - 显示通话状态（连接中、通话中、已断开）
   - 显示用户和 AI 的音频波形
   - 显示通话时长
   - 显示静音/取消静音按钮

2. **通话控制**
   - 开始通话：点击电话按钮
   - 结束通话：点击挂断按钮
   - 静音/取消静音：点击静音按钮

### 视觉要求

- 通话指示器：显示在消息列表顶部或底部
- 波形动画：实时显示音频波形
- 通话按钮：固定在输入区域

### 交互要求

- 点击电话按钮：开始/结束通话
- 通话中：显示通话界面
- 通话结束：隐藏通话界面

## 6. 消息类型支持

### 文本消息

- 纯文本
- Markdown 格式
- 代码块（语法高亮）
- 表格
- 列表（有序、无序）
- 引用
- 链接

### 媒体消息

- 图片（支持预览）
- 音频（支持播放）
- 视频（支持播放，可选）

### 特殊消息

- 系统消息（通知类）
- 错误消息（红色提示）
- 加载消息（骨架屏）

## 7. 响应式设计

### 桌面端（≥768px）

- 消息最大宽度：70%
- 输入框：多行显示
- 工具栏：图标 + 文字
- 会话头部：完整显示

### 移动端（<768px）

- 消息最大宽度：85%
- 输入框：自适应高度
- 工具栏：仅图标
- 会话头部：紧凑显示

## 8. 性能优化

### 虚拟滚动

- 只渲染可视区域的消息
- 支持大量消息（1000+）
- 平滑滚动体验

### 懒加载

- 图片懒加载
- 代码块懒加载高亮
- 链接预览懒加载

### 缓存策略

- 消息列表缓存
- 会话列表缓存
- 图片缓存

## 9. 错误处理

### 发送失败

- 显示错误提示
- 提供重试按钮
- 保存失败消息（可选）

### 网络错误

- 显示网络错误提示
- 自动重连（可选）
- 提供手动重试

### 加载失败

- 显示加载失败提示
- 提供重新加载按钮

## 设计注意事项

1. **可读性**
   - 足够的文字对比度
   - 合适的字体大小
   - 清晰的消息分隔

2. **可访问性**
   - 支持键盘导航
   - 支持屏幕阅读器
   - 提供清晰的焦点状态

3. **性能**
   - 优化大量消息渲染
   - 减少重绘和重排
   - 使用虚拟滚动

4. **用户体验**
   - 快速响应
   - 清晰的反馈
   - 流畅的动画
