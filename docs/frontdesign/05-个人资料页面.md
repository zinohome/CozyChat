# 05. 个人资料页面

## 页面概述

个人资料页面提供用户个人信息编辑功能，包括头像上传、显示名称、个人简介、兴趣等字段。采用即时保存机制。

## 路由

- 路径：`/profile`
- 访问权限：需要登录（受保护路由）

## 页面布局

```
┌─────────────────────────────────────────┐
│      Header (返回按钮 + 标题)            │
├─────────────────────────────────────────┤
│                                         │
│      Card (资料卡片)                     │
│      ┌─────────────────────────────┐    │
│      │  头像上传区域                │    │
│      │  表单字段                    │    │
│      │  - 用户名（只读）            │    │
│      │  - 邮箱（只读）              │    │
│      │  - 显示名称                  │    │
│      │  - 个人简介                  │    │
│      │  - 兴趣                      │    │
│      └─────────────────────────────┘    │
│                                         │
└─────────────────────────────────────────┘
```

## 1. 页面头部

### 功能要求

1. **返回按钮**
   - 左侧箭头图标
   - 点击返回聊天页面

2. **标题**
   - "个人资料"
   - 居中或左侧显示

### 视觉要求

- 高度：64px
- 背景：主题背景色
- 标题字体：18px，加粗

## 2. 资料卡片

### 功能要求

1. **卡片容器**
   - 最大宽度：800px
   - 居中显示
   - 内边距：24px

2. **表单布局**
   - 垂直布局（Form layout="vertical"）
   - 字段间距：24px

### 视觉要求

- 卡片背景：白色或主题背景色
- 卡片圆角：8px
- 卡片阴影：轻微阴影

## 3. 头像上传区域

### 功能要求

1. **头像显示**
   - 圆形头像
   - 尺寸：120x120px
   - 默认图标：用户图标
   - 支持自定义头像

2. **上传按钮**
   - "上传头像"按钮
   - 图标：上传图标
   - 点击触发文件选择

3. **文件选择**
   - 支持图片格式：JPG、PNG、GIF、WebP
   - 文件大小限制：5MB
   - 预览上传的图片

### 视觉要求

1. **头像容器**
   - 居中显示
   - 边框：2px 实线（主题边框色）
   - 圆形

2. **上传按钮**
   - 主按钮样式
   - 位于头像下方
   - 间距：16px

### 交互要求

1. **上传流程**
   - 选择文件：打开文件选择对话框
   - 预览：立即显示预览（本地预览）
   - 上传：自动上传到服务器
   - 成功：更新头像显示
   - 失败：显示错误提示

2. **即时保存**
   - 上传成功后立即保存
   - 显示成功提示

## 4. 表单字段

### 4.1 用户名（只读）

- **类型**：输入框（禁用）
- **数据来源**：用户登录信息
- **说明**：用户名不可修改

### 4.2 邮箱（只读）

- **类型**：输入框（禁用）
- **数据来源**：用户登录信息
- **说明**：邮箱不可修改

### 4.3 显示名称

- **类型**：单行输入框
- **必填**：否
- **最大长度**：50 字符
- **验证规则**：最大 50 字符
- **保存时机**：失焦时保存
- **占位符**："请输入显示名称"

### 4.4 个人简介

- **类型**：多行文本域
- **必填**：否
- **最大长度**：200 字符
- **行数**：4 行
- **验证规则**：最大 200 字符
- **保存时机**：失焦时保存
- **占位符**："请输入个人简介"
- **字数统计**：显示字数（如：150/200）

### 4.5 兴趣

- **类型**：单行输入框
- **必填**：否
- **格式**：逗号分隔的多个兴趣
- **保存时机**：失焦时保存
- **占位符**："例如：编程, 阅读, 旅行"
- **提示**：多个兴趣请用逗号分隔

### 视觉要求

1. **输入框**
   - 高度：40px（单行），自适应（多行）
   - 圆角：4px
   - 边框：1px 实线
   - 内边距：12px 16px
   - 字体大小：14px

2. **标签**
   - 字体大小：14px
   - 字体颜色：主题文字色
   - 必填标记：红色星号（如有）

3. **错误提示**
   - 位置：输入框下方
   - 颜色：红色（#ff4d4f）
   - 字体大小：12px

### 交互要求

1. **即时保存**
   - 输入框失焦时自动保存
   - 显示保存状态（可选）
   - 保存成功：无提示（静默保存）
   - 保存失败：显示错误提示，恢复原值

2. **表单验证**
   - 实时验证
   - 错误提示显示在输入框下方
   - 保存前再次验证

3. **键盘交互**
   - Tab 键：切换字段
   - Enter 键：多行文本域中换行

## 5. 数据加载

### 加载状态

- 显示加载动画（Spin）
- 居中显示
- 半透明遮罩

### 数据初始化

- 页面加载时从服务器获取用户资料
- 填充表单字段
- 显示头像（如有）

## 6. 数据保存

### 保存机制

1. **即时保存**
   - 每个字段独立保存
   - 失焦时触发保存
   - 不显示保存按钮

2. **保存 API**
   - 使用 PATCH 方法更新部分字段
   - 只发送变更的字段
   - 返回更新后的完整数据

3. **保存状态**
   - 保存中：显示加载状态（可选）
   - 保存成功：静默保存（无提示）
   - 保存失败：显示错误提示

### 错误处理

1. **网络错误**
   - 显示网络错误提示
   - 提供重试按钮（可选）

2. **验证错误**
   - 显示验证错误提示
   - 阻止保存

3. **服务器错误**
   - 显示服务器错误提示
   - 恢复原值

## 7. 响应式设计

### 桌面端（≥768px）

- 卡片最大宽度：800px
- 头像：120x120px
- 表单字段：垂直布局

### 移动端（<768px）

- 卡片宽度：100%（减去内边距）
- 头像：100x100px
- 表单字段：垂直布局
- 内边距：16px

## 8. 特殊处理

### 兴趣字段处理

- **输入格式**：逗号分隔的字符串（如："编程, 阅读, 旅行"）
- **存储格式**：数组（如：["编程", "阅读", "旅行"]）
- **转换逻辑**：
  - 显示时：数组转字符串（join(', ')）
  - 保存时：字符串转数组（split(',').map(trim).filter(Boolean)）

### 头像上传处理

- **本地预览**：使用 FileReader 读取文件并显示预览
- **实际上传**：TODO - 需要实现实际上传逻辑
- **临时方案**：使用本地预览（Base64）

## 9. 数据同步

### 多设备同步

- 通过服务器同步
- 实时更新（如有 WebSocket）
- 冲突处理：后保存覆盖先保存

### 缓存策略

- 使用 React Query 缓存
- 缓存时间：5 分钟
- 失效策略：保存成功后失效缓存

## 设计注意事项

1. **即时保存体验**
   - 无感知保存
   - 快速响应
   - 清晰的错误提示

2. **数据一致性**
   - 确保数据同步
   - 处理并发更新
   - 提供数据验证

3. **可访问性**
   - 支持键盘导航
   - 清晰的焦点状态
   - 支持屏幕阅读器

4. **性能优化**
   - 减少不必要的 API 调用
   - 使用防抖优化保存（可选）
   - 快速响应
