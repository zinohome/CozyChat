## 问题描述

**错误信息**:
```
Exception: No "request" or "websocket" argument on function "<function create_memory at 0x...>"
```

**根本原因**:
`slowapi` 要求被装饰的函数必须有一个名为 `request` 的参数（类型为 `starlette.requests.Request`），但我错误地将其命名为 `http_request`，导致 slowapi 无法识别。

---

## 修复方案

### 原则
1. **FastAPI Request 对象参数名必须是 `request`**（slowapi要求）
2. **Pydantic 模型参数改名为 `data`**（避免命名冲突）
3. **函数体内所有 `request.xxx` 改为 `data.xxx`**（引用正确的对象）

### 修改的文件

#### 1. `backend/app/api/v1/users.py`
```python
# ❌ 错误的写法
async def login_user(
    http_request: Request,  # slowapi 找不到 'request'
    request: UserLoginRequest,
    ...
)

# ✅ 正确的写法
async def login_user(
    request: Request,  # slowapi 要求的参数名
    data: UserLoginRequest,  # Pydantic 模型改名
    ...
):
    # 函数体内使用 data.username 而不是 request.username
    user = manager.authenticate(username=data.username, password=data.password)
```

**修改内容**:
- `register_user`: 参数 `http_request` → `request`, `request` → `data`
- `login_user`: 参数 `http_request` → `request`, `request` → `data`
- 函数体内所有 `request.username` → `data.username`, `request.password` → `data.password`, etc.

#### 2. `backend/app/api/v1/chat.py`

## 关键经验教训

### ❌ 不要这样做
```python
# 错误1: 参数名错误
async def my_func(http_request: Request, ...):  # slowapi 找不到
    pass

# 错误2: 忘记更新函数体内引用
async def my_func(request: Request, data: MyRequest, ...):
    username = request.username  # 应该是 data.username
```

### ✅ 应该这样做
```python
# 正确: 参数名必须是 request，Pydantic 模型用 data
@rate_limit("10/minute", per_user=True)
async def my_func(
    request: Request,  # slowapi 需要
    data: MyRequest,   # Pydantic 模型
    ...
):
    # 使用 data 访问请求数据
    username = data.username
    password = data.password
```

### 📝 记住
1. **slowapi 严格要求参数名为 `request`**
2. **FastAPI 的 Request 对象和 Pydantic 模型不能同名**
3. **修改参数名后，必须同步修改函数体内所有引用**

## 总结

本次修复的核心问题是**参数命名冲突**。slowapi 库强制要求被装饰的函数必须有一个名为 `request` 的参数，而 FastAPI 中很多端点函数也习惯使用 `request` 作为 Pydantic 模型的参数名。

**解决方案**：
- FastAPI Request 对象 → `request` (slowapi要求)
- Pydantic 请求模型 → `data` (避免冲突)

这个修复确保了 API 限流功能能够正常工作，同时保持了代码的清晰性和可读性。
