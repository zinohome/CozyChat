**基础音色（0-5）**:
- 0: female（女声）
- 1: male（男声）
- 2: mature_male（成熟男声）
- 3: energetic_male（充满活力的男声）
- 4: warm_female（温暖的女声）
- 5: warm_male（温暖的男声）

**AI大模型音色（101001-101005）**:
- 101001: ai_female（AI女声）
- 101002: ai_male（AI男声）
- 101003: ai_narrator（AI旁白）
- 101004: ai_warm_female（AI温暖女声）
- 101005: ai_energetic（AI活力声音）

#### 3.4 使用示例

### 4. 关键技术实现

#### 4.1 异步转换
由于腾讯SDK是同步的，我们实现了完整的异步包装：

**方法**: `ThreadPoolExecutor` + `asyncio.Queue`

```python
# 在单独线程运行同步SDK
def _run_sync():
    synthesizer.start()
    synthesizer.wait()

await asyncio.get_event_loop().run_in_executor(None, _run_sync)
```

#### 4.2 SSL证书配置
解决WebSocket连接的SSL证书验证问题：

**方法**: Monkey-patch `WebSocketApp.run_forever`

```python
# 强制使用certifi证书
def patched_run_forever(self, sockopt=None, sslopt=None, ...):
    if sslopt is None:
        sslopt = {
            "cert_reqs": ssl.CERT_REQUIRED,
            "ca_certs": certifi.where(),
            "check_hostname": True,
        }
    return _original_run_forever(self, sockopt=sslopt, ...)
```

#### 4.3 参数映射

**速度映射**（OpenAI格式 → 腾讯格式）:
```python
def _convert_speed(speed: float) -> int:
    # OpenAI: 0.25-4.0 → 腾讯: -2到2
    if speed <= 0.5: return -2
    elif speed <= 0.75: return -1
    elif speed <= 1.25: return 0
    elif speed <= 2.0: return 1
    else: return 2
```

## 🐛 问题排查与解决

### 问题1：SSL证书验证失败

**症状**:
```
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed
```

**原因**: WebSocket连接使用的证书验证失败

**解决方案**: 
- 在`tencent_speech_sdk/__init__.py`中配置全局SSL上下文
- Monkey-patch `WebSocketApp.run_forever`强制使用certifi证书

**状态**: ✅ 已解决

### 问题2：资源包配额用尽错误

**症状**:
```
Code: 20002
Message: UnsupportedOperation.PkgExhausted
```

**原因**: 
- 资源包未生效（购买后需等待15分钟）
- 资源包未绑定到AppID
- 资源包类型不匹配
- **最终解决**: 重新购买资源包

**解决方案**: 
1. 等待资源包生效（15分钟）
2. 检查资源包绑定状态
3. 确认资源包类型匹配
4. **如果以上都不行**: 重新购买资源包

**状态**: ✅ 已解决（重新购买资源包）

### 问题3：线程安全问题

**症状**:
```
RuntimeWarning: coroutine 'Queue.put' was never awaited
There is no current event loop in thread
```

**原因**: 在子线程中调用`asyncio.get_event_loop()`

**解决方案**: 
- 在主线程获取event loop
- 传递给收集器使用
- 使用`asyncio.run_coroutine_threadsafe`进行线程间通信

**状态**: ✅ 已解决

### 问题4：模块导入错误

**症状**:
```
ModuleNotFoundError: No module named 'tencent_speech_sdk.common'
```

**原因**: 导入路径不正确

**解决方案**: 
- 本地包装器已经处理了路径添加
- 直接从`tencent_speech_sdk`导入，不需要`.common`
- 例如: `from tencent_speech_sdk import credential`

**状态**: ✅ 已解决
