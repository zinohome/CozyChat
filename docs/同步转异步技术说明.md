# 同步转异步技术说明

## 1. 问题背景

### 1.1 项目架构：异步（Async）

CozyChat项目使用**FastAPI异步架构**，所有引擎接口都是异步的：

```python
# 基类定义的异步接口
class STTEngineBase(ABC):
    @abstractmethod
    async def transcribe(
        self,
        audio_data: bytes,
        language: Optional[str] = None,
        **kwargs: Any
    ) -> str:
        """语音转文本 - 异步方法"""
        raise NotImplementedError

class TTSEngineBase(ABC):
    @abstractmethod
    async def synthesize(
        self,
        text: str,
        voice: Optional[str] = None,
        speed: Optional[float] = None,
        **kwargs: Any
    ) -> bytes:
        """文本转语音 - 异步方法"""
        raise NotImplementedError
```

**OpenAI引擎的实现**（原生异步）：
```python
class OpenAISTTEngine(STTEngineBase):
    async def transcribe(self, audio_data: bytes, ...) -> str:
        # OpenAI SDK本身就是异步的
        response = await self.client.audio.transcriptions.create(...)
        return response.text
```

### 1.2 腾讯SDK：同步（Sync）

腾讯语音SDK是**同步的**，所有操作都是阻塞的：

```python
# 腾讯SDK的同步API
class SpeechRecognizer:
    def start(self):  # 同步方法，会阻塞
        # 启动WebSocket连接，会阻塞直到连接建立
        self.ws.run_forever()  # 阻塞调用
    
    def write(self, data: bytes):  # 同步方法
        self.ws.sock.send_binary(data)  # 阻塞调用
    
    def stop(self):  # 同步方法
        self.ws.close()  # 阻塞调用

# 使用方式（同步）
recognizer = SpeechRecognizer(...)
recognizer.start()  # 阻塞，等待连接
recognizer.write(audio_chunk)  # 阻塞，发送数据
recognizer.stop()  # 阻塞，关闭连接
```

### 1.3 冲突

**问题**：我们需要实现一个异步方法，但底层SDK是同步的。

```python
class TencentSTTEngine(STTEngineBase):
    async def transcribe(self, audio_data: bytes, ...) -> str:
        # ❌ 不能直接调用同步方法
        recognizer = SpeechRecognizer(...)
        recognizer.start()  # 这会阻塞整个事件循环！
        # ...
```

**如果直接调用同步方法会发生什么？**

```python
# 错误示例
async def transcribe(self, audio_data: bytes) -> str:
    recognizer = SpeechRecognizer(...)
    recognizer.start()  # ❌ 阻塞事件循环！
    # 在异步函数中调用同步阻塞方法
    # 会导致整个FastAPI应用被阻塞
    # 其他请求无法处理
```

## 2. 解决方案：在线程中运行同步代码

### 2.1 核心思想

**将同步代码放到独立线程中运行，不阻塞主事件循环。**

```
┌─────────────────────────────────────┐
│   FastAPI异步事件循环（主线程）      │
│                                     │
│   async def transcribe():          │
│       ┌─────────────────────────┐  │
│       │ 在线程池中运行同步代码    │  │
│       │  ┌───────────────────┐  │  │
│       │  │ 腾讯SDK同步调用    │  │  │
│       │  │ recognizer.start() │  │  │
│       │  │ recognizer.write() │  │  │
│       │  │ recognizer.stop()  │  │  │
│       │  └───────────────────┘  │  │
│       └─────────────────────────┘  │
│       await 等待线程完成            │
└─────────────────────────────────────┘
```

### 2.2 Python实现方式

Python提供了两种方式在线程中运行同步代码：

#### 方式1：`asyncio.to_thread()`（Python 3.9+）

```python
import asyncio

async def transcribe(self, audio_data: bytes) -> str:
    # 将同步函数放到线程中运行
    result = await asyncio.to_thread(
        self._transcribe_sync,  # 同步函数
        audio_data,            # 参数
        language
    )
    return result

def _transcribe_sync(self, audio_data: bytes, language: str) -> str:
    """同步版本的识别函数"""
    recognizer = SpeechRecognizer(...)
    recognizer.start()  # 在线程中阻塞，不影响主事件循环
    # ... 执行识别
    recognizer.stop()
    return result_text
```

#### 方式2：`ThreadPoolExecutor`（兼容性更好）

```python
from concurrent.futures import ThreadPoolExecutor
import asyncio

# 创建线程池（类级别，共享使用）
_executor = ThreadPoolExecutor(max_workers=5)

async def transcribe(self, audio_data: bytes) -> str:
    loop = asyncio.get_event_loop()
    # 在线程池中运行同步函数
    result = await loop.run_in_executor(
        _executor,              # 线程池
        self._transcribe_sync,  # 同步函数
        audio_data,             # 参数
        language
    )
    return result

def _transcribe_sync(self, audio_data: bytes, language: str) -> str:
    """同步版本的识别函数"""
    recognizer = SpeechRecognizer(...)
    recognizer.start()
    # ... 执行识别
    recognizer.stop()
    return result_text
```

## 3. 完整实现示例

### 3.1 腾讯ASR引擎实现

```python
import asyncio
import threading
from concurrent.futures import ThreadPoolExecutor
from typing import Any, Dict, Optional

# 导入腾讯SDK（同步）
import sys
sys.path.append("example/tencentcloud-speech-sdk-python")
from common import credential
from asr import speech_recognizer

from app.engines.voice.stt.base import STTEngineBase, STTProvider
from app.utils.logger import logger


class ResultCollector(speech_recognizer.SpeechRecognitionListener):
    """结果收集器 - 在线程中运行，收集识别结果"""
    
    def __init__(self):
        self.final_text = ""
        self.error = None
        self.completed = threading.Event()  # 线程同步原语
    
    def on_recognition_result_change(self, response):
        """识别结果变化（中间结果）"""
        result = response.get("result", {})
        text = result.get("voice_text_str", "")
        if text:
            self.final_text = text
    
    def on_sentence_end(self, response):
        """句子结束（最终结果）"""
        result = response.get("result", {})
        text = result.get("voice_text_str", "")
        if text:
            self.final_text = text
    
    def on_recognition_complete(self, response):
        """识别完成"""
        self.completed.set()  # 通知主线程完成
    
    def on_fail(self, response):
        """识别失败"""
        self.error = response.get("message", "Unknown error")
        self.completed.set()


class TencentSTTEngine(STTEngineBase):
    """腾讯ASR引擎"""
    
    # 共享线程池
    _executor = ThreadPoolExecutor(max_workers=5, thread_name_prefix="tencent_asr")
    
    def __init__(self, config: Dict[str, Any]):
        super().__init__(config)
        
        # 读取配置
        api_config = config.get("api", {})
        self.app_id = api_config.get("app_id")
        self.secret_id = api_config.get("secret_id")
        self.secret_key = api_config.get("secret_key")
        
        # 创建凭证
        self.credential = credential.Credential(
            self.secret_id,
            self.secret_key
        )
        
        # ASR参数
        self.engine_model_type = config.get("model", "16k_zh")
        self.filter_modal = config.get("filter_modal", 1)
        self.filter_punc = config.get("filter_punc", 1)
        self.filter_dirty = config.get("filter_dirty", 1)
        self.need_vad = config.get("need_vad", 1)
        self.voice_format = config.get("voice_format", 1)
    
    def _get_provider(self) -> STTProvider:
        return STTProvider.TENCENT
    
    async def transcribe(
        self,
        audio_data: bytes,
        language: Optional[str] = None,
        **kwargs: Any
    ) -> str:
        """语音转文本（异步）"""
        # 验证音频格式
        if not self.validate_audio_format(audio_data):
            raise ValueError("Unsupported audio format")
        
        # 在线程池中运行同步识别
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(
            self._executor,
            self._transcribe_sync,  # 同步函数
            audio_data,
            language or self.language
        )
        
        return result
    
    def _transcribe_sync(
        self,
        audio_data: bytes,
        language: str
    ) -> str:
        """同步版本的识别函数（在线程中运行）"""
        # 创建结果收集器
        collector = ResultCollector()
        
        # 创建识别器（同步操作）
        recognizer = speech_recognizer.SpeechRecognizer(
            self.app_id,
            self.credential,
            self.engine_model_type,
            collector
        )
        
        # 配置参数（同步操作）
        recognizer.set_filter_modal(self.filter_modal)
        recognizer.set_filter_punc(self.filter_punc)
        recognizer.set_filter_dirty(self.filter_dirty)
        recognizer.set_need_vad(self.need_vad)
        recognizer.set_voice_format(self.voice_format)
        
        try:
            # 启动识别（阻塞，但在线程中，不影响主事件循环）
            recognizer.start()
            
            # 分块发送音频数据（阻塞操作）
            SLICE_SIZE = 6400
            offset = 0
            while offset < len(audio_data):
                chunk = audio_data[offset:offset + SLICE_SIZE]
                recognizer.write(chunk)  # 阻塞，但在线程中
                offset += SLICE_SIZE
                import time
                time.sleep(0.02)  # 模拟实时发送间隔
            
            # 停止识别
            recognizer.stop()
            
            # 等待识别完成（最多30秒）
            if collector.completed.wait(timeout=30):
                # 检查是否有错误
                if collector.error:
                    raise Exception(f"Recognition failed: {collector.error}")
                return collector.final_text
            else:
                raise TimeoutError("Recognition timeout")
                
        except Exception as e:
            logger.error(f"Tencent ASR error: {e}", exc_info=True)
            raise
    
    async def health_check(self) -> bool:
        """健康检查"""
        try:
            # 尝试创建一个测试识别器
            test_credential = credential.Credential(
                self.secret_id,
                self.secret_key
            )
            # 如果凭证创建成功，说明配置正确
            return True
        except Exception as e:
            logger.warning(f"Tencent ASR health check failed: {e}")
            return False
```

### 3.2 执行流程详解

```
1. FastAPI收到请求
   ↓
2. 调用 async def transcribe()
   ↓
3. 调用 loop.run_in_executor()
   ↓
4. 线程池中的线程开始执行 _transcribe_sync()
   ↓
5. 在线程中：
   - 创建 SpeechRecognizer（同步，阻塞线程）
   - recognizer.start()（同步，阻塞线程）
   - recognizer.write()（同步，阻塞线程）
   - recognizer.stop()（同步，阻塞线程）
   ↓
6. 主事件循环继续处理其他请求（不阻塞）
   ↓
7. 线程完成，返回结果
   ↓
8. await 返回，继续执行
```

## 4. 关键点说明

### 4.1 为什么需要线程？

**同步代码会阻塞**：
- `recognizer.start()` 会等待WebSocket连接建立
- `recognizer.write()` 会等待数据发送完成
- 这些操作可能需要几秒甚至几十秒

**如果直接调用**：
```python
async def transcribe(self, audio_data: bytes) -> str:
    recognizer.start()  # ❌ 阻塞整个事件循环
    # FastAPI无法处理其他请求
    # 所有用户请求都会被阻塞
```

**在线程中运行**：
```python
async def transcribe(self, audio_data: bytes) -> str:
    await loop.run_in_executor(executor, self._transcribe_sync, ...)
    # ✅ 主事件循环继续运行
    # ✅ 其他请求可以正常处理
```

### 4.2 线程同步

**问题**：如何在线程中收集结果，并返回给异步函数？

**解决方案**：使用`threading.Event`或`asyncio.Queue`

```python
class ResultCollector:
    def __init__(self):
        self.result = ""
        self.completed = threading.Event()  # 线程同步原语
    
    def on_recognition_complete(self, response):
        self.result = response["text"]
        self.completed.set()  # 通知主线程

# 在线程中等待
collector.completed.wait(timeout=30)  # 阻塞线程，但不阻塞事件循环
result = collector.result
```

### 4.3 线程池大小

```python
_executor = ThreadPoolExecutor(max_workers=5)
```

- **max_workers=5**：最多5个并发识别任务
- 如果超过5个任务，会排队等待
- 根据服务器性能调整

### 4.4 错误处理

```python
try:
    result = await loop.run_in_executor(...)
except Exception as e:
    # 处理线程中的异常
    logger.error(f"Error in thread: {e}")
    raise
```

## 6. 性能考虑

### 6.1 优势

- ✅ **不阻塞主事件循环**：其他请求可以正常处理
- ✅ **保持异步接口**：与项目架构一致
- ✅ **并发处理**：可以同时处理多个识别任务

### 6.2 注意事项

- ⚠️ **线程开销**：创建线程有一定开销
- ⚠️ **资源限制**：线程池大小需要合理配置
- ⚠️ **GIL限制**：Python的GIL可能影响CPU密集型任务（但I/O操作不受影响）

## 7. 总结

**同步转异步的核心**：
1. 将同步代码放到独立线程中运行
2. 使用`asyncio.to_thread()`或`ThreadPoolExecutor`
3. 使用`threading.Event`或`asyncio.Queue`进行线程间通信
4. 保持异步接口，与项目架构一致

**关键代码模式**：
```python
async def async_method(self, ...):
    # 在线程池中运行同步函数
    result = await loop.run_in_executor(
        executor,
        self._sync_method,  # 同步版本
        ...
    )
    return result

def _sync_method(self, ...):
    # 同步代码，在线程中运行
    # 可以调用同步SDK
    pass
```
